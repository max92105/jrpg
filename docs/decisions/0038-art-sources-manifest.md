# 0038. Art sources manifest

Status: accepted
Date: 2026-11-03

## Context
Decision 440: every art file must say where it came from. Audio has a per-file manifest (ADR 0036) because each sound
has its own freesound page. Art comes from a few sources with many files each: a bought pack (Mana Seed, ELV Games), a
font family, generated placeholders. The Mana Seed license (decision 438) allows one product and no redistribution, and
the developer's investors will ask about provenance, so a sheet imported without its line has to fail somewhere.

## Options
### A. A flat per-file list, as ADR 0036
- Pros: one shape for audio and art.
- Cons: every Mana Seed sheet repeats the author, url and license; a pack's license change is many edits.

### B. Sources and files (chosen)
- Pros: a source is written once; a file names it; placeholders are a flag on the source.
- Cons: two lists to keep in step, which the test does.

### C. A sidecar file per art folder
- Pros: close to the files.
- Cons: nine folders to read; a file moved between folders loses its line.

### D. Fields on `tilesheets.json`
- Pros: the editor already writes it.
- Cons: sheets only; the game would load license data it never uses.

### E. Credits generated by a script
- Pros: never stale.
- Cons: worth it once there are many sources; today there are five.

## Decision
`content/art/art-sources.json` holds `sources` (id, name, author, url, license as an SPDX id or a `LicenseRef-`, an
optional `licenseFile` path under `content/art/`, `isPlaceholder`) and `files` (a path under `content/art/` and a
`sourceId`). `content/art/CREDITS.md` is written by hand, one section per source and a "Placeholders (replace before
release)" section. The game never reads either, so there is no Data loader; `Data.Tests/Art/ArtSourcesTests` reads the
repository's folder (stamped into the test assembly as the apps stamp `ContentRoot`) and keeps files, entries, sources,
licenses and credits in step. Licenses: CC0, CC-BY 3.0 or 4.0, OFL 1.1 for fonts, a bought pack's
`LicenseRef-<publisher>`; never NC or SA (decision 427's rule, extended to art); `LicenseRef-Unrecorded` and
`LicenseRef-Generated` only on placeholder sources.

## Consequences
An imported sheet fails the test until its line is added (decision 448). A placeholder source lists what must be
replaced before release. A bought pack's license text stays outside the repository (it isn't redistributable either),
named by the source's url. The test reads the source tree, so a deleted file never haunts it from a stale test output.
