# C3. Skill descriptions in content

Part of [the battle plan](../README.md). Design: [design.md](../design.md).

- **C3. Skill descriptions in content** (Core + Data + content, about 130 lines; decision 102)
  - **Goal:** skills have a `description` like items.
  - **Changes:**
    - `SkillDefinition.Description` (required).
    - The skill loader and validator require it (it may be empty, as item descriptions can be).
    - `skills.json` gets placeholder wording for the developer to review, for example "Deals 15 damage to one enemy.".
  - **Tests:** Data `SkillCatalogValidator_Validate_MissingDescription_ThrowsNamingTheSkill`, `ContentCatalogLoader_Load_RepositoryContent_EverySkillHasDescription`.
- **Done, with deviations:** the missing-description test is a reader test (`ContentFileReaderTests.Read_SkillWithoutDescription_ThrowsNamingTheFileAndField`), since `required` and the strict JSON options reject the file before the validator sees a skill, as for items; the validator is unchanged, an empty description being allowed. The five descriptions in `skills.json` are placeholders for the developer to review; the damage ones carry no number, since defense lowers the damage dealt.
