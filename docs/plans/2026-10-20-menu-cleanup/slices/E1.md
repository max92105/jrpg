# E1. The equipment sheet and preview text as pure types

Part of [the menu cleanup plan](../README.md). Design: [design.md](../design.md), "What exists" (`EquipmentPage`), "Core changes" and key decision 8.

- **E1. The equipment sheet and preview text as pure types** (Core + Game, about 200 lines)
  - **Goal:** what `EquipmentPage` formats leaves the page, as two pure types tested on their own. Nothing changes on screen.
    - The member sheet: what's worn and the parameter values.
    - The preview: values and colors.
  - **Changes (Core):** `Party/PartyMember.EquippedIn(EquipmentSlot)` goes from `internal` to `public`, with a one-line doc ("null when the slot is empty").
  - **New types (Game):**
    - `Menus/EquipmentSheet`: `internal sealed record`. It is one member as the Equipment page shows them: their name, what they wear in each listed slot, and their parameter values.
      - `public static ImmutableArray<EquipmentSlot> Slots` (Weapon, Armor): the rows in order, before "Remove all". It moves from `EquipmentPage._slots`.
      - `public static string LabelIdOf(EquipmentSlot slot)` (moved).
      - Members: `string Name`, `ImmutableArray<ItemDefinition?> Worn` (in `Slots` order), `ImmutableArray<string> Stats` (Max HP, Max MP, Attack, Defense).
      - `public static EquipmentSheet Of(PartyMember member)`, built from `member.EquippedIn`. `EquipmentPage.WornIn` goes.
    - `Menus/StatPreviewText`: `internal sealed record StatPreviewText(PreviewValue Attack, PreviewValue Defense)`. It is a stat preview's new attack and defense as text, colored by whether each goes up or down.
      - `public static StatPreviewText Of(StatPreview preview)`, moved from `PreviewOf` and `ColorOf`.
      - `PreviewValue(string Text, Color Color)` is a nested public record.
  - **Changes (Game, `EquipmentPage`):**
    - It holds an `EquipmentSheet` and a `StatPreviewText?`.
    - `SheetOf`, `WornIn`, `PreviewOf`, `ColorOf` and `Number` go.
    - `Apply` reads `Shown.EquippedIn(slot)`.
  - **Tests:**
    - Core: `PartyMemberTests.EquippedIn_WornArmor_ReturnsIt`, `PartyMemberTests.EquippedIn_EmptyWeaponSlot_ReturnsNull`.
    - Game `EquipmentSheetTests`:
      - `Of_WearingBronzeSword_PutsItInTheWeaponSlot`;
      - `Of_NothingWorn_EverySlotIsEmpty`;
      - `Of_WearingSword_AttackTextIsTheMembersTotalAttack`: `Stats[2]` equals `member.TotalStats.Attack` formatted with the invariant culture, not a fixed content value (devil's advocate 7).
    - Game `StatPreviewTextTests`:
      - `Of_StrongerWeapon_AttackIsPositive`;
      - `Of_RemovingArmor_DefenseIsNegative`;
      - `Of_NoChange_IsPrimaryText`.
    - The existing `EquipmentPageTests` pass unchanged.
