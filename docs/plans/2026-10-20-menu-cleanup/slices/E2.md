# E2. The equipment sheet view

Part of [the menu cleanup plan](../README.md). Design: [design.md](../design.md), key decision 8.

- **E2. The equipment sheet view** (Game, about 260 lines, mostly moved)
  - **Goal:** `EquipmentPage`'s drawing moves to a view. The page keeps input, cursors, the choice and commands to Core, at about 170 lines. This mirrors `EquipmentChoice` / `EquipmentChoiceView`. Nothing changes on screen.
  - **New types (Game):** `Menus/EquipmentSheetView`, `internal sealed`. It draws the Equipment page's sheet in the legacy `EquipmentView` layout.
    - Built with `public EquipmentSheetView(ScreenText text, UiTextures ui)`. It owns the fonts, the two `SectionTitle`s and the labels.
    - `EquipmentLabels` moves here as a private record: slots, Empty, Remove all, stats.
    - `public void Draw(SpriteBatch batch, TextureLibrary textures, Place place, float opacity)`.
    - `public readonly record struct Place(EquipmentSheet Sheet, Rectangle Area, int SelectedRow, StatPreviewText? Preview, string? Notice)` is where and what to draw this frame. `SelectedRow == EquipmentSheet.Slots.Length` is "Remove all".
    - Moved in: the layout constants and `DrawSlotRow`, `DrawRemoveAllRow`, `DrawParameters` and `DrawPreview`, with their legacy comments.
  - **Changes:**
    - `EquipmentPage.Draw` narrows the area when the choice is open (as today). It draws the sheet through `EquipmentSheetView`, then the choice through `EquipmentChoiceView`.
    - Only the constants the page still uses stay there (`Margin` and the choice's width).
  - **Tests:** none new; it is draw-only. The existing `EquipmentPageTests` pass unchanged.
