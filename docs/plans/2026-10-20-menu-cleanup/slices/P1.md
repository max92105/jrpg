# P1. The party cursor as a pure type

Part of [the menu cleanup plan](../README.md). Design: [design.md](../design.md), "What exists" (`PartyPage`) and key decision 8.

- **P1. The party cursor as a pure type** (Game, about 220 lines)
  - **Goal:** the Party page's navigation over its two columns leaves the page, as a pure type tested on its own, like `EquipmentSheet` for Equipment. Nothing changes on screen.
    - The type covers Up and Down within a column, Left and Right to the other column at the same row or its last card, staying on a card after a member moves, and the swap's place-skipping.
  - **New types (Game):** `Menus/PartyCursor`, `internal sealed`. It is where the Party page's cursor stands over the active and reserve columns of a `PartyState`.
    - `public PartyCursor(PartyState party)`.
    - `public bool IsOnReserve { get; }`, `public int Row { get; }`, `public PartyMember Selected { get; }`.
    - `public void MoveInColumn(int step)` (wraps).
    - `public void SwitchColumn()` (developer, 2026-10-20 navigation rule; does nothing when the other column is empty).
    - `public void KeepOnACard()`: after a member moved, the next card slides in, or the cursor steps back to the last one, or to the active column when the reserve emptied.
    - `public void MoveToNextPlaceToSwap(int step)`: skips members Core says `!CanChangePlace` (C2).
    - `public void ReturnTo(int activeRow)`: used by Cancel while swapping.
    - `public void Reset()`: the first active card (M1, decision 109).
    - `IsOnReserve` replaces the page's `_column` int and its `ActiveColumn` / `ReserveColumn` constants. They're kept as private constants only if the view still needs column indexes.
  - **Changes (`PartyPage`):**
    - `_column`, `_row` and `_movingFromRow`'s arithmetic, `MembersIn`, `MoveInColumn`, `SwitchColumn`, `KeepCursorOnACard` and `MoveToNextPlaceToSwap` move to `PartyCursor`.
    - The page keeps:
      - input dispatch;
      - the action choice and swap sub-states;
      - commands to Core and the notices;
      - `ShowParty`.
    - `Selected` reads `_cursor.Selected`.
  - **Tests (Game, `PartyCursorTests`; repository new game, as `PartyPageTests`):**
    - `MoveInColumn_DownOnLastCard_WrapsToFirst`;
    - `SwitchColumn_FromLowerRowThanReserve_SelectsLastReserveCard`;
    - `SwitchColumn_EmptyReserve_StaysInActive`;
    - `KeepOnACard_LastReserveMemberJoined_MovesToActiveColumn`;
    - `MoveToNextPlaceToSwap_Up_SkipsTheLeader`;
    - `Reset_AfterMoving_SelectsTheLeader`.
    - The existing `PartyPageTests` pass unchanged.
