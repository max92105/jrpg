# U4. One member card for the Party page and the item target picker

Part of [the menu cleanup plan](../README.md). Design: [design.md](../design.md), key decision 7, tunables, risks.

- **U4. One member card for the Party page and the item target picker** (Game, about 280 lines; decision 111, question 112)
  - **Goal:** the Party page and the item target picker draw the same member card, the Party card's look. It is built from `MeasuredText` and `MemberVitalBars` and lives in `Ui/`, so the victory screen can reuse it. The picker shows the cards in two columns (question 112, placeholder). Its behavior is unchanged.
  - **New types (Game):** `Ui/MemberCardView`, `internal sealed`, moved from `Menus/PartyMemberCardView`. It draws one member as a card (legacy `PartyMemberCard`): diamond portrait, name with the Leader badge, level, class, and HP and MP meters.
    - `public MemberCardView(ScreenText text, UiTextures ui, ContentCatalog catalog)`.
    - `public const int Height = 120`.
    - `public Card CardOf(PartyMember member, PartyMember leader)`.
    - `public void Draw(SpriteBatch batch, TextureLibrary textures, Place place, float opacity)`.
    - Nested records:
      - `Card(MeasuredText Name, bool IsLeader, MeasuredText Level, string ClassName, string PortraitFile, MemberVitalBars Vitals)`;
      - `Place(Card Card, Rectangle Area, bool IsSelected)`.
    - The width comes from `Place.Area`, so the same card fills a Party column or a picker column.
  - **Changes:**
    - `Menus/PartyMemberCardView` is deleted. `PartyPage` uses `Ui/MemberCardView`, and M1's `CardOf` seam returns `MemberCardView.Card`.
    - `Menus/ItemTargetPickerView`:
      - its `MemberCard`, `CardPlace`, `DrawCard` and card constants go;
      - `Show` builds `MemberCardView.Card`s;
      - `Draw` lays them out in two 560 px columns 16 px apart, in member order, inside the band. The band's height follows the row count;
      - a member the item can't be used on is drawn at the existing `UnavailableOpacity`, and a chosen one with `IsSelected`;
      - the band, heading and scrim are unchanged. `ItemTargetPicker` is untouched.
    - Leader for the picker's badge: `session.Party.Leader`, passed to `ItemTargetPickerView.Show`.
  - **Layout seam:** `internal static Rectangle CardArea(int index, Point cardsTopLeft)` on `ItemTargetPickerView` gives a card's place in the two columns. It is pure, so its rule can be tested without a window.
  - **Tests (Game):**
    - `ItemTargetPickerViewTests.CardArea_FirstMember_IsFirstColumnFirstRow`;
    - `ItemTargetPickerViewTests.CardArea_SecondMember_IsSecondColumnFirstRow`;
    - `ItemTargetPickerViewTests.CardArea_SeventhMember_IsFirstColumnFourthRow`.
    - `ItemTargetPickerTests`, `InventoryPageTests` and `PartyPageTests` pass unchanged. M1's `Open_AfterHpChanged_CardShowsTheNewHp` reads `CardOf(leader).Vitals.Hp.Bar.Fraction` (path from U3).
