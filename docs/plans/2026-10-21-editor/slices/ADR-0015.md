# ADR 0015: NPCs on maps

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "NPCs" and "Key decisions" 9; decision 69 (part).

- **ADR 0015: NPCs on maps** (before N1)
  - Write `docs/decisions/0015-npcs-on-maps.md` with `/adr`, from the options in the plan's "ADRs needed" (A an object drawn from a field sprite, recommended; B a separate NPC catalog and placed NPCs; C NPCs as tile objects with no format change), and add its line to `docs/decisions/README.md`.
  - It records the content change: `objects.json` gains an optional `fieldSpriteFile` per object (a file in `content/art/field-sprites/`); an object has tiles or a field sprite, never both; a field-sprite object has no above-player zones. Old content loads unchanged (the field is absent), so no migration.
  - It records the placeholder art rule (decision 69): NPCs reference one shared placeholder sprite by file name, so real art later is a file swap or a one-field change per NPC.
  - It records the answers (or the placeholders kept) to questions 127 (standing still), 128 (facing down), 129 (default outline), 130 (placeholder file), 131 (one object per character) and 132 (one cell, the player's frame layout), and that movement would need its own ADR.
  - Accepted by the developer before N1 starts.
