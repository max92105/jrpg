# E1. The window: no empty strip, a layer list that chooses and adds layers, maps by name

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "Why there is an empty strip at the top"; decisions 71 (layer presets plus a free Z) and 122.

- **E1. The window: no empty strip, a layer list that chooses and adds layers, maps by name** (Editor, about 190 lines)
  - **Goal:**
    - With no load or save error, the toolbar sits at the top of the window: the two error lines take no space. An error still shows, in red, above the toolbar.
    - Clicking a layer in the side list chooses it (the toolbar's layer box follows, and the reverse). Each entry reads "Ground (z -5)", or "Layer (z 3)" for a Z with no preset.
    - **Adding a layer** (the developer's "above layer": ground lowest, then flora, details and so on): under the list, an editable box (the presets, or a typed Z) and **Add layer**. The chosen Z becomes the layer edits go to; the list shows it at once, as "Detail (z -4), empty" until something is painted on it. Painting there creates the layer (`MapDraft.SetTileId` already adds a layer for a new Z); a layer left with no tiles isn't saved (existing `MapDraft` rule), which the "empty" mark says.
    - The map list reads "Forest (forest)": display name then id, sorted by display name (decision 122). Switching maps works as today.
  - **New types:**
    - `Maps/LayerEntry` (record): one row of the layer list, its Z, its name and whether the map has tiles there yet.
    - `Shell/MapEntry` (record): one row of the map list, its id and the text shown.
  - **Changes:**
    - `MainWindow.xaml`: a `CollapsedWhenEmpty` style (a `DataTrigger` on empty `Text`) on both error lines; the layer `ListBox` binds `SelectedValue` to `Layer.Z` through `SelectedValuePath="Z"` and shows `Name`; the Add layer box and button; the map list binds to `MapEntries`, selecting by `Id`.
    - `Maps/LayerPresets.NameOf(int z)`: the preset's name, or "Layer" for another Z.
    - `Maps/LayerChoiceViewModel.TryAddLayer(string text)`: a preset name or a whole number becomes `Z`; returns false and keeps the choice otherwise.
    - `Shell/MainViewModel.LayerEntries`: the open map's layers, bottom first, plus the chosen Z marked empty when the map has no layer there; refreshed on `Map` and `Z` changes.
    - `Shell/MainViewModel.MapEntries` replaces the list's use of `MapIds` (which `EventEditing` keeps using); `MainWindow` selects by entry id.
  - **Tests:**
    - `LayerPresetsTests`: `NameOf_PresetZ_ReturnsItsName`, `NameOf_OtherZ_ReturnsLayer`.
    - `LayerChoiceViewModelTests`: `TryAddLayer_WholeNumber_ChoosesThatZ`, `TryAddLayer_PresetName_ChoosesItsZ`, `TryAddLayer_NotANumber_KeepsTheChoice`.
    - `MainViewModelTests`:
      - `LayerEntries_ForestMap_ListsLayersBottomFirstWithNames`;
      - `LayerEntries_ChosenZWithoutLayer_ListsItAsEmpty`;
      - `MapEntries_RepositoryContent_ShowsNameThenIdSortedByName`;
      - `Save_NewMap_AddsItsEntry` (replaces the list assertion of `Save_NewMap_WritesItAndAddsItToTheList`).
