# E11a. Point handles: drag, insert, remove

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "Tunables" (shapes window), "Legacy mapping" (`ObjectEditorWindow`). Builds on E9 and E10. Split up front (review): editing points first, the rectangle, snap, zoom and dimming in E11b.

- **E11a. Point handles: drag, insert, remove** (Editor, about 200 lines)
  - **Goal (legacy `ObjectEditorWindow` controls):**
    - Each point of the active shape (the outline, or the chosen zone) has a round handle, 10 screen px whatever the window's size; the last point's handle is yellow, so the next click's edge is clear.
    - **Drag a handle** to move the point. **Right click a handle** removes the point.
    - A click within 8 screen px of an edge of the active shape **inserts** a point there instead of adding one at the end.
    - Moved and inserted points are clamped and rounded to the pixel grid like added ones (E9).
  - **New types:**
    - `Objects/ShapeEditing` (static, pure): where a mouse gesture lands on a shape. Points here are screen positions, so tolerances stay in screen pixels whatever the scale and the object's proportions.
      - `HandleAt(IReadOnlyList<Point2D> points, Point2D mouse, double radius)`: the index of the nearest point within `radius`, or null.
      - `EdgeAt(IReadOnlyList<Point2D> points, Point2D mouse, double distance)`: the index of the point an edge within `distance` starts from (the closing edge included), or null.
  - **Changes:**
    - `Objects/ObjectShapesViewModel`: `MovePoint(int index, Point2D point)`, `InsertPoint(int afterIndex, Point2D point)`, `RemovePoint(int index)`; all act on `ActivePoints` and go through the same placing step as `AddPoint` (clamp, round).
    - `Objects/ObjectShapesWindow`: handles drawn as ellipses; mouse down tries `HandleAt` (drag starts), then `EdgeAt` (insert), then `AddPoint`; right click on a handle removes it.
    - Controls help (F1): drag, right click and insert in the "Shapes window" section.
  - **Existing tests this breaks:** none.
