# E5b1. Setting up a sheet with the guessed cut

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "Tunables" (tile size guess, new sheet id); decisions 115, 118. Split from E5b (developer, 2026-10-21): this slice creates the sheet at once with the guessed cut; [E5b2](E5b2.md) puts the Cut panel between **Set up** and the sheet.

- **E5b1. Setting up a sheet with the guessed cut** (Editor, about 280 lines)
  - **Goal:**
    - Choosing an image that isn't set up shows a **Set up** button (and Tiles > Set up sheet in the menu). It creates the sheet in the draft at once: id from the file name in snake case (decision 118: `Grass3.png` -> `grass_3`), tile size guessed (48, then 32, 16, 64, 24 px: the first that divides both sides, else 48), margin and spacing 0.
    - One catalog step: undoable (E4b), saved with Ctrl+S, stored as tile size. The sheet box rebuilds: the image shows by its id with its grid, and cells can be chosen and painted.
    - Undoing the set-up is refused while tiles are cut from the sheet, naming the first one ("Can't undo: tile 12 is cut from sheet grass_3."). An undo that removes the sheet of the chosen cell clears the choice, so nothing is painted from a sheet that no longer exists.
    - **Known gap until E5b2:** a wrong guess can't be corrected (no Cut panel yet).
  - **New types:**
    - `Tiles/SheetCutGuess` (static): the tile size a new sheet starts with, from its image size.
    - `Tiles/TilesheetIds` (static): a new sheet's id from its file name, unique among the taken ids.
  - **Changes:**
    - `Catalogs/CatalogDraft.SetTilesheet(TilesheetDefinition sheet)`: adds the sheet, or replaces the one with its id; one undoable step. `SheetsRemovedByUndo()` beside `TilesRemovedByUndo()`.
    - `Catalogs/CatalogUsage.TilesCutFrom(string sheetId, ContentCatalog catalog)`; `Shell/MainViewModel` refuses the undo with it.
    - `Tiles/TileBrowserViewModel`: `SetUpSheetCommand` (can execute on an image not set up); `SheetChoices` rebuilt when `Current.Tilesheets` changes, keeping the shown image.
    - `Tiles/TileBrowserView`: the Set up button; `Shell/MainWindow`: Tiles > Set up sheet; F1 line.
  - **Tests:**
    - `SheetCutGuessTests`: `TileSizeFor_DivisibleBy48_Is48`, `TileSizeFor_DivisibleBy32Only_Is32`, `TileSizeFor_NoCommonSizeDivides_Is48`.
    - `TilesheetIdsTests`: `FromFile_MixedCaseWithDigits_IsSnakeCase` (`Grass3.png` -> `grass_3`, `tree02_s_01_animation.png` -> `tree_02_s_01_animation`, `RA_Jungle.png` -> `ra_jungle`), `FromFile_IdTaken_AppendsNumber`.
    - `CatalogDraftTests`: `SetTilesheet_NewId_AddsItAndMarksDirty`, `Undo_SetTilesheet_RemovesTheSheet`.
    - `TileBrowserViewModelTests`: `SetUpSheetCommand_ImageNotSetUp_AddsTheGuessedSheetAndShowsIt`, `SetUpSheetCommand_SheetAlreadySetUp_CannotExecute`, `Undo_SetUpOfTheChosenCellsSheet_ClearsTheChoice`.
    - `MainViewModelTests`: `Undo_SetUpSheetWithTilesCut_RefusesNamingTheTile`.
