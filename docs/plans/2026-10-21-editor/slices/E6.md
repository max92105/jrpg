# E6. Re-cutting a set-up sheet

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "Key decisions" 3 and "Risks" (a re-cut changes art on every map); decision 116. Builds on E5b's Cut panel and E4b's `CatalogUsage`.

- **E6. Re-cutting a set-up sheet** (Editor, about 250 lines)
  - **Goal (decision 116):**
    - A **Cut...** button for a set-up sheet (and Tiles > Cut sheet...) opens E5b's Cut panel pre-filled with the sheet's cut. Apply replaces the cut; tiles keep their column and row.
    - For a sheet with tiles, the panel warns while editing: "12 tiles are cut from this sheet, used on 2 maps (forest, start) and by 1 object (tree); they will show other pixels."
    - A cut that would put a tile's cell outside the image is refused with its id: "Tile 57 at (11, 3) would be outside the 10 x 8 grid." (the art check would refuse the save, and the editor would no longer open the maps).
    - Apply asks once with the warning; on yes, the map, the sheet marks and object previews redraw with the new cut. Ctrl+Z restores the old cut (one catalog step, E4b).
  - **Changes:**
    - `Catalogs/CatalogUsage`: `OfSheet(ContentCatalog catalog, string sheetId, MapLayout? openLayout)`: the tiles cut from a sheet and the maps and objects using them.
    - `Tiles/SheetCutViewModel`: takes the sheet's usage; `Problem` also covers tiles outside the new grid; `Warning`.
    - `Tiles/TileBrowserViewModel`: `CutSheetCommand` (can execute on a set-up sheet: opens `Cut` with its cut and usage); `ApplyCutCommand` asks through the shell's confirm when `Warning` is set.
    - `Tiles/TileImages`: crops cached by (sheet record, column, row) instead of tile id, so a re-cut sheet gets fresh crops.
    - `Shell/MainWindow`: redraws the map when `CatalogDraft.Current` changes (until now only map changes redrew it).
  - **Tests:**
    - `CatalogUsageTests`: `OfSheet_SheetUsedByMapAndObject_CountsBoth`, `OfSheet_UnusedSheet_IsEmpty`.
    - `SheetCutViewModelTests`: `Problem_TileOutsideNewGrid_NamesTheTile`, `Warning_SheetWithUsedTiles_NamesMapsAndObjects`, `Warning_SheetWithoutTiles_IsNull`.
    - `TileBrowserViewModelTests`: `CutSheetCommand_SetUpSheet_OpensCutWithItsColumnsAndRows`, `ApplyCutCommand_UserDeclinesWarning_KeepsTheCut`, `ApplyCutCommand_UserAccepts_ReplacesTheCut`.
    - `CatalogDraftTests`: `Undo_AfterReCut_RestoresTheOldCut`.
  - **Verify by hand:**
    - [ ] Re-cut `grass_3` (set up in E5b, unused): no warning; Apply; the grid changes.
    - [ ] On a copy of the content (`--content`), re-cut `ground` to 24 px: the warning names the maps; accept: the map redraws with quarter tiles; Ctrl+Z: back to 48 px.
    - [ ] A cut too small for a used tile is refused, naming it.
