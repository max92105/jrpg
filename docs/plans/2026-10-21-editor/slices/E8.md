# E8. Collision and zones shown on the map

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "Key decisions" 6, "Core changes", "Tunables" (collision overlay).

- **E8. Collision and zones shown on the map** (Core + Editor, about 220 lines)
  - **Goal:**
    - View > **Show collision** (Ctrl+H, and a toolbar toggle) draws over the map:
      - cells the player can't enter, tinted red, by the game's rule: no tile, or any blocked tile;
      - each placed object's collision outline, green;
      - each placed object's above-player zones, blue.
    - It redraws with every map or catalog change and their undo (painting, walkability marks, re-cuts, from E9 on shape edits).
    - Off by default; the choice holds across maps.
  - **Core:** `Maps/WalkabilityGrid` becomes public (`Build`, `IsWalkable`, `Width`, `Height`); behavior unchanged.
  - **New types:**
    - `Maps/CollisionShapes` (pure): what blocks the player on a map and what's drawn over them, in map cells. `Of(MapLayout layout, ContentCatalog catalog)` returns `BlockedCells`, `Outlines` and `Zones` (each a list of `Point2D` outlines in map cells).
    - `Maps/CollisionDrawing` (WPF): draws a `CollisionShapes` as one image over the map.
  - **Changes:**
    - `Shell/MainViewModel.IsCollisionShown` (observable).
    - `Shell/MainWindow.xaml`: a `CollisionImage` layer between the map and the grid; `MainWindow` redraws it with the map when shown.
  - **Tests:**
    - Core: the existing `WalkabilityGrid` tests pass unchanged.
    - `CollisionShapesTests`:
      - `Of_CellWithBlockedTile_IsBlocked`;
      - `Of_CellWithoutTiles_IsBlocked`;
      - `Of_ObjectWithOutline_PlacesItInMapCells` (a 2 x 3 object at (4, 5): point (0.5, 1) -> (5, 8));
      - `Of_ObjectWithZones_ListsEachZoneInMapCells`;
      - `Of_ObjectWithoutOutline_AddsNoOutline`.
  - **Verify by hand:**
    - [ ] On `start`, toggle on: houses and trees show green outlines and blue canopies; the map's hole (5, 13) is red.
    - [ ] Mark a tile blocked (E4a): its cells turn red at once; Ctrl+Z: they clear.
    - [ ] Walk the game along the red and green edges: it blocks exactly there.
