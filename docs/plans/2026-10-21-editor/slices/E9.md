# E9. An object's collision outline

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "Key decisions" 7, "Tunables" (shapes window), "Legacy mapping" (`ObjectEditorWindow`); ADR 0014. The object browser and placing already read the catalog draft (E3a).

- **E9. An object's collision outline** (Editor, about 270 lines)
  - **Goal:**
    - Objects > **Edit shapes...** opens the **object shapes window**: for the one placed object selected on the map if there is exactly one (Ctrl + drag, E2), else for the object chosen in the Objects panel. A double-click on an object in the panel, or on a placed object on the map in Objects mode, opens it too.
    - The window shows the object's picture, fitted into a 560 px box, with its collision outline drawn over it in the overlay's green (E8).
    - A click on the picture adds a point at the end of the outline. Points are clamped into the object (a click past the edge lands on it) and rounded to the object's pixel grid (one map pixel: 1 / (cells x 48) of its size), so outlines stay on whole pixels as the game's canopy mask reads them.
    - **Backspace** or **Ctrl+Z** removes the last point (legacy); **Clear shape** empties the outline (an empty outline never blocks, as in Core).
    - An outline with 1 or 2 points disables **OK** and says why: "The collision outline needs at least 3 points (has 2), or none." **Cancel** (or Esc) leaves the object as it was.
    - OK puts the object in the catalog draft: one catalog step ("Unsaved changes"; the main window's Ctrl+Z undoes it, E4b), saved with Ctrl+S. The map, its canopies and the collision overlay redraw at once; the Objects panel lists the new record and keeps it chosen.
    - Zones are kept untouched (E10 edits them); dragging, inserting and removing a chosen point come in E11a; snapping and zoom in E11b.
  - **New types:**
    - `Objects/ObjectShapesViewModel` (`ObservableObject`): the collision outline being edited for one object definition, and the problem that stops it being saved.
      - `ObjectShapesViewModel(ObjectDefinition definition)`.
      - `CollisionOutline` (`IReadOnlyList<Point2D>`, observable, replaced on each change), `ObjectId`, `Width`, `Height`.
      - `AddPoint(Point2D point)`: `point` in 0..1 over the object; clamped into 0..1 (the validator refuses anything outside), then rounded to the pixel grid (`MapDrawing.CellPixels` per cell).
      - `RemoveLastPoint()`, `ClearShapeCommand`.
      - `Problem` (null when the outline is empty or has 3+ points).
      - `ToDefinition()`: the definition with the edited outline; throws `InvalidOperationException` with `Problem` when there is one (as `NewMapViewModel.ToMap` does).
    - `Objects/ObjectShapesWindow` (XAML + code-behind, no rules): a `Viewbox` holding a grid of the object's size in map pixels (`Width * MapDrawing.CellPixels`), with the picture (`MapDrawing.DrawObject`) and a `Canvas` for the outline; turns a click into a 0..1 point (`position / (cells * CellPixels)`) and keys into the view model's calls; OK sets `DialogResult` when `Problem` is null.
  - **Changes:**
    - `Catalogs/CatalogDraft.SetObject(ObjectDefinition definition)`: replaces the object with its id in `Current` (adds it if the id is new, E12b's first use); one undoable step (E4b); nothing when the record is equal.
    - `Objects/ObjectBrowserViewModel`: rebuilds `Objects` when `Current` changes and re-selects the chosen object by id, so the panel's preview and the ghost show the new record.
    - `Objects/ObjectPlacingViewModel`:
      - `StartEditingShapes()`: an `ObjectShapesViewModel` for the single selected placed object's definition, else the chosen object's, else null (the menu entry is disabled then);
      - `StartEditingShapesAt(Point2D point)`: for the placed object under a map point (the double-click), or null;
      - `ApplyShapes(ObjectShapesViewModel edited)`: `SetObject(edited.ToDefinition())`.
    - `Maps/CollisionDrawing`: its outline stroke and fill brushes become `internal static` so the shapes window draws with the same colors (one place per tunable).
    - `Shell/MainWindow`: the menu entry, the two double-clicks, opening the window and calling `ApplyShapes` on OK. Controls help (F1): a "Shapes window" section.
