# N2. NPCs in the editor: drawn, and a Talk preset

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "NPCs"; ADR 0015. Builds on N1 (field-sprite objects) and the existing event presets (`Events/EventPresets`).

- **N2. NPCs in the editor: drawn, and a Talk preset** (Editor, about 200 lines)
  - **Goal:**
    - Field-sprite objects draw on the editor's map, in the Objects panel's preview and as the placing ghost, with the game's standing frame (facing down), so a placed NPC looks as in the game.
    - The object events window offers a **Talk** preset beside Chest, Door and Sign: an Interact event with the prompt "Talk" and one Dialogue step, the speaker and lines left for the developer to type (as Sign leaves its text).
    - The shapes window opens on NPCs for their collision outline; the "Over the player" choice is greyed for them, with "NPCs have no above-player zones" (the validator refuses them, N1).
    - The collision overlay (E8) shows NPC outlines like any object's.
  - **Changes:**
    - `Tiles/TileImages.FieldSpriteFrameOf(string file)`: the standing frame's crop, cached per file (the frame's place from the same rule as the game: 48 px frames, the down row first frame; a named constant pair beside the tunables row, since the editor can't reference the game's `FieldSpriteFrame`).
    - `Maps/MapDrawing.DrawObject` and the map's object parts: a field-sprite object draws its frame over its cells; tile objects as today.
    - `Events/EventPresets.Talk(EventIdAllocation target)`: the Talk event (prompt "Talk", like the legacy presets' prompts).
    - `Events/ObjectEventsWindow` and its view model: the Talk preset button.
    - `Objects/ObjectShapesViewModel.CanEditZones`: false for a field-sprite object (`IsEditingZones` can't be set then).
    - Controls help (F1): the Talk preset.
  - **Tests:**
    - `EventPresetsTests`: `Talk_AnyObject_IsInteractDialogueWithTalkPrompt`, `Talk_AnyObject_LeavesSpeakerAndLinesEmpty`.
    - `ObjectShapesViewModelTests`: `CanEditZones_FieldSpriteObject_IsFalse`, `IsEditingZones_SetOnFieldSpriteObject_StaysFalse`.
    - `CollisionShapesTests`: `Of_FieldSpriteObject_PlacesItsOutline`.
  - **Verify by hand:**
    - [ ] Open `start`: the villager is drawn as in the game; the Objects panel previews it; placing another shows the ghost.
    - [ ] Place a second villager, give it the Talk preset, type a speaker and a line, Ctrl+S, F5: both talk, each with its own text.
    - [ ] Open the villager's shapes: the outline edits; "Over the player" is greyed with the reason.
- **From N1's review:** `Maps/Editing/PlacedObjectHits.CoversWithATile` decides a click hit from the object's tiles only, so a click can't select, move or remove a field-sprite object (only a Ctrl + drag rectangle selects it): treat a sprite object's whole cell area as hit.
