# N3. A new NPC

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "NPCs", "Tunables" (NPC placeholders); questions 129-132 (placeholders). Builds on N2 (NPCs drawn), E12b (`ObjectIds`), E9 (`SetObject`, the shapes window).

- **N3. A new NPC** (Data + Editor, about 220 lines)
  - **Goal:**
    - Objects > **New NPC...** asks for an **Id** (E12b's id rules) and a **Sprite** (every PNG in `content/art/field-sprites/`, `npc_placeholder.png` chosen by default; decision 69: NPCs share the placeholder until real art exists).
    - On OK: an object with that id, category "NPC", one cell (question 132), the chosen field sprite, and the default outline over the lower half of the cell (question 129) joins the catalog draft as one step (undoable unless placed, E12b's rule); the Objects tab shows it chosen, ready to place; the shapes window doesn't open (the default outline is usually right; Edit shapes is one click away).
    - Real art later: put the new sheet in `content/art/field-sprites/` (E7's import covers only tilesheets; field sprites are copied by hand for now) and either replace `npc_placeholder.png` (every NPC changes) or choose it for one NPC (question 131).
  - **Data:** `Art/ArtFolders.FieldSpriteImagesIn(string artRoot)`: the PNG file names in the field-sprite folder, sorted ordinally (as E5a's `TilesheetImagesIn`).
  - **New types:**
    - `Objects/NewNpcViewModel` (`ObservableObject`): the id and sprite chosen for a new NPC, and what stops them being used.
      - `NewNpcViewModel(IReadOnlyCollection<string> takenIds, IReadOnlyList<string> spriteFiles)`.
      - `Id`, `SpriteFile` (observable; the placeholder by default when listed), `IdProblem`, `ToDefinition()`.
    - `Objects/NewNpcWindow` (XAML + code-behind, no rules): the id, the sprite list with the frame's preview, OK and Cancel.
  - **Changes:**
    - `Shell/MainViewModel`: `StartNewNpc()`, `CreateNpc(NewNpcViewModel newNpc)` (`SetObject`, chooses it in `Placing.Browser`, sets `Mode` to Objects).
    - `Shell/MainWindow`: the menu entry and the dialog. Controls help (F1): New NPC.
  - **Tests:**
    - `ArtFoldersTests` (Data): `FieldSpriteImagesIn_RepositoryArt_ListsPlayerAndPlaceholder`.
    - `NewNpcViewModelTests`:
      - `SpriteFile_PlaceholderListed_IsChosenByDefault`;
      - `IdProblem_IdTaken_SaysSo`;
      - `ToDefinition_AnyId_IsOneCellNpcWithLowerHalfOutline`.
    - `MainViewModelTests`: `CreateNpc_NewId_AddsItAndChoosesIt` (saved into a temporary content copy and loaded back).
