# 0. Content tests assert entries, not totals

Part of [the demo retirement plan](../README.md). Design: [design.md](../design.md), "What exists" (failing tests); rule in `.claude/rules/tests.md` (last line).

- **0. Content tests assert entries, not totals** (Data + Editor tests, about 50 lines)
  - **Goal:** `main` is green again. The five tests that pin totals of repository content assert the entries they need, so content edits made in the editor no longer break them. No production code changes.
  - **Changes (tests only):**
    - `tests/Jrpg.Data.Tests/Content/ContentCatalogLoaderTests.cs`:
      - `Load_RepositoryContent_LoadsEveryTile` (pins 283 tiles) is deleted. The loader already refuses a map that uses an unknown tile (`MapLayoutValidator`), and that rule has its own tests. Tile walkability is covered by `CatalogDraftTests`.
      - `Load_RepositoryContent_LoadsObjectsWithTileGroupSizes` (pins 13 objects) becomes `Load_RepositoryContent_TreeHasItsTileGroupSizeAndOutline`. The `Objects.Count` assert goes; the `tree` size and outline asserts stay.
    - `tests/Jrpg.Editor.Tests/Objects/ObjectBrowserViewModelTests.cs`: `Objects_RepositoryContent_SortedByCategoryThenId` (pins the whole list) becomes `Objects_TwoCategories_SortedByCategoryThenId`. It uses the repository catalog with `Objects` replaced by four definitions in two categories, given out of order (`catalog with { Objects = ... }`), and asserts their order.
    - `tests/Jrpg.Editor.Tests/Shell/MainViewModelTests.cs`:
      - `LayerEntries_ChosenZWithoutLayer_ListsItAsEmpty` and `LayerEntries_PaintedOnEmptyZ_DropsTheEmptyMark` keep Z 2. Each first asserts, as a precondition, that the opened map has no layer at Z 2 (`Assert.DoesNotContain(..., layer => layer.Z == 2)`), so a content change that adds one fails loudly instead of silently testing nothing.
      - Then they assert only the Z 2 entry: `"Layer (z 2), empty"` is among the entries; or `"Layer (z 2)"` is there and `"Layer (z 2), empty"` isn't. They no longer assert the whole list.
    - `docs/plans/backlog.md`: remove the line "Three tests pin repository content totals" (done).
  - **Tests:** the four kept above pass on today's content, and each fails if its entry disappears or its rule breaks.
  - **Verify:**
    - [x] `verify.ps1`: every step passes, 0 failed tests.
    - [x] No test in `tests/` asserts the size of a whole repository catalog or map.

Now `ComposesTheThreeLiveMaps` drops the start map's 56-object count and the exact map set (it checks the three maps are there). `ListsMapsAndOpensTheFirst`, `MapEntries_..._SortedByName` and `LayerEntries_MapWithTwoLayers_...` assert their known entries, in order, among whatever else is listed. `RepositoryNewGameTests` keeps its 7 party members: that's the new-game party, not a catalog the editor writes.
