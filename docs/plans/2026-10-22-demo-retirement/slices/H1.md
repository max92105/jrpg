# H1. The footer hint line

Part of [the demo retirement plan](../README.md). Design: [design.md](../design.md), "Gap survey" (game screens), key decision 4; tunables "footer hints" and "footer hint text". From the plan review; the developer can strike it (README, "Slices").

- **H1. The footer hint line** (Game + content, about 180 lines)
  - **Goal:**
    - The game menu's footer bar, empty today, shows one line of help.
    - On the main menu it reads "Choose a menu."; on a page, that page's hint.
    - A page can change its hint while the player works in it, and the footer follows. Q2 uses this for its take hint.
    - The footer's look stays as it is: the text uses the existing secondary text style, so this needs no separate look slice.
  - **Changes:**
    - `Menus/IMenuPage.Hint` (`string`, read-only): the page's current footer line, already formatted. It changes only when the page's state does, so reading it allocates nothing.
    - `Menus/GameMenuScene`:
      - draws `Hint` of the open page, or the main menu's hint, left-aligned in the footer (tunable);
      - re-measures only when the string changes by reference (`Ui/MeasuredText`).
    - Each page returns its hint (from its constructor's `UiMessages`): `StatusPage`, `InventoryPage`, `EquipmentPage`, `PartyPage`, `OptionsPage`, `SavePage`, `LoadPage`, `SystemPage`.
    - `Ui/MessageIds` and `content/text/ui.json`: `menu_hint_main`, `menu_hint_status`, `menu_hint_inventory`, `menu_hint_equipment`, `menu_hint_party`, `menu_hint_options`, `menu_hint_save`, `menu_hint_load` (tunable wording, placeholders).
  - **Tests:**
    - `GameMenuSceneTests`:
      - `Hint_NoPageOpen_IsTheMainMenuHint`;
      - `Hint_PageOpen_IsThePagesHint`;
      - `Hint_PageClosed_GoesBackToTheMainMenuHint`.
      (Through an internal read accessor `FooterHint`, if the scene has no other seam.)
    - One per page that changes its hint later (none yet; Q2 adds Equipment's).
    - `MessageIdsTests` (existing): passes with the new ids.
  - **Verify by hand:**
    - [ ] Open the menu: "Choose a menu." in the footer. Open each tab: its hint. Close the page: back to the main hint.
    - [ ] The text sits inside the footer bar, clear of the hairline, at 1080p and windowed small.
