# Q1. Core: what can be taken from whom, and taking it

Part of [the demo retirement plan](../README.md). Design: [design.md](../design.md), "Core changes", key decision 6; tunables "who can give an item up" and "the receiver's own item"; ADR 0003; decision 137.

- **Q1. Core: what can be taken from whom, and taking it** (Core, about 170 lines)
  - **Goal:**
    - Core lists, for a member and a slot, every item another member wears there that this member could wear, one entry per wearer.
    - Core moves such an item from its wearer to the member in one step.
    - Nothing calls this yet; Q2 does, at the end of the same phase.
  - **New types:**
    - `Party/WornItem` (public sealed record): one item worn by one member.
      - `WornItem(PartyMember Wearer, ItemDefinition Item)`.
  - **Changes:**
    - `Party/PartyEquipment.TakeableFor(PartyMember member, EquipmentSlot slot, PartyState party)` returns `IReadOnlyList<WornItem>`:
      - for each member of `party.Members` other than `member`, active or reserve, in that order, their item in `slot`;
      - kept when `member`'s class can wear it and it isn't the item `member` already wears in that slot (same id).
    - `Party/PartyEquipment.TryTakeFrom(PartyMember giver, PartyMember receiver, EquipmentSlot slot)`:
      - moves the giver's item in `slot` to the receiver, and the receiver's own item there, if any, to the bag;
      - the giver's slot is left empty;
      - returns false and changes nothing when the giver is the receiver, the giver's slot is empty, the receiver's class can't wear the item, or the bag has no room for the receiver's item;
      - `PartyMember.Wear`/`TakeOff` stay internal.
  - **Tests:**
    - `PartyEquipmentTests`:
      - `TakeableFor_TwoOthersWearIt_ListsOneEntryPerWearer`;
      - `TakeableFor_ReserveMemberWearsIt_ListsThem`;
      - `TakeableFor_ClassCantWearIt_LeavesItOut`;
      - `TakeableFor_MemberAlreadyWearsIt_LeavesItOut`;
      - `TakeableFor_OtherSlot_LeavesItOut`;
      - `TakeableFor_InPartyOrder_ActiveThenReserve`;
      - `TryTakeFrom_GiverWearsIt_MovesItAndEmptiesTheGiversSlot`;
      - `TryTakeFrom_ReceiverWearsSomething_PutsItInTheBag`;
      - `TryTakeFrom_NoRoomForReceiversItem_ChangesNothing`;
      - `TryTakeFrom_ReceiverClassCantWearIt_ChangesNothing`;
      - `TryTakeFrom_GiverSlotEmpty_ReturnsFalse`;
      - `TryTakeFrom_SameMember_ReturnsFalse`.
  - **Verify by hand:** none (Core only).
