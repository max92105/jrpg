Part of [the demo retirement plan](../README.md). Design: [design.md](../design.md), key decision 8 (wording rules); decision 135.

- **W2. Game `Ui/`** (Game + Game tests; 151 lines in 17 files; about 120 lines changed)
  - **Goal:** no line in `src/Jrpg.Game/Ui` or `tests/Jrpg.Game.Tests/Ui` has the word. `UiTheme` still says what each value is for, without pointing to demo files.
  - **Files** (lines): `UiTheme` 119, `UiTextures` 5, `MemberCardView` 4, `PointedBarShape` 3, `StatBar` 3, `Vignette` 2, `SectionTitle` 2, `OutlinedShape` 2, `ConfirmPromptView` 2, and 1 each in `ConfirmPrompt`, `PlayTimeText`, `GradientStrip`, `CommandHeaderShape`, `OutlinedFont`, `DiamondShape`, `NavTabShape`; `UiThemeTests` 2.

    - `UiTheme`:
      - the class comment becomes "The UI's colors and sizes in one place (decision 82), so screens look alike and change together."

      - Size comments keep their arithmetic ("16, doubled like the box") without the file name.

    - `UiThemeTests.BarLine_LegacyWhiteAt40Percent_IsPremultiplied` becomes `BarLine_WhiteAt40Percent_IsPremultiplied`.
    - `UiThemeTests.NavFill_LegacyArgb_IsPremultipliedInChannelOrder` becomes `NavFill_StraightArgb_IsPremultipliedInChannelOrder`.
  - **Tests:** none new; everything passes unchanged apart from the renames.
