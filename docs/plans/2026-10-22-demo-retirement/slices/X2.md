# X2. The guard: `verify.ps1` fails on the word

Part of [the demo retirement plan](../README.md). Design: [design.md](../design.md), key decision 9, risks ("The guard's false positives", "A stale exception"); decisions 134, 136.

- **X2. The guard** (script + docs; about 45 lines)
  - **Goal:**
    - `verify.ps1` gains a step, "no retired word outside history". It fails when the word appears, case-insensitive, in a checked file's text or in a checked file or folder name. It names each hit (`path:line` for text, the path for a name).
    - `/verify`, `/slice` and the Stop hook get it, since they run the script.
  - **Changes:**
    - `.claude/scripts/verify.ps1`, step 6, after the naming step. It runs even when the build failed, as steps 4 and 5 do.
      - **The pattern is built in pieces** (`$retired = 'leg' + 'acy'`), so the script doesn't contain the word and needs no exception for itself. A comment says why.
      - **Checked roots** (one array):
        - `src`, `tests`, `content`, `docs`, `.claude`;
        - the root files `CLAUDE.md`, `README.md`, `AI-SETUP.md`, `.editorconfig`, `.gitignore`, `.gitattributes`, `Directory.Packages.props`, `Jrpg.slnx`, `Jrpg.slnLaunch`, `global.json`.
      - **Skipped history** (one array, each entry with its reason):
        - `docs/plans/done/` (finished plans);
        - `docs/plans/2026-10-22-demo-retirement/` (this plan, until it moves to `done/`; remove the entry then);
        - the ADRs written before the decision, by file name, not a wildcard, so ADR 0016 on is checked:
          `docs/decisions/0001-engine-free-architecture.md`, `0002-content-schema-mapping.md`, `0003-equipment-ownership-model.md`, `0004-battle-command-flow.md`, `0005-map-content-source-of-truth.md`, `0006-map-event-flow.md`, `0007-save-format-and-versioning.md`, `0008-game-shell-structure.md`, `0009-art-location-and-asset-loading.md`, `0010-player-facing-text.md`, `0011-content-after-the-converter.md`, `0012-editor-architecture.md`, `0013-battle-presentation-and-playback.md`, `0014-editing-shared-catalogs.md`, `0015-npcs-on-maps.md`.
      - **Always skipped:** `bin/`, `obj/`, and binary files (`*.png`, `*.ttf`, `*.dll`, `*.jpg`; the reference screenshots in `docs/ui_ux_exemples/` too).
    - `CLAUDE.md`, Commands: "All checks at once (build, tests, format, Core and naming rules, no retired word outside history; one line per check)".
    - The removal of this plan's skip entry at the retro is already a checkbox in [Z.md](Z.md).
  - **Tests:** the script has no test project. Checked by hand below.
  - **Verify by hand:**
    - [ ] `verify.ps1` on the clean tree: the new step passes.
    - [ ] `Select-String -Path .claude/scripts/verify.ps1 -Pattern legacy`: no output (the pattern is built in pieces).
    - [ ] Add a comment with the word to a file in `src/Jrpg.Core`: the step fails, naming the file and line. Remove it.
    - [ ] Create an empty folder `tests/Legacy`: the step fails, naming the folder. Remove it.
    - [ ] Create `docs/decisions/0016-test.md` containing the word: the step fails. Remove it.
    - [ ] The word in a file under `docs/plans/done/`: the step passes.
    - [ ] `verify.ps1` takes under a second longer than before.
