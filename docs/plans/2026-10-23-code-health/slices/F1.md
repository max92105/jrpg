# F1. A re-cut lets go of a chosen cell past the new grid

Part of [the code health plan](../README.md). Design: [design.md](../design.md), backlog survey ("Re-cut to a smaller grid"); README, "Proposed by the architect" (let go, not clamp).

- **F1. A re-cut lets go of a chosen cell past the new grid** (Editor, about 60 lines)
  - **Write first, and see it fail:** `ApplyCutCommand_ReCutSmallerThanChosenCell_LetsTheChoiceGo`.
  - **Goal:**
    - A chosen cell or rectangle that a re-cut (or its undo or redo) leaves outside the sheet's grid is let go, as when the sheet itself is gone. Painting can then no longer make a tile outside the image, which the save would refuse.
    - A choice the new grid still holds is kept.
  - **Changes:**
    - `Tiles/TileBrowserViewModel`:
      - the grid check inside `CellAt` (`column >= 0 && row >= 0 && column < sheet.ColumnsIn(width) && row < sheet.RowsIn(height)`) becomes one private method, `IsInGrid(TilesheetDefinition sheet, int column, int row)`, which reads the size through `_images.SizeOf`;
      - `CellAt` and `ListSheetsAnew` both use it;
      - after its sheet-gone check, `ListSheetsAnew` lets go of `SelectedCell` and `SelectedCells` when the shown sheet's grid no longer holds the chosen cell or the rectangle's far corner.

      `SheetGrid` stays in the backlog ("When next touched").
    - `docs/plans/backlog.md`: remove the "Re-cutting a sheet to a smaller grid leaves..." line.
  - **Tests** (`TileBrowserViewModelTests`; each starts from a choice the old grid holds, per the refresh rule):
    - `ApplyCutCommand_ReCutSmallerThanChosenCell_LetsTheChoiceGo`;
    - `ApplyCutCommand_ReCutSmallerThanChosenRectangle_LetsTheRectangleGo`: its top-left stays inside and its far corner falls outside;
    - `ApplyCutCommand_ReCutStillHoldingChosenCell_KeepsIt`;
    - `Undo_ReCutThatGrewTheGrid_LetsGoOfACellInTheNewArea`: through `_draft.Undo()`.
  - **Verify by hand:**
    - [ ] Choose a cell near the bottom right of a sheet, Cut it with larger tiles, Apply: nothing is chosen, and painting on the map shows the "choose a tile" hint.
    - [ ] Choose a cell near the top left and re-cut the same way: the choice stays.
- **Done, with deviations:** as planned. The re-cut check lives in a private `IsChoiceInGrid` beside `IsInGrid`, folding in the existing sheet-gone check. `TileBrowserViewModel` is now 310 lines; its `SheetGrid` split stays in the backlog ("When next touched"). `ApplyCutCommand_ReCutStillHoldingChosenCell_KeepsIt` passed before the fix, as a keep-test should. Review: `IsChoiceStillCut` renamed `IsChoiceInGrid` (the class also has a Cut panel); a fifth test covers redo.
