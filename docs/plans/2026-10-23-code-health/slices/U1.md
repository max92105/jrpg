# U1. Whole numbers formatted in one place

Part of [the code health plan](../README.md). Design: [design.md](../design.md), backlog survey ("Private `Number(int)` copied", "More inline invariant formatting"), replacement mapping.

- **U1. `NumberText` and `MessageArgument.Number`** (Game, about 120 lines)
  - **Goal:**
    - Every whole number the Game shows is written through one place, the same on every machine.
    - The five private `Number` copies, `FoundItemText.Count` and the inline `ToString(CultureInfo.InvariantCulture)` calls go.
    - What the player sees is unchanged.
  - **New types:**
    - `Ui/NumberText` (static, pure): whole numbers written the same on every machine (invariant culture).
      - `static string Of(int value)`.
  - **Changes:**
    - `Ui/MessageArgument`: `static MessageArgument Number(string name, int value)`, for a placeholder filled with a number.
    - Callers:
      - `Of`: `EquipmentSheet`, `StatPreviewText`, `StatusPage`, `SaveSlotListView`, `MemberCardView`, `FoundItemText`, `InventoryPage.RowOf`, `EquipmentChoiceView`, `ActionPlayback`, `VictoryScreenView` (reward value, level, experience), `VitalsText`;
      - `MessageArgument.Number`: `VitalMeter`, `ItemUseDialog`, `PartyColumnsView`, `SavePage`, `CommandPanelView`, `VictoryScreenView` (needed), `VitalsText`.

      Afterwards, Grep `CultureInfo.InvariantCulture` and `static string Number(` in `src/Jrpg.Game`. The expected hits are:
      - `Ui/NumberText`;
      - `Saving/SaveSlots.cs:22` (the slot file name, `string.Create` with a format);
      - `Saving/SaveSlotListView.cs:94` (the save date with `DateFormat`).

      Neither of the last two is a whole number, so both stay.
    - `docs/map.md`: Ui row lists `NumberText`.
    - `docs/plans/backlog.md`: remove the `Number(int)` line and the "More invariant number formatting inline" line.
  - **Tests:**
    - `NumberTextTests`:
      - `Of_NegativeUnderSwedishCulture_UsesTheAsciiMinus`: sv-SE formats the minus as U+2212 under the current culture. Set and restore `CultureInfo.CurrentCulture` in the test.
      - `Of_Thousands_HasNoSeparator`.
    - `MessageArgumentTests`:
      - `Number_NegativeUnderSwedishCulture_UsesTheAsciiMinus`.
    - Existing view and presenter tests pass unchanged.
  - **Verify by hand:**
    - [ ] Before/after screenshots (`.claude/scripts/play-game.ps1`) of the Status and Inventory pages show the same numbers.
