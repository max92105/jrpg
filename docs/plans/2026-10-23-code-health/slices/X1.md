    The small test map is shared, so new tests start from it. The test count of `Jrpg.Core.Tests` is the same before and after; record both.

    - `ExplorationInteractionTests`: the eight `InteractionInFront_*` tests.
    - `ExplorationTouchEventTests`: the seven `Walk_*` tests.
