# A1a2. The editor authors the voice step; the intros start with the voice

Part of [the new-game flow plan](../README.md). Design: [design.md](../design.md), "Content format". ADRs 0016, 0018. Split from A1a at the size check. A1a1 adds the step and its startup check.

- **A1a2. The editor authors the voice step; every intro starts with the placeholder voice** (Editor + content, about 60 lines; decision 160)
  - **Goal:**
    - In the event dialog, "Voice" is a step kind with a file field.
    - Each leader's intro starts with the placeholder voice. The content change comes with the editor support, so the editor never meets a step it can't open.
  - **Changes:**
    - Editor: `EventStepKind.Voice` with a file field, its `From`/`ToStep` cases, its problem (a blank file) and its label ("Voice: Placeholder.wav"); an add button in both event windows.
    - Content `content/map-layouts/intro.json`: every intro event starts with `{ "type": "voice", "file": "Placeholder.wav" }`.
  - **Tests:**
    - `EventStepViewModelTests`: `From_VoiceStep_KeepsTheFile`, and a voice step in the every-kind round trip.
    - `RepositoryNewGameTests`: every leader's intro starts with a voice step.
  - **Verify by hand:**
    - Renaming the file to `placeholder.wav` stops the start, naming both spellings.
    - The editor opens the intro map and shows the voice step.
