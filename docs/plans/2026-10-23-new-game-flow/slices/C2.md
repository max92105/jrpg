# C2. The nine characters

Part of [the new-game flow plan](../README.md). Design: [design.md](../design.md), "Tunables and placeholders" (leader choices, new characters, their art, summaries).

- **C2. The nine characters: Ragnir, Omer and Lazarus added, Kamilia removed, Teelle the Paladin, Thaali the Druid, summaries, generated portraits** (Core + Data + content, about 220 lines; decisions 161, 162, 166, 167; questions 182, 183)
  - **Goal:**
    - The nine characters exist with their classes, each with a placeholder summary.
    - The choice lists them in order: Ragnir, Omer, Zanyr, Lazarus, Jazog, Teelle, Zaruk, Sarxian, Thaali.
    - Every choice has an intro event on the `intro` map.
    - Kamilia is gone.
  - **Changes:**
    - Core `Party/PartyMemberDefinition`: `required string Summary` ("who the character is, shown when choosing a leader").
    - Data `Party/PartyMemberCatalogValidator`: `summary must not be empty.`
    - Content:
      - `party-members.json`:
        - `ragnir` (warrior), `omer` (mage), `lazarus` (rogue) added;
        - `kamilia` removed;
        - a `summary` for all nine.
      - `art/portraits/` and `art/battlers/`: `Ragnir.png`, `Omer.png`, `Lazarus.png`.
        - 256 px squares, made once by a PowerShell `System.Drawing` script (a flat class color with the initial). Record the command in the Done note.
        - Check the battler size rule in `ArtReferenceCheck` first; if battlers must be larger, generate at that size.
        - `Kamilia.png` stays unused (question 183).
      - `new-game.json`: `leaderChoices` in the order above, each with its intro.
      - `content/maps/intro`: an intro event for Ragnir, Omer and Lazarus, like the others; Kamilia's removed if she had one.
    - Tests:
      - `PartyMemberBuilder` gets a default summary.
      - `StatusPageTests` stops using Kamilia.
      - `StartMapScenarios.StartWithWholeParty` (L1) lists her among its recruits: remove her there too.
      - Any test that counted members or named Kamilia picks another member.

The script uses `System.Drawing`: Ragnir is red R, Omer blue O, Lazarus grey L. It was kept in the session scratchpad, not the repository.
  - Ragnir, Omer and Lazarus's intros sit on cells (0..2, 1) of the 6x3 intro map. The empty-summary check is a row in the existing invalid-field theory rather than its own test. No save test was added: `SaveGameRepairTests.Repair_UnknownMember_DropsItFromMembersAndActiveOrder` already covers a removed member.
  - `StartWithWholeParty` now recruits the three new characters too. Without them the sidebar no longer scrolls. Two cursor tests now move 4 members to the active party instead of 3, so the reserve stays shorter than the cursor's row. Tests: 1735 before, 1737 after.
