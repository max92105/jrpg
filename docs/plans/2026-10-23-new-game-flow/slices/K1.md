# K1. An event can run when the player arrives on its map

Part of [the new-game flow plan](../README.md). Design: [design.md](../design.md), "The intro as a map cutscene". ADR 0016 (option B).

- **K1. An event can run when the player arrives on its map, only when a given character leads** (Core + Data, about 200 lines; decision 185)
  - **Goal:**
    - A map event with `"activation": "arrive"` runs as soon as the player is on its map: at a new game's start, after a warp, after a load.
    - An event with `"onlyWhenLeaderId": "omer"` runs only while Omer leads. The condition applies to every activation, like `onlyWhenObjectId`.
    - A "once" arrival event runs once per playthrough. A non-once one runs on every arrival.
  - **Changes (Core):**
    - `Events/EventActivation.Arrive`: "the player arrives on the map (a new game, a warp, a load); the cutscene trigger."
    - `Events/MapEvent.OnlyWhenLeaderId` (`string?`): "when set, the event only runs while this member leads, such as each leader's intro."
      - `CanRunOn` gains the leader: `CanRunOn(string objectId, string leaderId)`. Callers pass the party's leader.
    - `Exploration/ExplorationContext` gains what the leader check needs, the party (or the leader's id). `GameSession` passes it.
    - `Exploration/ExplorationState`:
      - on entering a map (constructor and warp landing), finds the first runnable arrival event, objects first then cells, in map order, and starts it as `EventRun` does for touch;
      - `InteractionFinder` (or a small `ArrivalFinder` beside it, if the finder's search doesn't fit) returns it.
  - **Changes (Data):**
    - The JSON enum reads `arrive`. `MapEventValidator` checks that `onlyWhenLeaderId` is a known member.
    - `MapEventValidator` refuses an arrival event with a prompt, since a prompt only means something for Interact.
  - **Tests:**
    - `ExplorationStateTests` (a test map from `TestExplorationMap`):
      - `Start_MapWithArrivalEvent_RunsIt`
      - `Start_ArrivalEventForAnotherLeader_DoesNotRun`
      - `Warp_OntoMapWithArrivalEvent_RunsItAfterLanding`
      - `Restore_OnceArrivalEventDone_DoesNotRunAgain`
    - `MapEventTests.CanRunOn_OtherLeader_IsFalse`
    - `MapEventValidatorTests`: theory rows for an unknown `onlyWhenLeaderId` and a prompt on an arrival event.
  - **Verify by hand:** none yet. Nothing in content uses it before K3. The editor can't open a map with one until K2b, and none exists.
