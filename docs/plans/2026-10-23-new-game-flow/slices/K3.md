# K3. The intro map

Part of [the new-game flow plan](../README.md). Design: [design.md](../design.md), "The intro as a map cutscene", "Tunables and placeholders" (intros). ADR 0016, decision 185.

- **K3. The intro map: a new game starts there, each leader's intro plays, then a warp to the start map** (content + Data + tests, about 150 lines; decisions 159, 173, 174, 185)
  - **Goal:**
    - Every new game starts on a small `intro` map.
    - On arrival, the leader's intro event runs: three placeholder stills of 4 s with captions, then a warp to the start map's start cell.
    - Skipping still warps.
    - This is the first full run: title, choice, "Begin as X?", intro, start map.
  - **Changes:**
    - Content:
      - `content/maps/intro` (settings and layout): a small map of one dark, walkable tile, made with the editor (it knows the steps after K2b), or by hand if quicker. Check the JSON diff.
      - One placed object, or one cell, holding one arrival event per leader choice. Each event is "once", has `onlyWhenLeaderId`, and holds three still steps captioned "{Name}'s intro, still n (placeholder)", then a warp to `start` (10, 3).
      - `new-game.json` `startLocation`: the `intro` map.
    - The start position and facing on `start` are the warp's, so play begins where it did before.
    - Data: nothing new, unless the intro map shows a gap in validation.
  - **Tests:**
    - `RepositoryNewGameTests`:
      - `StartNew_RepositoryContent_EveryLeaderHasAnIntroOnTheStartMap`: each leader choice has exactly one arrival event on `intro` gated on them.
      - `StartNew_RepositoryContent_StartsOnTheIntroWithTheLeadersIntroRunning`
      - `StartNew_RepositoryContent_SkippedIntroWarpsToTheStartMap`
    - Tests that assumed a new game starts on `start` use their own start location (`StartMapScenarios` already does). Fix the ones that read the repository's `startLocation`.
  - **Verify by hand:**
    - New Game, choose Zanyr, Yes: three stills fade in and out with captions, then the start map.
    - Confirm during a still skips to the start map.
    - The menu's play time after the intro includes it (decision 174).
