# ADR 0019: Class battle resources

Part of [the class mechanics plan](../README.md). Design: [design.md](../design.md), "Key design decisions" 1 and 2, "When things happen in a turn".

- **ADR 0019: Class battle resources** (checkbox step before M1a; write with `/adr`)
  - **Question:** how is a class's battle resource defined, and how does it change? Each class plays differently (decisions 188-206), and the developer will keep changing the rules while play-testing.
  - **Options:**
    - A. mechanisms in code, numbers in content (recommended):
      - a class lists resources with a max, a starting amount and gains on a closed set of triggers (per turn, per hit taken, per hit landed, per heavy hit, per enemy fallen, per ally fallen; later per battle fought);
      - skills spend, gain or require them;
      - special rules (backfire, dominance, readiness from speed, strain) are switched on by optional fields.
    - B. a shared meter plus per-class rule hooks: one meter type, and one small rule class per class, chosen by a content id, reacting to battle hooks. Each class's rule reads in one file, and odd rules (backfire, sticky dominance) are natural there.
    - C. scripted triggers in content.
  - **Why A over B** (record it): seven of the nine resources are the same meter on the same few triggers with different numbers, so B's nine rule classes would mostly repeat each other. With A, the developer changes a trigger amount in JSON while play-testing; with B every such change is code. B's strength, odd rules, is kept in A by small rule records with their own formulas.
  - **Record with the decision:**
    - A new trigger is a code change with a test; code never names a class or resource id.
    - Per-turn things happen at the end of the holder's own turn. That's once per round in today's turn order, and the battle's constructor stays silent.
    - Resources live in `ResourceMeters` on the `Combatant`, built for every battle. Lasting resources (ADR 0024) are the exception.
    - `ResourceChanged(Combatant Holder, string ResourceId, int Change)` is the event; the HUD reads live amounts (ADR 0013).
  - **Done when:** `docs/decisions/0019-class-battle-resources.md` is accepted by the developer and indexed in `docs/decisions/README.md`.
