# ADR 0025: Font roles

Part of [the UI second pass plan](../README.md). Before T1. Extends ADR 0009 (TTF fonts through FontStashSharp). Decision 250.

(The drafted ADR 0025 on reference material was dropped at approval: decision 264 and a rule line replace it.)

- [x] **Write ADR 0025** with `/adr`, from the README's "ADRs" entry: A (a subfolder per role, recommended), B (`fonts.json` naming a file per role), C (a file-name prefix).
  - **Records (A):**
    - `content/art/fonts/*.ttf` stays the body font and its fallbacks, in file-name order (today's rule).
    - `content/art/fonts/titles/*.ttf` is the title face: Cormorant Garamond SemiBold (SIL Open Font License, Google Fonts; decision 250), its `OFL.txt` beside it. It is loaded as a second font system whose fallbacks are the body files, so a character it lacks still shows.
    - Both folders must hold a font: a missing or broken one stops the start with the folder or file named (`ContentValidationException`).
    - `FontLibrary.FontAt(pixels)` is the body, `FontLibrary.TitleFontAt(pixels)` the title; screens pick by role, never by file. No bold header role; damage numbers stay in the body font (decision 250).
  - **Consequences:** a third role is a third subfolder and a method; changing the serif is a file swap.
  - Add its line to `docs/decisions/README.md`.
- **Done, with deviations:** written as accepted, since the developer approved the plan with option A and decision 250's font. Docs only, so no review or verify.
