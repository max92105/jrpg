# C5. `InventoryPage` split: `InventoryRow` and `InventoryListView`

Part of [the UI second pass plan](../README.md). Design: [design.md](../design.md), "Replacement mapping", "Clean-up selection". Right before MO2b, the first slice that changes the item list. The line under the list (`ItemDetailLine`) arrives in M4, which changes it.

- **C5. `InventoryPage` split: `InventoryRow` and `InventoryListView`** (Game, mostly moved, about 200 lines)
  - **Goal:** `Menus/InventoryPage` (328 lines) keeps its input (rail, list, item use), the notice and its page contract; the row data and the list's drawing move out.
  - **New types:**
    - Game `Menus/InventoryRow` (internal sealed record): one item line as the inventory shows it: item id, name, icon file, quantity text and width, description, usable. Today's private `ItemRow`.
    - Game `Menus/InventoryListView` (internal sealed): draws the inventory's visible rows, its selection and its empty line. Today's `DrawList` and `DrawRow` with their fonts and row constants; `InventoryLabels` (the empty line and its width) moves with it, its width through `Ui/MeasuredText` (backlog). The description and notice drawing stays in the page until M4.
  - **Changes (Game):** `InventoryPage` builds rows (`RowOf`) and hands the list view the rows, the cursor and whether the list has the cursor. Remove the A2 part of the `InventoryPage` backlog line (the notice part stays for M4). `docs/map.md`, Menus line: `InventoryRow`, `InventoryListView`.
  - **Tests:** none new; `InventoryPageTests` and `InventoryPageRestItemTests` pass unchanged. Record the solution's test count before and after (equal).
  - **Verify by hand:** the Items page looks and behaves as before (F12, compare with the capture after SZ1).
- **Done, with deviations:**
  - **Line counts:** `InventoryPage` is 271 lines (from 328), `InventoryListView` 97 and `InventoryRow` 9.
  - **The heading and column titles stay in the page**, with the notice and description. The view owns only the rows and the empty line, and gives the page the constants it lines up with (`VisibleRows`, `RowInset`, `NameLeft`, `QuantityInset`, `Height`). `InventoryLabels` is gone: the empty line is a `MeasuredText` in the view, and the page measures a quantity through `InventoryListView.MeasureQuantity`, and takes the description's size from `InventoryListView.BodyPixels` (after review).
  - **Tests:** 2138 before and after, with no test changed.
