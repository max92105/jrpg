# M4. Inventory look

Part of [the UI second pass plan](../README.md). Design: [design.md](../design.md), "Tunables and placeholders" (inventory columns). After MO2b. Look at `docs/ui-reference/menu-inventory-description.webp` (the description in a dark strip under the selected row, the column titles), `menu-inventory-target.webp` and S0's Items captures first.

- **M4. Inventory look: column titles, the description under the selected row** (Game, about 210 lines)
  - **Goal:**
    - Over the list, two column titles in spaced caps ("ITEM", "QTY") with the hairline `Ui/ColumnTitles` draws on the Equipment page.
    - The selected item's description shows in a dark strip right under its row (at the glide's position), over the rows below; near the list's bottom it shows above the row. A use's notice shows in the same strip until the player moves on.
  - **New types:** Game `Menus/ItemDetailLine` (internal sealed): the strip under the selected item: the last use's notice until the player moves on, otherwise the item's description. The rest of the backlog's `InventoryPage` line.
    - `void ShowNotice(string notice)`, `void ClearNotice()`, `string TextFor(InventoryRow? selected)`, `static int TopFor(Rectangle selectedRow, int listBottom, int lineHeight)`.
  - **Changes:**
    - `Menus/InventoryPage`: its `_notice` becomes an `ItemDetailLine`; `Notice` reads it (tests use it). Remove the rest of the `InventoryPage` backlog line.
    - `Menus/InventoryListView`: the column titles and the strip (`UiTheme.CommandHintFill`, the battle's description box color, so both tips match).
    - `content/text/ui.json` and `Ui/MessageIds`: `inventory_column_item`, `inventory_column_quantity`.
    - `docs/map.md`, Menus line: `ItemDetailLine`.
  - **Tests** (`ItemDetailLineTests`):
    - `TextFor_NoNotice_IsTheSelectedDescription`
    - `TextFor_AfterShowNotice_IsTheNotice`
    - `TextFor_AfterClearNotice_IsTheDescriptionAgain`
    - `TopFor_RowWithRoomBelow_IsUnderTheRow`
    - `TopFor_LastVisibleRow_IsAboveTheRow`
  - **Verify by hand:** move through a long category: the strip follows the selection, flips above the last rows, never leaves the list; with the cursor on the rail, the strip dims like the row; using a potion shows its notice in the strip. Compare with `menu-inventory-description.webp`.
- **Done, with deviations:**
  - **Column titles already existed** ("Name", "Qty"). `Ui/ColumnTitles` now draws every list's captions in spaced caps (2 px letter spacing), so the item choice and the save list match too (decision 252); `ColumnTitle` takes the plain caption. `inventory_column_name` ("Name") is renamed `inventory_column_item` ("Item"), which the item choice shares.
  - **The strip** runs from just left of the name column to the list's right edge, in `UiTheme.CommandHintFill` over the highlight hairline, like the battle's description box. With the category empty, a use's notice takes the empty line's place in a strip.
  - **`ItemDetailLine.TextFor` returns null** when there is neither a notice nor a selected item. 7 tests (`TextFor_NothingSelectedAndNoNotice_IsNull` and the boundary `TopFor_RowExactlyFillingTheRoomBelow_IsUnderTheRow` added); 2153 in the solution. The `InventoryPage` backlog line is gone.
