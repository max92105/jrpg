# R2. The export index

Part of [the UI second pass plan](../README.md). Decisions 231-233, 264. Design: [design.md](../design.md), "Reference material".

- **R2. The export index: 2-4 named files per screen and the idea to take** (docs, about 60 lines)
  - **Goal:** `docs/ui-reference/export-index.md` tells a look slice which few export files show its screen's pieces, and the idea to take from each. Nothing is copied anywhere.
  - **Steps:**
    1. For each screen of design.md's table, list its export subfolder's `Texture` folder on its own (one Glob per folder; never the whole export; `Common/Texture` holds about 325 files: list it by prefix, `UiTX_Common_Dialog*`, `UiTX_Common_List*`, `*Footer*`, `*Header*`).
    2. Open a few candidates (Read shows a PNG) and keep 2-4 per screen.
    3. Write the page: a header paragraph (where the export is, the reference-only rule, "list one subfolder at a time"), then one short section per screen: the screenshots for it (R1's names) and the files, each with its subfolder and the idea in a few words ("double hairline, the inner one with open corners"; "a glow band fading out to the right"). Ideas, never measurements: the sizes come from our captures and the tunables.
    4. A note per section where our screen already follows the idea (the pips as `PipRow`, the turn diamonds, the status marks), so nobody redoes them.
    5. The folder README links the page.
  - **Tests:** none (docs).
  - **Verify by hand:** each named file exists in its subfolder; `git status` shows only the new `.md`.
- **Done, with deviations:** besides design.md's screens, a section for B1's shatter: `Battle/ActionOrder` holds a crack and 17 shards. The Status and Equip folders hold no page layout, only panel bases and lines, so those sections name the shared frame and the tab files from `MainMenu/Other` and `Common`.
