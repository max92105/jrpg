# T1. A title font; the game's name in it

Part of [the UI second pass plan](../README.md). Design: [design.md](../design.md), "Tunables and placeholders" (title font, title name size). ADR 0025. Look at `docs/ui-reference/title-screen.jpg` and `battle-victory.jpg` first: the serif.

The developer downloads Cormorant Garamond SemiBold (Google Fonts, `CormorantGaramond-SemiBold.ttf`) and its `OFL.txt` into `content/art/fonts/titles/` before this slice (decision 250).

- **T1. A title font; the game's name on the title screen in it** (Game + content font, about 160 lines)
  - **Goal:** the game loads a title face beside the body font, and the title screen writes the game's name in it.
  - **Content:** the TTF and `OFL.txt` in `content/art/fonts/titles/`. Check the Game project copies the subfolder to the output and on publish (the content rule in `Jrpg.Game.csproj`).
  - **Changes (Game):**
    - `Rendering/FontLibrary`:
      - `Load` also reads `art/fonts/titles/*.ttf` into a second `FontSystem`: the title files first, then the body files as fallbacks. The folder holding no font throws `ContentValidationException` naming `art/fonts/titles`.
      - `public SpriteFontBase TitleFontAt(int pixels)`.
      - `Dispose` disposes both; a failure while loading the second disposes the first.
      - The file loop becomes one private method used for both folders, so the class stays near 110 lines.
    - `Title/TitleScene`: `_nameFont = text.Fonts.TitleFontAt(NameTextPixels)`, at 120 px; the drop shadow stays.
    - `docs/map.md`, Rendering line: `FontLibrary` (body and title faces, ADR 0025).
  - **Tests** (`FontLibraryTests`, which build font folders in a temporary directory):
    - `Load_RepositoryContent_GivesATitleFont`
    - `Load_NoTitleFont_ThrowsNamingTheTitlesFolder`
    - `Load_TitleFileThatIsNotAFont_ThrowsNamingTheFile`
    - The existing tests that build a temporary fonts folder need a `titles` subfolder with a font: about 4 fixture edits.
  - **Verify by hand:** the title shows the game's name in the serif (F12, compare with the before capture); renaming `titles` for one run stops the start with the folder named on screen and in the Output window (restore it).
