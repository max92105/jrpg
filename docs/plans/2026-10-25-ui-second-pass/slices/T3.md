# T3. Title entrance and a clear selection

Part of [the UI second pass plan](../README.md). Decision 252. Design: [design.md](../design.md), "Tunables and placeholders" (`TitleEntrance`, title footer, sizing targets' title entries). After P1a (it doesn't need T1). Look at `docs/ui-reference/title-screen.jpg`, the index's "Title" section and S0's title captures first.

Developer: "right now the menu is just my art with the options and it's hard to know what is selected."

- **T3. Title entrance and a clear selection: the screen fades in, entries in the shared selection look, a footer line** (Game, about 220 lines)
  - **Goal:**
    - Opening the title, the picture fades in from black, then the name, then the entries.
    - Entries are smaller (about 34 px, from SZ's targets), plain white, centered; the selected one sits in the shared selection look (`DrawSelectedRow`, a band as wide as the longest entry plus padding) with `MenuPointer` at its left, so it reads at a glance. The glow and growing go.
    - A footer line at the bottom center, from `ui.json` `title_footer` ("Prototype build"), in `TextSecondary`.
    - Input works during the entrance (a Confirm chooses at once), so no flow test waits for it.
  - **New types:** Game `Title/TitleEntrance` (internal sealed): how visible the title's picture, name and entries are at a time since the screen opened.
    - `void Advance(TimeSpan delta)`; `float PictureOpacity`, `NameOpacity`, `EntriesOpacity` (0 to 1, `Easing.ShareOf` over each window).
  - **Changes:**
    - `Title/TitleScene`: owns a `TitleEntrance`, advanced in `Update`; `Draw` multiplies each part by its opacity over black. Entry places and the band's width are computed once in the constructor. The file list overlay (Load) is unchanged.
    - `content/text/ui.json`: `title_footer`; `Ui/MessageIds.TitleFooter`.
  - **Tests:**
    - `TitleEntranceTests`:
      - `PictureOpacity_AtOpening_IsZero`
      - `NameOpacity_BeforeItsDelay_IsZero`
      - `EntriesOpacity_AfterTheEntrance_IsOne`
      - `PictureOpacity_HalfwayThroughItsFade_IsBetweenZeroAndOne`
    - `TitleSceneTests`: `Update_ConfirmDuringEntrance_ChoosesTheEntry` (the existing tests confirm on the first update and pass unchanged).
  - **Verify by hand:** start the game: black, the picture, the name, then the entries; the selected entry is obvious (band and diamond, the same as in the menu); the footer line shows; Load opens the file list; returning to the title plays the entrance again. F12, compare with `title-screen.jpg` and the before capture.
