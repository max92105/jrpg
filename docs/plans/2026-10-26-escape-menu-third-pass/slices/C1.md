# C1. `InventoryPage` split: the list column's drawing moves out

Part of [the escape menu third pass plan](../README.md). Design: [design.md](../design.md), "Replacement mapping". After LK1, before ML1 and SB1: SB1 grows `InventoryPage` (281 lines).

- **C1. `InventoryPage` split: the list column's drawing moves to `InventoryColumnView`** (Game, mechanical, about 170 lines moved, 30 new)
  - **Goal:** `InventoryPage` keeps the page's state, input and rows; drawing the list column moves to its own view, so SB1, IT1, IT2 and IT3 have room. Nothing on screen changes.
  - **New types:** Game `Menus/InventoryColumnView` (internal sealed): draws the Inventory's list column: the category rail, the category's name, the column titles and the list with its detail strip.
    - `InventoryColumnView(ScreenText text, UiTextures ui, SpriteFontBase bodyFont)`: builds the rail view, the list view, the heading and label fonts, the column titles and the category names (from `CategoryRail`'s tabs).
    - `Draw(SpriteBatch batch, TextureLibrary textures, Place place, float opacity)`.
    - `Place(CategoryRail Rail, IReadOnlyList<InventoryRow> Rows, ListCursor? Cursor, bool ListHasCursor, SelectionMotion Selection, Rectangle Area, string? Detail)`: `ListHasCursor` is passed in (today `!Rail.HasCursor`) so IT1 can dim the list while aiming.
  - **Changes (Game):** `Menus/InventoryPage`: `DrawList`, the heading and label fonts, `_columnTitles`, `_categoryNames`, `_railView`, `_listView` and their layout constants move out; the body font stays (rows measure their quantities with it) and is handed to the view. Expect about 236 lines.
  - **Tests:** none new. Record the solution's test count before and after; `InventoryPageTests`, `InventoryPageSelectionTests` and `InventoryPageRestItemTests` pass unchanged.
  - **Verify by hand:** F12 on Inventory before and after: identical (rail, heading, titles, rows, the strip under the selected row, the empty line on an empty category).
