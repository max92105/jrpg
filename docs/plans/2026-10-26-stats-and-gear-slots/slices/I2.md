# I2. Enemies resist Taunt; a status skill for every class

Part of [the stats and gear slots plan](../README.md). Decisions 320 (dead stats), 324 (crowd control resistance), ADR 0021 (the closed list of kinds). Design: "Dead-stat check", "Tunables" (statuses), "Formulas" (Taunt). After I1.

- **I2. Enemies resist Taunt; a status skill for the mage, cleric, monk and warlock** (Core + content, about 170 lines)
  - **Goal:**
    - **Taunt against crowd control resistance:** an enemy choosing its target while a member taunts first rolls its own crowd control resistance; on a success it ignores the taunt and picks among every living member, as with no taunt. A Taunt is self-granted, so the roll is the enemy's, at its choice, not at the grant.
    - **Every class has an Intelligence skill** (decision 320), on an existing skill and from ADR 0021's list (no new kind):
      | Class | Skill | Status added | Placeholder |
      |---|---|---|---|
      | mage | fire_blast | Poison (a burn; a Burn kind is out of scope) | power 5, 2 turns |
      | cleric | recovery | Regen (on its user, after the heal) | power 6, 2 turns |
      | monk | palm_strike | Stun (granted once after both blows; rolls I1's chance against the target's crowd control resistance) | power 30, 1 turn |
      | warlock | eldritch_bolt | Exposed | power 20, 2 turns |
    - The rogue keeps no Power skill: its Power acts through its basic attack (accepted, decision 320).
  - **Changes:**
    - Core `Battle/EnemyTactics.ChooseCommand`: with a taunting member, `ChanceRolls.Succeeds(enemy's crowd control resistance)` decides whether the taunt binds; the class summary's "one random call either way" becomes "one more draw only when the enemy might resist" (an enemy with 0 % draws nothing extra, so taunt tests with builder enemies keep their sequences). `EnemyTactics` reaches `ChanceRolls` through its `IRandom` (constructor unchanged).
    - `content/skills.json`: the four statuses above; each skill's `description` says what it now leaves behind.
    - Game tests: tests that play these four skills from repository content now see a `StatusApplied` (or a roll, for Palm Strike): grep `fire_blast`, `recovery`, `palm_strike`, `eldritch_bolt` in `tests/Jrpg.Game.Tests` and `tests/Jrpg.Core.Tests` and re-pin or fix the random (count in the Done note).
  - **Tests** (`EnemyTacticsTests`, `ContentCatalogLoaderTests`):
    - `EnemyTacticsTests: ChooseCommand_TauntResisted_TargetsAnyLivingMember` (fixed random)
    - `EnemyTacticsTests: ChooseCommand_TauntNotResisted_TargetsTheTaunter`
    - `EnemyTacticsTests: ChooseCommand_EnemyWithoutResistance_DrawsOnlyForTheTarget`
    - `ContentCatalogLoaderTests: Load_RepositoryClasses_EachHasASkillGrantingAStatus` (asserts, per class except the rogue's Power, that a class skill grants a status; reads the entries it needs)
  - **Size:** Core about 30, content about 25, 4 tests about 55, Game and Core test re-pins about 40: about 150-170.
  - **Verify by hand:** the barbarian taunts the goblins: now and then one hits someone else (goblin 10 %); the mage's Fire Blast leaves a Poison mark; the cleric's Recovery a Regen; the monk's Palm Strike sometimes stuns; the warlock's Eldritch Bolt exposes. The Status page's Intelligence caption means something for all four.
- **Done, with deviations:**
  - **`EnemyTactics.ResistsTaunt`** rolls the enemy's crowd control resistance through a `ChanceRolls` built on the tactics' own random, before the target draw; the summary now says "one more draw only when a taunt might be resisted".
  - **Content:** the four statuses as planned (fire_blast Poison 5 for 2, recovery Regen 6 for 2, palm_strike Stun 30 for 1, eldritch_bolt Exposed 20 for 2), each description saying what it leaves behind. `StatusKind.Taunt`'s summary names the resistance.
  - **Re-pins:** none. No Core or Game test plays the four skills from repository content in a battle (`ActionPlaybackTests` only reads Fire Blast's name); `ContentCatalogLoaderTests.Load_RepositoryContent_RecoveryHealsItsUser` now expects the Regen grant.
  - **Tests:** `EnemyTacticsTests` 3 (resisted, not resisted, no taunt draws once against a resistant goblin; the old no-taunt test's comment says the builder's goblin resists nothing), `ContentCatalogLoaderTests.Load_RepositoryClasses_EachButTheRogueHasASkillGrantingAStatus`. Count: 2,522 → 2,526.
