# P1. Five primaries and accuracy on the class

Part of [the stats and gear slots plan](../README.md). Decision 293. Design: [design.md](../design.md), "Tunables" (class primaries), "Content shapes". After ADR 0026 and C2.

- **P1. Five primaries and accuracy on the class, grown by level** (Core + Data + content, about 150 lines)
  - **Goal:** every class gives the five primaries and an accuracy at level 1 and grows them each level with ADR 0017's formula; content refuses a negative one. Nothing reads them in battle yet; P2 is the first reader (Constitution's max HP).
  - **New type:** Core `Stats/PrimaryStats` (public sealed record): the five primaries, Power, Agility, Intelligence, Constitution, Will; `Plus(PrimaryStats)` adds another set (ClassGrowth now, gear in P4); `None` is all zero.
  - **Changes:**
    - `Party/ClassStats`: gains `Primaries` (`PrimaryStats`, init, default `None`) and `Accuracy` (init, default 0). Init properties, not constructor parameters, so the 18 `new ClassStats(` sites stay as written; `Attack` and `Defense` stay until M1 and M2b.
    - `Party/ClassGrowth.StatsAt`: grows `Primaries` and `Accuracy` like the others (its comment keeps the one-formula reasoning).
    - `content/classes.json`: `base` and `growth` gain `accuracy` and a `primaries` object, the design table's placeholders.
    - `Data/Party/ClassCatalogValidator.FindNegativeStat`: each primary and accuracy at least 0, the field named (`base.primaries.power`).
    - `tests/.../Builders/ClassBuilder`: `WithPrimaries(PrimaryStats base, PrimaryStats growth)`.
  - **Tests:**
    - `ClassGrowthTests: StatsAt_LevelOne_IsBasePrimaries`
    - `ClassGrowthTests: StatsAt_LevelThree_GrowsEachPrimaryTwice`
    - `ClassGrowthTests: StatsAt_LevelThree_GrowsAccuracy`
    - `ClassCatalogValidatorStatTests: Validate_NegativeBasePrimary_NamesTheField`
    - `ClassCatalogValidatorStatTests: Validate_NegativeGrowthAccuracy_NamesTheField`
    - `ContentCatalogLoaderTests: Load_RepositoryFighter_HasPrimaries` (asserts the fighter's base Power is above 0, not the table)
  - **Call sites:** `new ClassStats(` 18, unchanged.
  - **Verify by hand:** the game starts (content loads); a broken primary in `classes.json` stops the start naming `classes.json` and the field.
