# E1. A map event opens the Forge

Part of [the forge plan](../README.md). Decision 353; ADR 0006 (map event flow), ADR 0008 (scenes return requests). After F1.

- **E1. The `openForge` event step: a map event opens the Forge screen** (Core + Data + Game, about 200 lines)
  - **Goal:** an event step `openForge` waits, like a dialogue step, while the Forge screen is open; closing the screen continues the event. No content uses it until N1, after the editor can show it (E2; the plan lessons: content with a new step lands with or after its editor support).
  - **New types:**
    - `Events/OpenForgeStep`: the step that opens the Forge and waits for it to close.
    - `Scenes/ForgeRequested`: the request a map scene returns to open the Forge.
  - **Changes:**
    - `Exploration/EventRun`: the step waits for `Continue()` (ADR 0006).
    - `Data/Content/ContentTypeDiscriminators` and `Data/Maps/MapEventSteps`: `"openForge"`.
    - `Game/Exploration/EventPresenter` (238): returns `ForgeRequested` on the step; `Flow/MenuTransitions` (or a `ForgeTransitions` if it grows past four constructor parameters) pushes `ForgeScene` and continues the run when it closes.
  - **Tests:**
    - `EventRunTests: Advance_OpenForgeStep_WaitsForContinue` (in a new `EventRunForgeTests` file: `EventRunTests` is at 269)
    - `MapEventStepsTests: Read_OpenForge_LoadsTheStep`
    - `EventPresenterTests: Update_OpenForgeStep_RequestsForgeOnce`
    - `GameFlowForgeTests: ForgeRequested_ThenClose_ContinuesTheEvent`
  - **Watch:** the editor throws on a step it can't open: no content may use `openForge` before E2.
