# E2. The editor shows and adds the `openForge` step

Part of [the forge plan](../README.md). Decision 353; ADR 0012 (editor architecture). After E1. Design: [design.md](../design.md), "What exists" (editor).

- **E2. The editor shows and adds the `openForge` step; the Forge master preset** (Editor, about 110 lines; the editor plan's sizing: tests count about as much as code)
  - **Goal:** the event dialogs list an `openForge` step like the other steps (no fields), add, move and remove it with undo, and a "Forge master" preset makes an Interact event of an empty dialogue line (for the developer to write) and the step.
  - **New types:** none.
  - **Changes** (the editor has no resources file: labels are C# strings):
    - `Editor/Events/EventStepKind.OpenForge`.
    - `Editor/Events/EventStepViewModel` (201): `Label` "Open the Forge"; `From` maps `OpenForgeStep`; `ToStep` makes one. No `Problem` (no fields).
    - `Editor/Events/EventViewModel.AddOpenForge` (`[RelayCommand]`, `AddStep(EventStepKind.OpenForge)`), with its "Forge" button beside "Rest" in `ObjectEventsWindow.xaml` and `CellEventWindow.xaml`.
    - `Editor/Events/EventPresets.ForgeMaster(EventIdAllocation target)`: Interact, prompt "Talk", steps: an empty `DialogueStep`, then `OpenForgeStep`; the class summary lists it.
    - `Editor/Events/EventListViewModel.ApplyForgeMasterPreset` (`[RelayCommand]`), with its "Forge master" button beside the other presets in `ObjectEventsWindow.xaml`.
  - **Tests:**
    - `EventStepViewModelTests: FromStep_OpenForgeStep_ShowsOpenTheForgeWithNoFields` (as `FromStep_RestStep_ShowsRestWithNoFields`)
    - `EventStepViewModelTests: ToStep_OpenForge_ReturnsOpenForgeStep`; and `new OpenForgeStep()` added to `StepsOfEveryKind`
    - `EventPresetsTests: ForgeMaster_TalksThenOpensTheForge`
    - `EventListViewModelTests: ApplyForgeMasterPreset_SelectsTheEmptyDialogueStep` (237 lines; the preset command test)
  - **Call sites:** none.
  - **Watch:** `EventStepViewModelTests` 244 (+25).
  - **Verify by hand:** in the editor, place an NPC, open its events, press Forge master: an Interact event with an empty line selected and the Open the Forge step; write the line, OK, save, reopen: both steps are there. Add an Open the Forge step to a cell event with the Forge button; Ctrl+Z removes it.
