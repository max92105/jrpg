# N1. A forge master on the start map

Part of [the forge plan](../README.md). Decisions 353, 372. After E2 (content with the new step only once the editor can open it). Design: [design.md](../design.md), "Risks" (placement).

- **N1. A forge master stands on the start map** (content + tests, about 70 lines)
  - **Goal:** an NPC on the start map, outdoors near where the player walks by (decision 372), runs the Forge master event: a line, then the Forge. From here on, every Forge slice is checked by hand at it.
  - **Changes:** content through the editor (E2's preset): a placed `villager` object (the shared placeholder field sprite `npc_placeholder.png`, ADR 0015) on `start`, its Interact event: a line (placeholder, speaker "Forge master": "Bring me your gear, and the scrap to work it."), then `openForge`. The developer picks the cell, off the paths the Game tests walk (design.md, "Risks": row 3 right of (10, 3), row 14 left to the forest warp, the door, the chest, the villager, the innkeeper).
  - **Tests:**
    - `RepositoryForgeTests: StartMap_HasAnInteractEventOpeningTheForge` (Data tests; asserts the event it needs, not a total)
    - `StartMapForgeMasterTests: Update_TalkThroughTheLine_RequestsTheForge` (Game tests, as `StartMapVillagerTests`; `StartMapScenarios.BelowForgeMaster` stands under the cell the developer chose)
  - **Watch:** run the whole Game test suite after placing it: a test walking the start map would meet the new NPC's collision.
  - **Verify by hand:** walk to the forge master, talk: the line, then the Forge (its title over the map); Cancel returns to the map with the event finished; talk again: it opens again.
