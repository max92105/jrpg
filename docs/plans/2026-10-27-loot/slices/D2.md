# D2. Drop tables in content

Part of [the loot plan](../README.md). ADR 0030, decision 343. Design: "Tunables" (drop tables), "Content shapes". After D1.

- **D2. Drop tables in content; the goblin drops** (Data + content + tests, about 200 lines)
  - **Goal:** `drop-tables.json` is loaded and validated; the goblin names its table, so winning against the goblin trio adds potions and now and then a piece of gear (plain until R3b). The victory screen doesn't show them until D3; the Inventory page does.
  - **New type:**
    - `Data/Loot/DropTableCatalogValidator`: checks the drop tables file: ids unique, entries present, each item id known, chance 1..100, `1 ≤ minQuantity ≤ maxQuantity`, and a stackable's `maxQuantity` within its `maxStack`.
  - **Changes:**
    - `Data/Content/ContentCatalogLoader`: reads `drop-tables.json` after items, before enemies; `ContentCatalog.DropTables` from it.
    - `Data/Battle/EnemyCatalogValidator.Validate(file, enemies, dropTableIds)`: an unknown `dropTableId` is named.
    - Content: `drop-tables.json` with the `goblin` table (design.md); `enemies.json` goblin `"dropTableId": "goblin"`.
  - **Tests:**
    - `DropTableCatalogValidatorTests: Validate_UnknownItem_Throws`
    - `DropTableCatalogValidatorTests: Validate_ChanceZero_Throws`
    - `DropTableCatalogValidatorTests: Validate_ChanceAboveHundred_Throws`
    - `DropTableCatalogValidatorTests: Validate_MinAboveMax_Throws`
    - `DropTableCatalogValidatorTests: Validate_NullEntry_Throws` (tests rule: a new list gets a null-entry test)
    - `EnemyCatalogValidatorTests: Validate_TwoEnemiesShareATable_Passes` (decision 343)
    - `EnemyCatalogValidatorTests: Validate_UnknownDropTable_Throws`
    - `RepositoryLootTests: Goblin_DropsFromATableThatExists`
  - **Call sites:** `EnemyCatalogValidator.Validate` in its tests (2). Grep the Core and Game tests that win a repository battle and then read the inventory or fight again (`BattleScenarios`, `GameFlow` battle tests, `GameSessionBattleTests`): drops now change the inventory and the session's draws after a victory; fix each by asserting what it needs (budget about 20 lines).
  - **Verify by hand:** win against the goblin trio a few times; the Inventory page gains potions, and once in a while a Bronze Sword, Leather Cap, Leather Boots or Power Ring row.
