# R2. `Loot/GearRoll`: rarity by weight, affixes from a pool

Part of [the loot plan](../README.md). ADR 0030, decisions 339, 340, 359. Design: "Loot", "Tunables". After D3. Its caller arrives in R3b (drops); content in R3a. `Loot/AffixDefinition` exists since S1a.

- **R2. `Loot/GearRoll`: rarity by weight, affixes from a pool** (Core, about 230 lines)
  - **Goal:** given an affix pool and a rarity table, a base item rolls into a piece: a rarity by weight among the rolled tiers, an affix count in that tier's range (Rare 2-3), then that many affixes chosen by weight among the pool's affixes for the item's kind, never one twice (decision 359), each value in its range. Every draw is skipped when only one outcome is possible.
  - **New types:**
    - `Randomness/WeightedPick`: picks an index by weight with one draw (`NextBelow(total)`); draws nothing when one weight is the whole total; a weight of 0 is never picked; throws when every weight is 0.
    - `Loot/RarityRule(int Weight, int MinAffixes, int MaxAffixes)`: one rolled tier's weight and affix count range.
    - `Loot/LootRules(IReadOnlyDictionary<Rarity, RarityRule> Rarities)`: the rarity table; Unique has no row (decision 339).
    - `Loot/GearRoll(IReadOnlyList<AffixDefinition> pool, LootRules rules, IRandom random)`: rolls dropped gear. `GearPiece Roll(ItemDefinition item)`.
  - **Tests:**
    - `WeightedPickTests: Pick_OneWeightHoldsAll_DrawsNothing`
    - `WeightedPickTests: Pick_DrawBelowFirstWeight_PicksFirst`
    - `WeightedPickTests: Pick_DrawAtFirstWeight_PicksSecond` (the boundary's other side)
    - `WeightedPickTests: Pick_ZeroWeight_NeverPicked`
    - `GearRollTests: Roll_MagicPicked_HasOneAffix`
    - `GearRollTests: Roll_RareLowDraw_HasTwoAffixes`
    - `GearRollTests: Roll_RareHighDraw_HasThreeAffixes`
    - `GearRollTests: Roll_CommonOnly_DrawsNothingAndIsPlain`
    - `GearRollTests: Roll_Affixes_OnlyThoseForTheKind`
    - `GearRollTests: Roll_SameAffix_NeverTwice`
    - `GearRollTests: Roll_PoolSmallerThanCount_RollsWhatItHas`
    - `GearRollTests: Roll_LowestDraw_TakesMin`
    - `GearRollTests: Roll_HighestDraw_TakesMax`
  - **Call sites:** none (new types).
  - **Size note:** 13 tests at about 13 lines each; if the slice heads past 260, `WeightedPick` and its four tests go first as their own commit.
