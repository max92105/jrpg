# B1. No running from a boss: Core refuses Flee, Run is greyed

Part of [the enemy skills and bosses plan](../README.md). After C1. Design: [design.md](../design.md), "Key decisions" 6. Question Q9 (placeholder until answered).

- **B1. No running from a boss: Core refuses Flee, Run is greyed** (Core + Game + content, about 170 lines)
  - **Goal:** `isBoss` in `enemies.json` marks a boss. While a boss is in the battle, standing or fallen, the party can't flee: Core refuses the command and the command list greys Run.
  - **New types:** none.
  - **Changes:**
    - `Battle/EnemyDefinition`: `bool IsBoss { get; init; }` (absent: false).
    - `Battle/BattleState`: `public bool CanFlee` (the actor is a party member and no combatant's `Enemy` is a boss); `Flee` throws `InvalidOperationException` when it's false, replacing its own side check (the side is part of `CanFlee`).
    - `Game/Battle/CommandMenu.IsEnabled`: `CommandEntry.Run => _canFlee`, set in `Start` from `battle.CanFlee`; the summary lists Run with the other greyed entries.
    - `content/enemies.json`: `goblin_chief` gets `"isBoss": true`.
    - Test builder: `EnemyDefinitionBuilder.AsBoss()`.
  - **Tests:**
    - `BattleStateTests` (or a new `BattleFleeTests`): `CanFlee_PartyTurnNoBoss_IsTrue`
    - `BattleFleeTests: CanFlee_BossInTheBattle_IsFalse`
    - `BattleFleeTests: CanFlee_BossFallen_IsStillFalse` (Q9's proposed rule)
    - `BattleFleeTests: CanFlee_EnemyTurn_IsFalse` (the other side of the actor check)
    - `BattleFleeTests: Execute_FleeFromABoss_Throws`
    - `CommandMenuRunTests: IsEnabled_BossBattle_RunIsGreyed`
    - `CommandMenuRunTests: Update_DownFromDefendInABossBattle_NeverSelectsRun` (the guard pressed: `ListCursor` skips a greyed entry; the test asserts `Selected` isn't Run, whatever the cursor's wrap rule; tests.md)
    - `CommandMenuRunTests: IsEnabled_NoBoss_RunIsOffered`
    - `ContentCatalogLoaderTests: Load_RepositoryContent_ForestRollsABoss` (some forest encounter holds an `isBoss` enemy)
  - **Verify by hand:** in the Chief's fight, Run is greyed and the cursor passes over it; in a goblin fight, Run escapes as before.
