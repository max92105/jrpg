# B3. Phases in content and on screen

Part of [the enemy skills and bosses plan](../README.md). After B2. Design: [design.md](../design.md), "Key decisions" 5, "Tunables and placeholders". Question Q8 (placeholder until answered).

- **B3. Phases in content and on screen: validated, the Chief's second phase, a cue on the boss** (Data + Game + content + text, about 200 lines)
  - **Goal:** `enemies.json` may give an enemy `phases`; Data checks them. The battle screen shows a phase change as a one-word cue on the enemy at the impact. The Chief gets its second phase below half HP. Content shape:
    ```json
    "phases": [
      { "belowHpPercent": 50, "tactics": [ { "weight": 2 }, { "skillId": "crushing_blow", "weight": 3 } ] }
    ]
    ```
  - **New types:** none.
  - **Changes:**
    - `Data/Battle/EnemyTacticsValidator`: `string? FindPhasesProblem(IReadOnlyList<EnemyPhase> phases, IReadOnlyDictionary<string, SkillDefinition> skills)`: no null phase; `belowHpPercent` within 1..99 and strictly descending; each phase's `tactics` not empty, then checked as D1's actions with the field `phases[i].tactics`. `EnemyCatalogValidator` calls it.
    - `Game/Battle/ActionPlayback.AddImpactCue`: `EnemyPhaseEntered entered => (entered.Enemy, messages.Text(MessageIds.BattleEnemyPhase))`; its summary names the phase cue. `Read` keeps its cases (design.md, "Key decisions" 5).
    - `Game/Ui/MessageIds.BattleEnemyPhase` = `battle_enemy_phase`; `content/text/ui.json`: "Enraged!" (placeholder, Q8).
    - `content/enemies.json`: the Chief's `phases` (design.md, "Tunables": below 50 %, attack 2, `crushing_blow` 3, `cleave` 2, `war_cry` 2 when an ally has fallen).
  - **Tests:**
    - `EnemyTacticsValidatorTests: Validate_PhaseThresholdHundred_IsRefused`
    - `EnemyTacticsValidatorTests: Validate_PhaseThresholdZero_IsRefused` (the range's other side)
    - `EnemyTacticsValidatorTests: Validate_PhasesNotDescending_NamesTheSecond`
    - `EnemyTacticsValidatorTests: Validate_PhaseWithoutTactics_IsRefused`
    - `EnemyTacticsValidatorTests: Validate_PhaseActionWithUnknownSkill_NamesThePhaseField` (`phases[0].tactics[1]`)
    - `EnemyTacticsValidatorTests: Validate_NullPhase_NamesTheIndex`
    - `ActionPlaybackPhaseTests: Start_EnemyPhaseEntered_ShowsTheCueOnTheEnemy` (a hit that crosses the threshold: one Impact beat, the cue's target is the boss)
    - `ActionPlaybackPhaseTests: Start_PhaseEnteredByAPoisonTick_AddsAnImpactBeat` (no hit in the turn: the cue still has a beat to show in)
    - `MessageIdsTests` covers the new id as it does every constant (ADR 0010; no new test).
