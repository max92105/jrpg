- **B3. Phases in content and on screen: validated, the Chief's second phase, "Enraged!" in its own beat** (Data + Game + content + text + Simulations, about 220 lines)
  - **Goal:** `enemies.json` may give an enemy `phases`; Data checks them. The battle screen shows a phase change as an "Enraged!" cue on the enemy in a beat of its own, after every beat of the action (decision 406). The Chief gets its second phase below half HP, and S1's table says how often fights reach it. Content shape:
    ```json
    "phases": [
      { "belowHpPercent": 50, "tactics": [ { "weight": 2 }, { "skillId": "crushing_blow", "weight": 3 } ] }
    ]
    ```
  - **New types:** none.
