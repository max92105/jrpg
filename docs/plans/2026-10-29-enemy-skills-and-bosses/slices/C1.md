# C1. A placeholder Goblin Chief fight in the forest, with its skills

Part of [the enemy skills and bosses plan](../README.md). After D1. Design: [design.md](../design.md), "Tunables and placeholders". Questions Q1, Q11, Q12 (placeholders until answered).

- **C1. A placeholder Goblin Chief fight in the forest, with its skills** (content + tests, about 90 lines)
  - **Goal:** the forest can roll the Chief's encounter; the Chief uses Cleave and Field Dressing by its phase 1 tactics. It is not a boss yet (B1 adds `isBoss`), so Run still works.
  - **Content** (every number from design.md's "Tunables", each description ending "Placeholder: the developer writes the real skill."):
    - `skills.json`: `cleave`, `field_dressing`, `crushing_blow`, `war_cry` (the last two are first used in B3; a skill nobody lists is legal content, so they can land now with the others).
    - `enemies.json`: `goblin_chief` with the Goblin's art, its stats and `tactics` (attack 4, `cleave` 2, `field_dressing` 3 when an ally's HP is below 50 %).
    - `encounters.json`: `goblin_chief` = `["goblin", "goblin_chief", "goblin"]` on `Forest.png`.
    - `maps/forest.json`: `goblin_chief` added to `randomEncounters.encounterIds` (Q1).
  - **Tests:**
    - `ContentCatalogLoaderTests: Load_RepositoryContent_ForestRollsAnEnemyWithASkill` (as the physical-resistance test does: some forest encounter holds an enemy whose tactics name a skill, so the mechanic is met in play; no ids or totals pinned)
  - **Check first:** grep the Game and Simulations tests that load the repository catalog and walk the forest or roll its table (`StartMapScenarios` replaces the table; `ForestFightsSimulation` and `LootSimulation` name their encounters): none should move. If one does, budget its fix here.
  - **Verify by hand:** walk the forest until the Chief's encounter (one in three); the Chief shows "Cleave" in the action window and every member takes damage with the goblin's strip; once a goblin is under half HP, the Chief sometimes casts "Field Dressing" on the most wounded goblin (a cue with the name and a heal number); Run still escapes.
