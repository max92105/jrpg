# D1. `enemies.json` tactics, checked against the skills

Part of [the enemy skills and bosses plan](../README.md). After T2. Design: [design.md](../design.md), "Core changes" (Data), "Decisions" in the README (what an enemy's skill may be).

- **D1. `enemies.json` tactics, checked against the skills** (Data, about 230 lines)
  - **Goal:** `enemies.json` may give an enemy `tactics`; a broken one stops the load with a message naming the enemy and the field. Content shape:
    ```json
    "tactics": [
      { "weight": 4 },
      { "skillId": "field_dressing", "weight": 3, "when": { "kind": "allyHpBelow", "percent": 50 } }
    ]
    ```
  - **New types** (`Data/Battle/`):
    - `EnemyReferences`: what an enemy may name. `internal sealed record EnemyReferences(IReadOnlySet<string> DropTableIds, IReadOnlyDictionary<string, SkillDefinition> Skills)`.
    - `EnemyTacticsValidator`: an enemy's actions against the skills. `internal static`; `string? FindProblem(IReadOnlyList<EnemyAction> tactics, string field, IReadOnlyDictionary<string, SkillDefinition> skills)` (`field` is `tactics` here, `phases[i].tactics` in B3).
  - **Rules** (each message names the field and the index):
    - no null entry; weight at least 1;
    - a `skillId` is a known skill; the skill changes no resource and requires none (enemies have no resources, ADR 0019); its targeting is neither `alliesInRange` nor `otherCombatant`;
    - `when.percent` within 1..99 for `ownHpBelow` and `allyHpBelow`; 0 (absent) for `allyFallen`.
  - **Changes:**
    - `Battle/EnemyCatalogValidator.Validate(string fileName, IReadOnlyList<EnemyDefinition> enemies, EnemyReferences references)`; calls `EnemyTacticsValidator` after its own checks.
    - `Content/ContentCatalogLoader`: builds `EnemyReferences(dropTableIds, skillsById)`.
  - **Call sites:** `EnemyCatalogValidatorTests` (4).
  - **Tests** (new file `EnemyTacticsValidatorTests`; message text pinned as the other validator tests do):
    - `Validate_TacticsWithANullEntry_NamesTheIndex`
    - `Validate_ActionWeightZero_IsRefused`
    - `Validate_UnknownSkillId_NamesIt`
    - `Validate_SkillThatSpendsAResource_IsRefused` (Fire Blast's shape)
    - `Validate_SkillThatRequiresAResource_IsRefused` (Heal's shape)
    - `Validate_SkillAimedAlongTheFormation_IsRefused` (`alliesInRange`)
    - `Validate_SkillAimedAtAnyOtherCombatant_IsRefused` (`otherCombatant`)
    - `Validate_HpConditionPercentZero_IsRefused`
    - `Validate_HpConditionPercentHundred_IsRefused` (the range's other side)
    - `Validate_AllyFallenWithAPercent_IsRefused`
    - `Validate_ActionWithoutSkillId_IsAccepted` (the basic attack)
    - `Load_EnemyWithTactics_ReadsTheConditionKind` (a temp content root through `ContentCatalogLoader`: the camelCase enum and `when` reach the record)
  - **Verify by hand:** a game start with a typo in a test copy of `enemies.json` (`"skillId": "cleve"`) names the enemy and the id on screen.
  - **Watch:** `EnemyCatalogValidatorTests` grows by none (new file); `ContentCatalogLoader` 113 (+2).
