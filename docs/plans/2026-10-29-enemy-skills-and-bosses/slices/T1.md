# T1. Enemies choose a skill from a weighted list

Part of [the enemy skills and bosses plan](../README.md). After the ADR step. Design: [design.md](../design.md), "Core changes", "Key decisions" 2 and 3, "Replacement mapping".

- **T1. Enemies choose a skill from a weighted list** (Core, about 240 lines)
  - **Goal:** an enemy whose definition lists tactics picks one action by weight (a skill, or the basic attack) and aims it; `Execute` lands the skill through the party's path. An enemy without tactics attacks exactly as today, with the same draws.
  - **New types:**
    - `Core/Tactics/EnemyAction`: one weighted choice in an enemy's tactics. `public sealed record`; `string? SkillId { get; init; }` (null: the basic attack), `required int Weight { get; init; }`. (`When` comes in T2.)
    - `Core/Battle/EnemyTargeting`: whom an enemy aims a chosen action at. `internal sealed class EnemyTargeting(IRandom random)`; `Combatant ForAttack(BattleState battle)` (today's rule moved from `EnemyTactics`: a taunting member unless the enemy's crowd control resistance shrugs it off, else a random living member; same draws); `IReadOnlyList<Combatant> ForSkill(BattleState battle, SkillDefinition skill)` (every candidate of `battle.TargetChoiceFor(skill)` when it takes all; a `singleEnemy` skill through the attack's taunt rule over its candidates; any other single target at random).
  - **Changes:**
    - `Battle/EnemyDefinition`: `IReadOnlyList<EnemyAction> Tactics { get; init; } = []`; `bool NamesSkill(string skillId)`.
    - `Battle/Combatant.Knows(SkillDefinition skill)`; the `Skills` summary says an enemy's skills are named by its tactics.
    - `Battle/BattleState.CanUse(SkillDefinition)`: `CurrentActor.Knows(skill)` in place of `Skills.Contains(skill)`.
    - `Battle/EnemyTactics(IRandom random, IReadOnlyDictionary<string, SkillDefinition> skills)`: no tactics → `AttackCommand(targeting.ForAttack(battle))`; else the actions whose skill `battle.CanUse` allows (an attack is always allowed), `WeightedPick.Pick` over their weights, then an `AttackCommand` or a `SkillCommand(skill, targeting.ForSkill(battle, skill))`. Its summary says what it draws, in order.
    - `Session/GameSession`: `new EnemyTactics(context.Random, context.Catalog.Skills)`.
    - Test builder: `EnemyDefinitionBuilder.WithTactics(params EnemyAction[] actions)`.
  - **Call sites:** `new EnemyTactics(random)` in 18 places (`EnemyTacticsTests` 9, `BattleTurnSequenceTests` 5, `BattleStateOutcomeTests`, `BattleStatusTests`, `ForestFightsSimulation`, `GameSession`): tests pass an empty skill dictionary; the simulation passes `catalog.Skills`. About 20 lines.
  - **Tests** (new file `EnemySkillTacticsTests`, with a test skill catalog):
    - `ChooseCommand_EnemyWithoutTactics_AttacksWithTodaysDraws` (one draw, the target's: the existing tests keep passing, and this one pins it for an enemy with an empty list)
    - `ChooseCommand_WeightedDrawInSkillsShare_UsesTheSkill` (attack weight 1, skill weight 3, draw 1: the edge moves with the weights)
    - `ChooseCommand_WeightedDrawInAttacksShare_Attacks` (same weights, draw 0)
    - `ChooseCommand_OnlyActionIsASkill_DrawsNothingForThePick` (one value in the sequence, the target's)
    - `ChooseCommand_SkillWithNoTarget_IsNotPicked` (a revive with nobody fallen beside an attack: the attack holds the whole weight, no pick draw)
    - `ChooseCommand_AllEnemiesSkill_TargetsEveryLivingMember`
    - `ChooseCommand_SingleEnemySkillWithATaunter_AimsAtTheTaunter`
    - `ChooseCommand_SingleAllySkill_AimsAtARandomEnemy` (the enemy's allies are the enemies, itself included)
    - `Execute_EnemySkillCommand_LandsTheSkillsDamage` (the chosen command executed: `EffectApplied` with the content power, no resource event)
    - `CanUse_EnemyWhoseTacticsDontNameTheSkill_IsFalse` (`BattleStateTests` or a new `CombatantKnowsTests`)
    - `Knows_MemberWithTheSkill_IsTrue` (the member side of `Knows`)
  - **Verify by hand:** nothing changes in play (no repository enemy has tactics before C1); the forest's goblins still only attack.
  - **Watch:** `BattleState` 269 (±0). `EnemyTactics` stays one per playthrough; `EnemyTargeting` is its field.
