# E1. A map event opens a shop

Part of [the gold and shops plan](../README.md). Decisions 353, 370 (no fade to black). ADR 0006 (map event flow), ADR 0008 (scenes return requests). After H1. The forge plan's E1 is the model. Design: [design.md](../design.md), "Key decisions" (one opening-step signal; `GameFlow.Start` under CA1502), "Replacement mapping".

- **E1. The `openShop` event step opens the named shop and waits for it** (Core + Data + Game, about 240 lines; adds no view type)
  - **Goal:** an event step `openShop` names a shop from `shops.json`; it waits, like the Forge's step, while that shop's screen is open; Cancel in the Shop closes it and the event continues. It opens and closes without the flow's fade. No content uses the step until N1, after the editor can show it (E2).
  - **New types:**
    - `Core/Events/OpenShopStep(string ShopId)`: public sealed record; the step that opens a shop and waits until it closes.
    - `Game/Scenes/ShopRequested(string ShopId)`: the request the map scene returns to open a shop.
    - `Game/Flow/ShopTransitions(SceneStack scenes, SceneFactory factory)`: opening a shop over the map and closing it (no fade; it fades itself in, L2a). `Open(GameSession session, string shopId)` pushes `factory.CreateShop(session, shopId)`; `Close(GameSession session)` pops it and continues the event.
  - **Changes:**
    - Core: `Exploration/EventRun.ApplyAndCheckWait`: `OpenShopStep` waits.
    - Data: `Content/ContentTypeDiscriminators` `"openShop"`; `Maps/MapContentReferences.ShopIds` (3 sites) and `MapEventValidator`: "openShop has unknown shop id '…'"; the loader passes the shop ids (after `shops.json`).
    - Game: `Exploration/EventPresenter.IsOpeningForge` becomes `EventStep? OpeningStep` (the Forge or shop step on the one update it first shows; the once-per-step rule unchanged); `ExplorationScene` maps it: `OpenForgeStep` → `ForgeRequested`, `OpenShopStep` → `ShopRequested(ShopId)`; the `<returns>` names both.
    - `Flow/GameFlow.Start`: a private `RunningSession` (`Session ?? throw`, one message) replaces the four `??`, then `ShopRequested` and `ShopClosed` go through `ShopTransitions` (CA1502: each `??` is a branch).
    - `Flow/SceneFactory.CreateShop(GameSession session, string shopId)` (`session.ShopFor(shopId)`).
    - Tests: `EventPresenterForgeTests` read `OpeningStep` (4 sites); `StartMapScenarios.BelowShopChest`: the chest runs `openShop` `general_store`, then a line.
  - **Tests:**
    - `EventRunShopTests: Advance_OpenShopStep_WaitsForContinue` (new file)

  - **Watch:** the scene returns the request once (the flow lessons). The editor throws on a step it can't open: no content may use `openShop` before E2. `GameFlow` 254 (+10), `EventPresenter` (after I2b) stays under 280.
  - **Verify by hand:** none yet (no content uses the step until N1); the flow test plays it headless.
