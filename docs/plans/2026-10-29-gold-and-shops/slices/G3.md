# G3. Each enemy drops gold; a new game starts with some

Part of [the gold and shops plan](../README.md). Decisions 103 (gold joins the victory's rewards), 376 (a range per enemy, after the item drops, no luck), 381 (placeholders). ADR 0030 (loot after the experience, drawing only when uncertain); ADR 0031 is written first. After G2. Design: [design.md](../design.md), "Key decisions" (gold rolls after the items), "Tunables", "Risks" (determinism).

- **G3. Each enemy drops gold; a new game starts with some** (Core + Data + content, about 215 lines)
  - **Goal:** an enemy may drop a range of gold; after a victory each defeated enemy with a range draws once, after every item draw, and the gold goes into the purse; `BattleSpoils.Gold` says what went in (past the cap it is lost). A new game starts with `startingGold`. Nothing shows it yet (G4; the save keeps it).
  - **New types:**
    - `Core/Battle/GoldRange(int Min, int Max)`: public sealed record; the gold a defeated enemy drops, both ends included.
  - **Changes:**
    - `Battle/EnemyDefinition.Gold` (`GoldRange?` init; null drops none).
    - `Session/BattleSpoils(VictoryRewards Rewards, Drops Drops, int Gold)`: what the purse took.
    - `Session/GameSession.SpoilsOf`: after `Keep`, a private `RollGold(battle)` (one `RangeRoll.Within` per defeated enemy with a range, none on a single value) adds to `Party.Purse`; `StartNew` adds `NewGame.StartingGold`. The `FinishBattle` summary names the gold.
    - `Content/NewGameDefinition.StartingGold` (int init, 0).
    - Data: `Battle/EnemyCatalogValidator`: gold 0 ≤ min ≤ max ≤ `Purse.MaxGold`, naming the enemy; `Content/NewGameValidator`: `startingGold` within 0 and `Purse.MaxGold`.
    - Content: `enemies.json` `goblin` and `stone_beetle` `gold: { "min": 6, "max": 12 }`; `new-game.json` `startingGold` 100 (placeholders).
    - `VictoryScreenTests`: the 4 `new BattleSpoils(` take a gold of 0.
  - **Tests:**
    - `GameSessionGoldTests: FinishBattle_VictoryOverGoldEnemies_AddsTheDrawnGold` (new file; `FixedSequenceRandom`, pinned amount)
    - `GameSessionGoldTests: FinishBattle_PurseNearlyFull_SpoilsReportOnlyWhatFit`
    - `GameSessionGoldTests: FinishBattle_EnemyWithoutGold_DrawsNothing` (the training dummy: the case the roll doesn't apply to)
    - `GameSessionGoldTests: FinishBattle_GoldEnemies_DropsSameAsWithoutGold` (the same seed with and without ranges: equal `Drops`)
    - `GameSessionGoldTests: StartNew_StartingGold_PurseHoldsIt`
    - `EnemyCatalogValidatorTests: Validate_GoldMinAboveMax_ThrowsNamingTheEnemy`
    - `EnemyCatalogValidatorTests: Validate_NegativeGoldMin_Throws`
    - `EnemyCatalogValidatorTests: Validate_GoldMaxAboveMaxGold_Throws`
    - `NewGameValidatorTests: Validate_NegativeStartingGold_Throws`
    - `NewGameValidatorTests: Validate_StartingGoldAboveMaxGold_Throws`
  - **Call sites:** `new BattleSpoils(` (1 in `GameSession`, 4 in `VictoryScreenTests`).
  - **Watch:** before budgeting seeded fixes, grep the repository tests that win against `goblin_trio` and then draw from the random or read the inventory (the loot retro); gold draws after every item draw, so the drops themselves don't move. `GameSession` about 258 (+12).
