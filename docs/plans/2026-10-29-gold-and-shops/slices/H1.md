# H1. A Shop screen that opens and closes

Part of [the gold and shops plan](../README.md). Decision 353 (a screen an NPC opens over the map, the Forge's model), 370. ADR 0008 (scenes return requests). After S3. The forge plan's F1a is the model. Design: [design.md](../design.md), "Structure and folder dependencies" (Game), "Risks" (CA1812).

- **H1. A Shop screen that opens over the map and Cancel closes** (Game + text, raw 90, about 145 lines at 1.6x: adds a view type)
  - **Goal:** a Shop screen exists: drawn over the map as a dark layer with the shop's name as its title; Cancel asks to close it, once. Nothing lists yet (B1), and nothing opens it in play until E1 (known gap: tests only).
  - **New types:**
    - `Game/Trade/ShopScene`: the Shop screen's input and its close request (an `IScene`); returns `ShopClosed` on the first Cancel and nothing after. `ShopScene(ScreenText text, UiTextures ui, GameSession session, Shop shop)`.
    - `Game/Trade/ShopView`: draws the Shop screen; here the scrim and the shop's name (plain: the look is L2a).
    - `Game/Scenes/ShopClosed`: the request the Shop returns to close.
  - **Changes:** none outside the new types (the title is the shop's content name, so no text id yet).
  - **Tests** (`ShopSceneTests`, new file; a session from the repository catalog and `ShopFor("general_store")`):
    - `Update_Cancel_RequestsCloseOnce` (two Cancels: one `ShopClosed`, then null)
    - `Update_Confirm_RequestsNothing`
  - **Watch:** CA1812: `SceneFactory.CreateShop` lands in E1, its first caller; if the build flags `ShopScene` here, it lands in this slice.
  - **Verify by hand:** none until N1 (no way in yet).
