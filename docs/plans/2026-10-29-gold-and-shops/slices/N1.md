# N1. A shopkeeper on the start map

Part of [the gold and shops plan](../README.md). Decision 353; ADR 0015 (NPCs share a placeholder sprite). After E2 (content with the new step only once the editor can open it). The forge plan's N1 is the model. Design: [design.md](../design.md), "Risks" (placement).

- **N1. A shopkeeper stands on the start map** (content + tests, about 70 lines)
  - **Goal:** a placeholder shopkeeper on the start map runs the Shopkeeper event: a line, then the General Store. From here on every shop slice is checked by hand at it. The developer moves it where the story wants it.
  - **Changes:** content through the editor (E2's preset): a placed `villager` object (`npc_placeholder.png`) on `start`, uid `shopkeeper`, its Interact event `shopkeeper_0`: a line (placeholder, speaker "Shopkeeper": "Have a look. Everything's priced fair."), then `openShop` `general_store`. A cell near the forge master (25, 14), off the paths the Game tests walk (row 3 right of (10, 3); row 14 left to the forest warp; the door at (5, 14); the chest at (19, 21); the villager at (12, 4); the innkeeper at (30, 26); the forge master).
  - **Tests:**
    - `RepositoryShopTests: StartMap_HasAnInteractEventOpeningTheGeneralStore` (Data tests; the event it needs, not a total)
    - `StartMapShopkeeperTests: Update_TalkThroughTheLine_RequestsTheGeneralStore` (Game tests, as `StartMapForgeMasterTests`; `StartMapScenarios.BelowShopkeeper`)
  - **Watch:** run the whole Game test suite after placing it: a test walking the start map would meet the new NPC's collision.
  - **Verify by hand:** walk to the shopkeeper, talk: the line, then the Shop (its name over the map); Cancel returns to the map with the event finished; talk again: it opens again.
