# S3. Shops, prices and the sell share in content

Part of [the gold and shops plan](../README.md). ADR 0011 (content only in `content/`), ADR 0002 (JSON straight into Core records). After S2. Design: [design.md](../design.md), "Tunables", "Structure and folder dependencies" (Data).

- **S3. Shops, prices and the sell share in content, checked by the loader** (Core + Data + content, about 245 lines)
  - **Goal:** `items.json` gives prices, `shops.json` the shops (a general store, placeholder), `rules.json` the `trade` share; the loader checks them (the forge lesson: a check needing another file is called once both are loaded) and the session opens a shop by id.
  - **New types:**
    - `Data/Trade/ShopCatalogValidator`: the rules for `shops.json`, checked against the loaded items: ids unique, a name, at least one item, every item known and priced, none listed twice; each problem names the shop and the file.
  - **Changes:**
    - `Content/ContentCatalog.Shops` (required, by id); `Session/GameSession.ShopFor(string shopId)` resolves the stock in order and builds a `Shop` (throws on an unknown id).
    - `Data/Content/ContentCatalogLoader`: reads `shops.json` after the items and calls the validator with `itemsById`; `rules.json` `trade` read into `GameRules.Trade`.
    - `Data/Items/ItemCatalogValidator`: a price, when given, is 1 to `Purse.MaxGold`.
    - `Data/Content/GameRulesValidator`: `trade.sellPercent` 0 to 100.
    - Content: `shops.json` (`general_store`, "General Store"), prices on every item but the materials, `rules.json` `trade: { "sellPercent": 50 }` (design.md, "Tunables"; placeholders).
    - Catalog sites: `ContentCatalogBuilder`, `BattleSceneTests` (empty `Shops`).
  - **Tests:**
    - `ShopCatalogValidatorTests: Validate_UnknownItem_ThrowsNamingTheShop`
    - `ShopCatalogValidatorTests: Validate_UnpricedItem_Throws`
    - `ShopCatalogValidatorTests: Validate_ItemListedTwice_Throws`
    - `ShopCatalogValidatorTests: Validate_NoItems_Throws`
    - `ShopCatalogValidatorTests: Validate_RepeatedShopId_Throws`
    - `ShopCatalogValidatorTests: Validate_BlankName_Throws`
    - `ItemCatalogValidatorPriceTests: Validate_ZeroPrice_Throws` (new file: `ItemCatalogValidatorTests` is 248)
    - `GameRulesValidatorTests: Validate_SellPercentAbove100_Throws`
    - `ContentCatalogLoaderShopTests: Load_Repository_GeneralStoreSellsPricedItems` (new file: `ContentCatalogLoaderTests` is 272)
    - `ContentCatalogLoaderShopTests: Load_ShopNamingUnpricedItem_ThrowsNamingTheFile`
    - `GameSessionShopTests: ShopFor_GeneralStore_ListsItsStockInOrder`
  - **Call sites:** `ContentCatalog` initializers (3).
  - **Watch:** an item's `price` is optional: the item records are read, not written, by the editor; check the content writer leaves `items.json` alone. A Data test that counts content files or items (grep `items.json` in `Jrpg.Data.Tests`) may need the new file.
  - **Verify by hand:** start the game: it loads; break `shops.json` (an unknown item id): the start stops naming the file and the shop.
