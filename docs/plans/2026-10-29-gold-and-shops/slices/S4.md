# S4. Shops, prices and the sell share in content

Part of [the gold and shops plan](../README.md). Decisions 378, 381, 385. ADR 0011 (content only in `content/`), ADR 0002 (JSON straight into Core records). After S3. Design: [design.md](../design.md), "Tunables", "Structure and folder dependencies" (Data).

- **S4. Shops, prices and the sell share in content, checked by the loader** (Core + Data + content, about 240 lines)
  - **Goal:** `items.json` gives prices, `shops.json` the shops (a general store, placeholder), `rules.json` the `trade` share; the loader checks them (the forge lesson: a check needing another file is called once both are loaded), and the catalog holds the shops by id.
  - **New types:**
    - `Data/Trade/ShopCatalogValidator`: the rules for `shops.json`, checked against the loaded items: ids unique, a name, at least one item, no null entry, every item known and priced, none listed twice; each problem names the shop and the file.
  - **Changes:**
    - `Content/ContentCatalog.Shops` (required, by id).
    - `Data/Content/ContentCatalogLoader`: reads `shops.json` after the items and calls the validator with `itemsById`; `rules.json` `trade` read into `GameRules.Trade`.
    - `Data/Items/ItemCatalogValidator`: a price, when given, is 1 to `Purse.MaxGold`.
    - `Data/Content/GameRulesValidator`: `trade.sellPercent` 0 to 100.
    - Content: `shops.json` (`general_store`, "General Store"), prices on every item but the materials, `rules.json` `trade: { "sellPercent": 50 }` (design.md, "Tunables"; placeholders).
    - Catalog sites: `ContentCatalogBuilder`, `BattleSceneTests` (empty `Shops`).
  - **Tests:**
    - `ShopCatalogValidatorTests: Validate_UnknownItem_ThrowsNamingTheShop` (new file)
    - `ShopCatalogValidatorTests: Validate_UnpricedItem_Throws`
    - `ShopCatalogValidatorTests: Validate_ItemListedTwice_Throws`
    - `ShopCatalogValidatorTests: Validate_NoItems_Throws`
    - `ShopCatalogValidatorTests: Validate_NullItemId_Throws` (the serializer doesn't apply nullable annotations to list elements)
    - `ShopCatalogValidatorTests: Validate_RepeatedShopId_Throws`
    - `ShopCatalogValidatorTests: Validate_BlankName_Throws`
    - `ItemCatalogValidatorPriceTests: Validate_ZeroPrice_Throws` (new file: `ItemCatalogValidatorTests` is 248)
    - `ItemCatalogValidatorPriceTests: Validate_PriceAboveMaxGold_Throws`
    - `GameRulesValidatorTests: Validate_NegativeSellPercent_Throws`
    - `GameRulesValidatorTests: Validate_SellPercentAbove100_Throws`
    - `ContentCatalogLoaderShopTests: Load_Repository_GeneralStoreListsPricedItems` (new file: `ContentCatalogLoaderTests` is 272)
    - `ContentCatalogLoaderShopTests: Load_ShopNamingUnpricedItem_ThrowsNamingTheFile`
  - **Call sites:** `ContentCatalog` initializers (3).
  - **Watch:** the editor doesn't write `items.json` or `shops.json` (shops are edited by hand, README "Out of scope"); a Data test that counts content files may need the new one.
  - **Verify by hand:** start the game: it loads; break `shops.json` (an unknown item id): the start stops naming the file and the shop.
- **Done, with deviations:** `BattleSceneTests` needed no change (it builds its catalog with `with`, not an initializer); only the loader and `ContentCatalogBuilder` (`WithShops`) initialize `Shops`. The validator tests are one theory over six broken shops plus the repeated-id case; the price and sell-share bounds are theories over both ends, with the valid bounds in a second theory each. The placeholder general store sells eight items; every non-material item got a placeholder price (20 to 300). No Data test counts the content files. The review dropped a null-list check the strict reader already covers and put the sell-share check on `RangeProblems.Within`. Tests 2988 → 3007.
