# X1. Split `ExplorationState`: starting events

Part of [the gold and shops plan](../README.md). The backlog's "When next touched" line from the new-game flow plan: `Core/Exploration/ExplorationState.cs` (296) "should split it first: starting events (arrival, cell, touch) apart from walking". ADR 0006, ADR 0016, decision 38. Design: [design.md](../design.md), "Replacement mapping", "Risks".

- **X1. Split `ExplorationState`: starting events into `EventStarter`** (Core refactor, about 120 lines moved, tests unchanged)
  - **Goal:** `ExplorationState` keeps walking, the interaction prompt and the running event; which event starts next moves to its own type, so I1 can add the inn's state without crossing 300 lines. No behavior changes.
  - **New types:**
    - `Core/Exploration/EventStarter`: internal sealed; finds the map event that starts next: on arrival (once the map is entered and no event runs), on entering a cell, on touch (armed after standing still, decision 38), or on interact. Holds `_isTouchArmed` and `_isArrivalPending`; built per map entry or reset by `ExplorationState.EnterMap`.
  - **Changes:**
    - `Exploration/ExplorationState`: `TryStartCellEvent`, `StartArrivalEvent`, the touch check of `WalkAndTrigger` and their flags move to `EventStarter`; `Start(triggered)` stays (it owns `_run`) and takes what the starter finds. Summaries rewrapped; the backlog line is removed.
  - **Tests:** existing tests pass unchanged (`ExplorationArrivalTests`, `ExplorationWarpTests`, `ExplorationEncounterTests`, the touch and cell event tests, `EventRunTests`); test counts before and after are equal. `EventStarter` is internal and reached through `ExplorationState`, so it gets no tests of its own.
  - **Watch:** decision 38's arming (a touch event waits until the player stood still since entering the map or the last touch) and ADR 0016's order (arrival waits for the warping event to end) are the subtle parts: keep their comments with the code that now holds them. If the split runs past about 150 lines, stop and ask: I1 can add its three lines (296 → 299) and this slice return to the backlog.
  - **Verify by hand:** walk through a door, into the forest and back (touch, cell and arrival events); a new game's intro still plays.
