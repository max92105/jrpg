# C1. Map tracks in content

Part of [the music and sound effects plan](../README.md). After V1. Decision 419. Design: [design.md](../design.md), "Tunables and placeholders", "Core changes", "Key decisions" 9, "Risks" (content written back).

- **C1. A map's track in content, checked at startup; placeholder map tracks** (Core + Data + content, about 170 lines)
  - **Goal:** a map's settings may name a `musicFile` in `content/audio/music/`; a named file must exist by exact name, or the game doesn't start and names the file and the map. A map without one is silent (decision 419). Nothing plays yet (P2).
  - **New files:**
    - `.claude/scripts/new-placeholder-tone.ps1`: writes a 16-bit PCM mono 22 050 Hz WAV of one or more sine frequencies (`-Path`, `-Frequencies`, `-Seconds`, `-Amplitude`, `-FadeMilliseconds`, 0 by default). Each frequency is rounded so frequency × seconds is a whole number of cycles, so a loop meets its start with no seam; effects pass `-FadeMilliseconds 5`. A comment says it makes placeholders only.
    - `content/audio/music/PlaceholderTown.wav`, `PlaceholderForest.wav` (4 s chords, whole cycles, no fades).
  - **Changes:**
    - Core `Maps/MapSettings.MusicFile` (`string?`, init, after `DisplayName`; doc: the track the map loops, in the music folder; null for silence, decision 419).
    - Data `Content/AbsentWhenNullFilter`: `(typeof(MapSettings), "musicFile")`, with its reason comment (maps written before the field).
    - Data `Audio/AudioFolders.Music = "music"`; the summary lists it.
    - Data `Audio/AudioReferenceCheck.FindProblems`: map tracks (`Named by map '<id>'`) checked like voices, in id order; the voice loop becomes a private `AddMissingByExactName(problems, audioRoot, folder, references)`, as `ArtReferenceCheck` has, which C2 and B3 reuse; the summary lists what it checks.
    - Content: `maps/start.json` and `maps/interior_1.json` `"musicFile": "PlaceholderTown.wav"`, `maps/forest.json` `"PlaceholderForest.wav"`, each after `displayName`.
  - **Tests:**
    - `AudioReferenceCheckTests` (53 lines): `FindProblems_MapTrackMissing_NamesTheFileAndTheMap`, `FindProblems_MapTrackInOtherCase_NamesTheMismatch`; `FindProblems_RepositoryContent_FindsNothing` (exists) now covers the tracks.
    - `ContentWriterTests` (or the map settings writer test): `Write_MapWithoutMusic_LeavesTheFieldOut` (fails without the filter: a `null` is written).
    - Existing round-trip tests on the repository maps pass unchanged (the field order matches the files).
  - **Verify by hand:** rename `PlaceholderForest.wav` to `placeholderforest.wav` and start the game: the error screen names the file, the case mismatch and map `forest`; rename it back. Play `PlaceholderTown.wav` on a loop in any player: no click at the loop.
