# C1. Map tracks and encounter themes in content

Part of [the music and sound effects plan](../README.md). After V1. Design: [design.md](../design.md), "Tunables and placeholders", "Core changes", "Risks" (content written back).

- **C1. A map's track and an encounter's theme in content, checked at startup; placeholder tracks** (Core + Data + content, about 190 lines)
  - **Goal:** a map's settings may name a `musicFile` and an encounter may name its own `musicFile` (the boss hook, Q6); both must exist in `content/audio/music/` by exact name, or the game doesn't start and names the file and what names it. Nothing plays yet (P2).
  - **New files:**
    - `.claude/scripts/new-placeholder-tone.ps1`: writes a 16-bit PCM mono 22 050 Hz WAV of one or more sine frequencies for a number of seconds, with 5 ms fades at each end (`-Path`, `-Frequencies`, `-Seconds`, `-Amplitude`); a comment says it makes placeholders only.
    - `content/audio/music/PlaceholderTown.wav`, `PlaceholderForest.wav`, `PlaceholderBoss.wav` (4 s chords; design.md's table).
  - **Changes:**
    - Core `Maps/MapSettings.MusicFile` (`string?`, init, after `DisplayName`; doc: the looping track in the music folder, null for silence).
    - Core `Battle/EncounterDefinition.MusicFile` (`string?`, init; doc: the encounter's own theme, a boss's; null for the battle theme).
    - Data `Content/AbsentWhenNullFilter`: `(typeof(MapSettings), "musicFile")` and `(typeof(EncounterDefinition), "musicFile")`, each with its reason comment.
    - Data `Audio/AudioFolders.Music = "music"`; the summary lists it.
    - Data `Audio/AudioReferenceCheck.FindProblems`: map tracks (`Named by map '<id>'`) and encounter themes (`Named by encounter '<id>'`) checked like voices, in id order; the shared voice loop becomes a private `AddMissingByExactName(problems, audioRoot, folder, references)` as `ArtReferenceCheck` has; the summary lists what it checks.
    - Content: `maps/start.json` and `maps/interior_1.json` `"musicFile": "PlaceholderTown.wav"`, `maps/forest.json` `"PlaceholderForest.wav"` (after `displayName`); `encounters.json` `training_dummy` `"musicFile": "PlaceholderBoss.wav"`.
  - **Tests:**
    - `AudioReferenceCheckTests` (53 lines): `FindProblems_MapTrackMissing_NamesTheFileAndTheMap`, `FindProblems_MapTrackInOtherCase_NamesTheMismatch`, `FindProblems_EncounterThemeMissing_NamesTheEncounter`; `FindProblems_RepositoryContent_FindsNothing` (exists) now covers the tracks.
    - `ContentWriterTests` (or the map settings writer test): `Write_MapWithoutMusic_LeavesTheFieldOut` (fails without the filter: a `null` is written).
    - Existing round-trip tests on the repository maps pass unchanged (the field order matches the files).
  - **Verify by hand:** rename `PlaceholderForest.wav` to `placeholderforest.wav`, start the game: the error screen names the file, the case mismatch and map `forest`; rename it back.
