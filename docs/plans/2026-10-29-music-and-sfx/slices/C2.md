# C2. The game-wide audio file

Part of [the music and sound effects plan](../README.md). After C1 and the ADR on game-wide audio names (README, "ADRs needed"). Design: [design.md](../design.md), "Tunables and placeholders", "Core changes", "Key decisions" 4.

- **C2. The game-wide audio file: title and battle themes, every effect's file, checked at load and startup** (Core + Data + content, about 235 lines)
  - **Goal:** `content/audio.json` names the title theme, the battle theme and one file per effect id; loading refuses it unless both themes are named and every id in Data's closed list is named once, with no other id; the startup check refuses a named file missing from `music/` or `effects/` by exact name. Nothing plays yet.
  - **New types:**
    - Core `Content/AudioDefinition` (public sealed record): the game-wide audio files content names. `TitleThemeFile`, `BattleThemeFile` (`string?`, init), `EffectFiles` (`IReadOnlyDictionary<string, string>`, init, default empty); `new AudioDefinition()` is silence (test catalogs).
    - Data `Audio/SoundEffectIds` (public static): the closed list of effect ids the Game plays, one constant each (`MenuMove = "menuMove"`, ... design.md's list) and `All` (`IReadOnlyList<string>`, in that order).
    - Data `Audio/AudioDefinitionValidator` (internal static): `Validate(string fileName, AudioDefinition audio)`; throws `ContentValidationException` naming the file and the field: a theme missing or blank, an id of `All` missing, an unknown id, a blank file.
  - **Changes:**
    - Core `Content/ContentCatalog.Audio { get; init; } = new();` (not required: no test catalog changes).
    - Data `Content/ContentCatalogLoader`: `private const string AudioFile = "audio.json"`; read and validated with `ReadValidated`, set on the catalog.
    - Data `Audio/AudioFolders.Effects = "effects"`.
    - Data `Audio/AudioReferenceCheck`: both themes in `music/` (`Named by audio.json`), every effect file in `effects/` (`Named by audio.json effect '<id>'`), through C1's shared loop.
    - Content: `content/audio.json`; `content/audio/music/PlaceholderTitle.wav`, `PlaceholderBattle.wav`; `content/audio/effects/Placeholder<Cue>.wav` for each id (generated with C1's script, pitches in design.md's spirit: higher for confirm, lower for cancel, a click for typing).
  - **Tests:**
    - `AudioDefinitionValidatorTests` (new): `Validate_RepositoryShape_Passes`, `Validate_EffectIdMissing_NamesTheId`, `Validate_UnknownEffectId_NamesTheId`, `Validate_TitleThemeMissing_NamesTheField`, `Validate_BlankEffectFile_NamesTheId`
    - `ContentCatalogLoaderAudioTests` (new file: `ContentCatalogLoaderTests` is 272): `Load_RepositoryContent_ReadsEveryEffectFile` (`SoundEffectIds.All` all present), `Load_WithoutAudioFile_NamesTheFile`
    - `AudioReferenceCheckTests`: `FindProblems_EffectFileMissing_NamesTheId`, `FindProblems_BattleThemeMissing_NamesAudioJson`
  - **Verify by hand:** remove `menuMove` from `audio.json`: the game's error screen names `audio.json` and `menuMove`; restore it. The editor still opens (it loads the catalog).
