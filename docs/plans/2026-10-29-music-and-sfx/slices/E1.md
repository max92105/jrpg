# E1. The map's track in the editor

Part of [the music and sound effects plan](../README.md). After C1 (the field) and P2 (so a choice can be heard in the game). Design: [design.md](../design.md), "What exists" (editor), "Risks" (`MainViewModel` size).

- **E1. The editor's map settings choose the map's track** (Editor + Data, about 170 lines)
  - **Goal:** the map settings dialog has a Music box listing "(none)" and every `.wav` in `content/audio/music/`, by exact name, sorted; the map's track starts selected. OK applies it with the other settings as one undo step (Ctrl+Z undoes it); Ctrl+S writes `musicFile` (left out when none). The box offers only files that exist, so the editor can't write a track the startup check would refuse.
  - **Changes:**
    - Data `Audio/AudioFolders.FilesIn(string audioRoot, string folder)`: the `.wav` names in that folder, sorted ordinally; empty when the folder is missing.
    - Editor `Maps/Settings/MapSettingsViewModel`: constructor `(MapDefinition map, IEnumerable<string> encounterIds, IReadOnlyList<string> musicFiles)` (a lookup, not a folder read); `MusicChoices` (`"(none)"` first, then the files), `[ObservableProperty] SelectedMusic`; `ToSettings()` sets `MusicFile` (null for "(none)"); `AreSame` compares it. A map whose track isn't in the folder keeps it listed and selected, so opening the dialog never changes it. The summary names the music.
    - Editor `Maps/Settings/MapSettingsWindow.xaml`: a "Music" label and a `ComboBox` bound to `MusicChoices`/`SelectedMusic`, after the name (the theme's combo template applies).
    - Editor `Shell/MainViewModel.StartEditingSettings()` (one line): passes `AudioFolders.FilesIn(AudioFolders.RootIn(contentRoot), AudioFolders.Music)`. `MainViewModel` is already 490 lines: if the verify script refuses changing it, `MainWindow.xaml.cs` builds the list and passes it instead.
  - **Tests:**
    - `MapSettingsViewModelTests` (110): `Constructor_MapWithATrack_SelectsIt`, `ToSettings_NoneChosen_HasNoMusicFile`, `AreSettingsChanged_OnlyMusicChanged_IsTrue`, `Constructor_TrackNotInTheFolder_KeepsItSelected`
    - `AudioFoldersTests` (new): `FilesIn_RepositoryMusic_ListsThePlaceholdersSorted`, `FilesIn_MissingFolder_IsEmpty`
    - Existing `MapSettingsViewModelTests` constructions (about 8) gain `[]` for the music files.
  - **Verify by hand:** open `forest`, Map settings: Music shows `PlaceholderForest.wav`; choose `PlaceholderTown.wav`, OK, Ctrl+S: `maps/forest.json` has the town track; Ctrl+Z puts it back; choose "(none)" and save: the field is gone from the file. Run the game: the forest is silent; restore the file with git.
