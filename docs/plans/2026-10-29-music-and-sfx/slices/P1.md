# P1. The music the flow calls for, headless

Part of [the music and sound effects plan](../README.md). After C1 and ADR 0035. Decisions 416, 419, 425. Design: [design.md](../design.md), "Key decisions" 1, 2 and 7, "Replacement mapping".

- **P1. The music the flow calls for, headless: the title theme, the map's track, the battle theme from the flash** (Game, about 220 lines; adds no view type)
  - **Goal:** after every update, the flash's included, the flow writes into a music channel the track its state calls for: the title theme while no game is on (title and leader choice), the battle theme from the encounter's flash until the session finishes the battle, otherwise the current map's track (silence on a map without one). Nothing is heard yet (P2); tests read the channel. Until B4, the map's track comes back when the outcome screen opens (`FinishBattle` clears the pending encounter there); B4 puts the fanfare's silence first.
  - **New types:**
    - `Audio/MusicChannel`: the track the game wants heard now, by file in the music folder, or null for silence. `Track`, `Want(string? file)`.
    - `Audio/AudioChannels`: the channels the flow and scenes write during an update and the host plays after it. `Voice` (the existing `VoiceChannel`), `Music`; S1 adds `Effects`.
    - `Flow/MusicSelection` (internal static, pure): the track the flow's state calls for. `public static string? TrackFor(GameSession? session)` (B4 adds the battle screen's cue).
    - `Ui/UiSoundFiles` (internal static): the sound files the code plays that no content names, grouped by audio folder (decision 425). Here `Music`: `Title = "PlaceholderTitle.wav"`, `Battle = "PlaceholderBattle.wav"`.
  - **New files:** `content/audio/music/PlaceholderTitle.wav`, `PlaceholderBattle.wav` (C1's script, whole cycles, no fades).
  - **Changes:**
    - `Flow/SceneFactory.Voice` → `Audio` (`AudioChannels`); `CreateExploration` passes `Audio.Voice` to `EventPresenter` (its constructor unchanged).
    - `Flow/GameFlow` (254, about +8): `Voice` → `Audio`; a private `FollowMusic()` (`Audio.Music.Want(MusicSelection.TrackFor(Session))`) called on every path out of `Update`, the flash's early return included.
    - `Program.FirstScene` returns `(IScene Scene, AudioChannels Audio)`; the error screen's is `new AudioChannels()`. `JrpgGame` takes `AudioChannels audio` and follows `audio.Voice`.
  - **Tests:**
    - `MusicSelectionTests` (new): `TrackFor_NoSession_IsTheTitleTheme`, `TrackFor_OnAMapWithATrack_IsTheMapsTrack`, `TrackFor_OnAMapWithoutATrack_IsSilence` (a test map built without one, not a repository map), `TrackFor_EncounterPending_IsTheBattleTheme`
    - `GameFlowMusicTests` (new file: `GameFlowTests` is 321): `Update_OnTheTitle_AsksForTheTitleTheme`, `Update_DuringTheFlash_AsksTheBattleTheme` (a step that starts a battle; read during the flash, while the scenes don't update; seed-independent, as the flow lessons require), `Update_NewGameStarted_AsksForTheStartMapsTrack`
    - `UiSoundFilesTests` (new, as `UiArtFilesTests`): `EveryConstant_ExistsInItsFolder` (a theory per group and folder; the exact name, case included, compared with the folder's file list, since `File.Exists` ignores case on Windows), `EveryGroup_IsCheckedAbove`
    - The 15 `new VoiceChannel()` test sites: unchanged.
  - **Verify by hand:** none (nothing plays); the flow tests play it headless.
