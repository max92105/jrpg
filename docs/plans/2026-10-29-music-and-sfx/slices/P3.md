# P3. The map's track pauses and resumes

Part of [the music and sound effects plan](../README.md). After P2. Decisions 416, 417. ADR 0035 (release). Design: [design.md](../design.md), "Tunables" (resume fade-in), "Key decisions" 4.

- **P3. The map's track pauses for a battle and resumes where it was with a short fade-in; a track left is released** (Game, about 220 lines; adds no view type)
  - **Goal:** a change of track is still a cut, but the track left is paused rather than stopped; if it is wanted again it resumes where it paused, its volume rising over `ResumeFadeIn` (0.5 s placeholder), so after a battle the map's track comes back where it was (decisions 416, 417). Only one track waits paused; an older one is dropped. Silence drops the playing track and keeps the paused one (for B4's fanfare). A dropped track is released (its instance and its loaded sound), except the tracks the host keeps loaded (the two themes). No crossfade and no turning back mid-fade: a change during the fade-in is a cut like any other.
  - **New types:**
    - `Audio/MusicMix`: which track plays at what gain, and which one waits paused. `Want(string? file)`, `Advance(TimeSpan delta)`; `Playing` (`string?`), `PlayingGain` (0..1), `Paused` (`string?`), `ResumeFadeIn` (0.5 s). Pure, no MonoGame.
  - **Changes:**
    - `Audio/MusicPlayer` (P2's cut, constructor `(SoundLibrary sounds, IReadOnlyList<string> keptLoaded)`): keeps an instance per file in the mix (at most two); each `Follow` calls `_mix.Want(music.Track)` and `_mix.Advance(delta)`, then compares the mix with the last update: a newly paused track is `Pause()`d, a resumed one `Resume()`d, a new one started, a dropped one stopped, disposed and released unless kept; the playing instance's `Volume = gain × PlayingGain`. `Follow` gains the delta: `Follow(MusicChannel music, float gain, TimeSpan delta)`.
    - `Audio/SoundLibrary.Release(string folder, string file)`: disposes a loaded sound and forgets it, so a later `Get` loads it again.
    - `JrpgGame`: builds the player with `[UiSoundFiles.Music.Title, UiSoundFiles.Music.Battle]` kept; `Update` passes `gameTime.ElapsedGameTime`.
  - **Tests** (`MusicMixTests`, new):
    - `Want_NewTrack_PlaysItAtFullGain`
    - `Want_NewTrack_PausesTheOneBefore`
    - `Want_ThePausedTrack_ResumesItFromSilence` (gain 0, `Paused` empty, the one playing dropped)
    - `Advance_HalfTheFadeIn_GainIsHalf`
    - `Advance_PastTheFadeIn_GainIsFull`
    - `Want_Silence_DropsThePlayingTrackAndKeepsThePausedOne`
    - `Want_ThirdTrack_DropsTheOlderPausedOne`
    - `Want_SameTrack_ChangesNothing`
  - **Verify by hand:** a forest battle: the forest track stops at the flash; back on the map it fades in from the note it stopped on. The town and the forest in turn: each change cuts; walking back to a map just left resumes its track. Task Manager over a few battles: memory doesn't climb (dropped tracks are released).
