# S3. Cues on the game menu's tabs, Options and System

Part of [the music and sound effects plan](../README.md). After S1. Pending Q7. Design: [design.md](../design.md), "Key decisions" 3.

- **S3. Cues on the game menu's tabs, the Options page and the System page** (Game, about 190 lines; adds no view type)
  - **Goal:** in the game menu, Up and Down on the tabs tick `menuMove`, Confirm into a page `menuConfirm`, Cancel back to the tabs or out of the menu `menuCancel`. Inside a page the page's own ids are added: Options ticks on a row change and sounds `menuMove` on a value change (Left, Right; Q7 may give it its own cue); System ticks, confirms Save and Load, and its save and load lists use `SaveFilesPanel`'s ids (S1).
  - **Changes:**
    - `Menus/IMenuPage.Sounds` (default interface member, `=> []`): the effect ids the page's last update asks for; the summary of `IMenuPage` is unchanged otherwise.
    - `Menus/GameMenuScene` (223, about +12): an `AskedSounds`, cleared as `Update` starts; tab moves, entering, leaving and closing ask theirs; after a page's update, `AskAll(page.Sounds)`; `Sounds` overrides the default.
    - `Menus/OptionsPage` (about 200 after V1, +8): its `AskedSounds`; a row move and a value change ask `menuMove`; a value at its end that doesn't change asks nothing.
    - `Menus/SystemPage` (200, +8) and its save and load pages (`SavePage`, `LoadPage`): their lists through `SaveFilesPanel.Sounds`; a save written asks `menuConfirm`.
  - **Tests:**
    - `GameMenuSceneSoundTests` (new; `GameMenuSceneTests` is 224): `Update_DownOnTheTabs_AsksMenuMove`, `Update_ConfirmOnATab_AsksMenuConfirm`, `Update_CancelInAPage_AsksMenuCancel`, `Update_PageAsksASound_SceneAsksIt`
    - `OptionsPageTests`: `Update_RightOnMusic_AsksMenuMove`, `Update_RightOnVoicesAtMax_AsksNothing`
    - `SystemPageTests`: `Update_ConfirmOnSave_AsksMenuConfirm`
  - **Verify by hand:** open the menu on the map: tabs tick, entering a page sounds, Cancel back sounds lower; Options: rows tick, values tick, an end stop is silent; set Effects to 0 in Options: the menu falls silent at once.
