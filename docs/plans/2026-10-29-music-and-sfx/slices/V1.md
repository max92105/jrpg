# V1. Volumes in the Options page

Part of [the music and sound effects plan](../README.md). First slice. Design: [design.md](../design.md), "Tunables", "Key decisions" 6.

- **V1. Music, Effects and Voices volumes in the Options page; the voice-over follows its volume** (Game + text, about 190 lines; adds no view type)
  - **Goal:** the Options page lists Full screen, Text speed, Music, Effects and Voices; Left and Right step a volume between 0 and 10, stopping at either end, and the voice-over is heard at the Voices volume at once (even mid-line). Music and Effects change values nothing plays yet (P2, S1). Kept for this run only, as the other options (Q1).
  - **New types:**
    - `Hosting/VolumeLevel` (internal static): a volume setting's eleven steps read as a gain. `public const int Max = 10`; `public static float GainOf(int level)` (`level / 10f`, the placeholder curve; throws `ArgumentOutOfRangeException` outside 0..10).
  - **Changes:**
    - `Hosting/PlayerSettings`: `MusicVolume` (7), `EffectsVolume` (8), `VoiceVolume` (10), `int` levels with `{ get; set; }`; the summary names who reads them (the host's players).
    - `Menus/OptionsPage` (162, about +30): rows `MusicRow`, `EffectsRow`, `VoicesRow`, `RowCount = 5`; `Change(step)` becomes a switch on the row (full screen flips, text speed and volumes step and clamp at their ends; a private `Stepped(int level, int step)` keeps the complexity down); `ValueOf(row)` reads each volume's text from a `MeasuredText[] _levels` built once for 0..10 (no per-frame formatting). The summary's "Kept for this run only (question 89)" stays.
    - `Audio/VoicePlayer.Follow(VoiceChannel voice, float gain)`: sets `_playing.Volume = gain` every call (cheap), so a change is heard mid-line; the summary says so.
    - `JrpgGame.Update`: `_voicePlayer?.Follow(_voice, VolumeLevel.GainOf(_settings.VoiceVolume))`.
    - `content/text/ui.json` + `Ui/MessageIds`: `OptionsMusicVolume` ("Music"), `OptionsEffectsVolume` ("Sound effects"), `OptionsVoiceVolume` ("Voices"); the MessageIds test covers them.
  - **Tests:**
    - `VolumeLevelTests: GainOf_Max_IsOne`, `GainOf_Zero_IsSilent`, `GainOf_AboveMax_Throws`
    - `OptionsPageTests` (107 lines): `Update_RightOnMusic_RaisesItOneStep`, `Update_LeftOnEffectsAtZero_StaysAtZero`, `Update_RightOnVoicesAtMax_StaysAtMax`, `Update_DownFromTextSpeed_SelectsMusic` (row order)
    - Existing `OptionsPageTests` that walk the rows by count: re-checked (a wrap from the last row now lands elsewhere); budget 2 fixes.
  - **Verify by hand:** start a new game as a leader with an intro; open the menu during play, set Voices to 3, start the intro again from a new game: the voice-over is quieter; 0 is silent. Options shows five rows, the values with their diamonds.
