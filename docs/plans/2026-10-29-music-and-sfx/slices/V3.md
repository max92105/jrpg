# V3. Settings kept between runs

Part of [the music and sound effects plan](../README.md). **Only if Q1 answers that settings are saved between runs** (question 89); otherwise this slice is dropped. After its ADR (README, "ADRs needed"). Design: [design.md](../design.md), "Risks" (settings not saved).

- **V3. Settings kept between runs** (Game, about 170 lines; adds no view type)
  - **Goal:** full screen, text speed and the three volumes are written to a settings file when the game menu closes (and on quitting), and read at startup; a missing file gives today's defaults; a broken or out-of-range one is reported once and gives the defaults, never stops the game. The window opens in the saved mode.
  - **New types:**
    - `Hosting/SettingsFile(string path)`: reads and writes the player's settings as JSON. `PlayerSettings Read()` (defaults when missing or broken, reported through `DeveloperLog`), `void Write(PlayerSettings settings)` (atomic: a temporary file then a move, as saves are written).
  - **Changes:**
    - `Hosting/GamePaths.SettingsPath` (`%LocalAppData%/Jrpg/settings.json`, beside the saves).
    - `Hosting/PlayerSettings`: "for this run only (question 89)" leaves its summary; levels and the text speed clamped on read.
    - `Program`: `new SettingsFile(GamePaths.SettingsPath).Read()` instead of `new PlayerSettings()`; writes on exit.
    - `Flow/MenuTransitions.Close`: writes the settings (the Options page lives in the menu); the writer reaches it through `SceneFactory` or `GameFlow` without passing a fifth constructor parameter (the ADR settles where).
    - `Menus/OptionsPage`'s summary loses "Kept for this run only".
  - **Tests** (`SettingsFileTests`, new, in a temporary folder):
    - `Read_NoFile_GivesTheDefaults`
    - `Write_ThenRead_GivesTheSameSettings` (round trip)
    - `Read_BrokenJson_GivesTheDefaults`
    - `Read_VolumeOutOfRange_ClampsIt`
    - `Read_UnknownTextSpeed_GivesNormal`
  - **Verify by hand:** set Music to 3 and Text speed to Fast, close the menu, quit, start again: both kept. Corrupt the file by hand: the game starts with defaults and one line in the Output window.
