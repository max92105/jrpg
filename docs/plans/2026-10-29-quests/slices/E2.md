# E2. The event dialogs set an event's quest condition

Part of [the quests plan](../README.md). After E1 and QV. Q4's condition kinds. Design: [design.md](../design.md), "Key decisions" (conditions as one list entry).

- **E2. The event dialogs set an event's quest condition** (Editor, about 190 lines)
  - **Goal:** beside the leader condition, both event dialogs offer a quest condition as one list: "(always)", then per quest "not started", "active", "at <stage>" for each stage, "completed"; an event's one-line summary says it ("Press \"Talk\" when placeholder_errand at return_to_giver: 2 step(s)").
  - **New types:**
    - `Editor/Events/QuestConditionChoice` (internal sealed record over a `QuestCondition?`): one entry of the quest condition list with its label; null for "(always)". `static IReadOnlyList<QuestConditionChoice> AllFor(IEnumerable<QuestDefinition> quests)` builds the list in the order above.
  - **Changes:**
    - `StepChoices.QuestConditions` (init, empty by default); `EventEditingViewModel.Choices` fills it from `catalog.Current.Quests` in id order.
    - `EventViewModel.OnlyWhenQuest` (`QuestConditionChoice`, from `mapEvent.OnlyWhenQuest`), `Label` (" when x at y", " when x is active", " when x is not started", " when x is completed"), `ToEvent`.
    - `EventListViewModel` and `CellEventViewModel.QuestConditionChoices` (`[always, .. choices.QuestConditions]`, as `LeaderChoices`).
    - `ObjectEventsWindow.xaml` and `CellEventWindow.xaml`: a "Quest" combo beside the leader's.
  - **Tests:**
    - `QuestConditionChoiceTests: AllFor_TwoStageQuest_NotStartedActiveEachStageCompleted`
    - `QuestConditionChoiceTests: Label_AtStage_NamesQuestAndStage`
    - `EventQuestConditionTests: ToEvent_ConditionChosen_SetsOnlyWhenQuest`
    - `EventQuestConditionTests: ToEvent_AlwaysChosen_LeavesItNull`
    - `EventQuestConditionTests: New_EventWithCondition_SelectsItsChoice` (value equality with the list's entry)
    - `EventQuestConditionTests: Label_WithCondition_SaysWhen`
    - `CellEventViewModelTests: QuestConditionChoices_StartWithAlways`
  - **Watch:** a combo whose list lacks the event's condition (a quest removed from content) clears it, as the leader combo does; the map save would refuse the old one anyway (QV).
  - **Verify by hand:** give an NPC two Talk events, the first "when placeholder quest not started", the second "(always)"; save and reopen: both conditions are kept and the summaries say them. Ctrl+Z undoes the change.
