# E3. The Quest giver preset

Part of [the quests plan](../README.md). After E2. Design: [design.md](../design.md), "Risks" (event order is content).

- **E3. The Quest giver preset** (Editor, about 140 lines)
  - **Goal:** beside the other presets, a quest picker and a "Quest giver" button make an NPC's three Talk events for that quest, in the order that works: "not started" (an empty line, then Start quest), "active" (an empty line), "completed" (an empty line). The developer writes the lines and inserts the stage events above "active".
  - **New types:** none.
  - **Changes:**
    - `EventPresets.QuestGiver(EventIdAllocation target, string questId)`; the class summary lists it.
    - `EventListViewModel.PresetQuestId` (the picked quest; empty at first) and `ApplyQuestGiverPreset` (`[RelayCommand]`, enabled once a quest is picked), selecting the first empty dialogue step as the other presets do.
    - `ObjectEventsWindow.xaml`: the quest combo (`Choices.QuestIds`) and the "Quest giver" button beside the presets.
    - `ControlsHelpWindow`: no new gesture (a button), nothing to add.
  - **Tests:**
    - `EventPresetsTests: QuestGiver_ThreeTalkEventsGatedNotStartedActiveCompleted`
    - `EventPresetsTests: QuestGiver_NotStartedEvent_TalksThenStartsTheQuest`
    - `EventListViewModelQuestTests: ApplyQuestGiverPreset_NoQuestPicked_CannotExecute`
    - `EventListViewModelQuestTests: ApplyQuestGiverPreset_QuestPicked_SelectsTheFirstEmptyDialogue`
  - **Verify by hand:** place an NPC, open its events, pick a quest, press Quest giver: three Talk events in that order with their conditions, the first line selected; write the lines, OK, save, reopen.
