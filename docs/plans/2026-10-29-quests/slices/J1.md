# J1. The quest journal

Part of [the quests plan](../README.md). After SV (it reads `QuestLog.Progress`). Q6's order. Design: [design.md](../design.md), "Structure and folder dependencies" (`Quests` stays a leaf).

- **J1. The quest journal: active and completed quests in Core's order** (Core, about 140 lines)
  - **Goal:** Core says which quests the page lists and in which order, with the stage each is at; the page (G1) only formats it.
  - **New types:**
    - `Core/Quests/QuestJournal` (public sealed class, internal constructor over the `QuestLog` and the quest definitions): the log as the player reads it. `Active` and `Completed` (`IReadOnlyList<QuestEntry>`), built when read (the page reads them on opening, never per frame): main quests before side quests; active ones newest first, completed ones oldest first (Q6's pick).
    - `Core/Quests/QuestEntry` (public sealed record): one quest in the journal: its `Quest` (`QuestDefinition`) and the `Stage` (`QuestStage`) it is at.
  - **Changes:** `Core/Session/GameSession.Quests` (`QuestJournal`, built once in the constructor over `_context.World.Quests` and `catalog.Quests`).
  - **Tests** (`QuestJournalTests`):
    - `Active_MainAndSideQuests_MainFirst`
    - `Active_TwoSideQuests_NewestFirst`
    - `Completed_TwoQuests_OldestFirst`
    - `Active_CompletedQuest_NotListed`
    - `Active_AdvancedQuest_EntryAtTheCurrentStage`
    - `Completed_QuestCompletedAtItsStage_EntryAtThatStage`
    - `GameSessionTests: Quests_NewGame_NoActiveOrCompletedQuest`
  - **Verify by hand:** nothing to see yet; G1 shows it.
