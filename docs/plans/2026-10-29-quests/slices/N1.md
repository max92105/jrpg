# N1. The placeholder errand on the start map

Part of [the quests plan](../README.md). After E3 (content with the new steps and condition only once the editor opens them). Decision 397. Design: [design.md](../design.md), "Tunables" (placeholder giver), "Risks" (walking tests; N1 before SV).

- **N1. The placeholder errand on the start map** (content + tests, about 100 lines)
  - **Goal:** QD's placeholder errand runs on the start map, using each step and each condition kind once, so every later slice is checked by hand. The developer replaces it with real quests.
  - **Changes** (content through the editor's dialogs, or by hand in the editor's format):
    - `content/map-layouts/start.json`: a new placed `villager` (`quest_giver`, the shared placeholder sprite, ADR 0015) on a cell off the tests' paths (design.md, "Risks"); its Talk events, in this order (the first that may start wins):
      1. not started: a line, then `startQuest`;
      2. completed: a thanks line;
      3. reached `return_to_giver`: a line, then `completeQuest`;
      4. active: a reminder line.
    - The innkeeper: a Talk event before its existing one, at stage `ask_innkeeper`: a line, then `advanceQuest` to `return_to_giver`. Its rest event stays last, so QV's shadowing rule passes.
  - **Tests:**
    - `RepositoryQuestTests: StartMap_QuestGiverStartsThePlaceholderErrand` (Data tests; asserts the events it needs, not totals)
    - `RepositoryQuestTests: StartMap_InnkeeperAdvancesTheErrandOnlyAtAskInnkeeper`
    - `StartMapQuestTests: Interact_QuestGiver_StartsThePlaceholderErrand` (Game tests; `StartMapScenarios.BelowQuestGiver` stands under the chosen cell)
    - `StartMapQuestTests: Interact_InnkeeperWithNoQuest_StillRunsTheRestEvent`
  - **Watch:** run the whole Game test suite after placing the NPC (a walking test could meet its collision; the innkeeper tests must still reach the rest event, priced after the gold plan).
  - **Verify by hand:** talk to the giver: the line; again: the reminder; talk to the innkeeper: the quest line, then talking again gives the inn; back to the giver: the completion line; again: the thanks line. (The page and the notices come later; a save before SV forgets the errand.)
