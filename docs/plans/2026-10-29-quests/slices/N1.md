# N1. A placeholder quest on the start map

Part of [the quests plan](../README.md). After E3 (content with the new steps and condition only once the editor opens them) and SV (its progress is saved). Q13's shape. Design: [design.md](../design.md), "Tunables" (placeholder quest and NPC), "Risks" (walking tests).

- **N1. A placeholder quest on the start map** (content + tests, about 100 lines)
  - **Goal:** one placeholder side quest runs on the start map, using every step and every condition kind once, so every later slice is checked by hand. The developer replaces it with real quests.
  - **Changes** (content through the editor's presets, or by hand in the editor's format):
    - `content/quests.json`: `placeholder_errand`, side, title "Placeholder errand", a one-line description, stages `ask_innkeeper` ("Ask the innkeeper about the road north.") and `return_to_giver` ("Bring the innkeeper's answer back.").
    - `content/maps/start`: a new placed `villager` (`quest_giver`, the shared placeholder sprite, ADR 0015) on a cell off the tests' paths (design.md, "Risks"); its Talk events in order: not started (a line, `startQuest`); at `return_to_giver` (a line, `completeQuest`); active (a reminder line); completed (a thanks line).
    - The innkeeper: a Talk event before its existing one, at `ask_innkeeper`: a line, then `advanceQuest` to `return_to_giver`.
  - **Tests:**
    - `RepositoryQuestTests: StartMap_QuestGiverStartsThePlaceholderErrand` (Data tests; asserts the events it needs, not totals)
    - `RepositoryQuestTests: StartMap_InnkeeperAdvancesTheErrandOnlyAtAskInnkeeper`
    - `StartMapQuestTests: Interact_QuestGiver_StartsThePlaceholderErrand` (Game tests; `StartMapScenarios.BelowQuestGiver` stands under the chosen cell)
    - `StartMapQuestTests: Interact_InnkeeperWithNoQuest_StillRunsTheRestEvent`
  - **Watch:** run the whole Game test suite after placing it (a walking test could meet the new NPC's collision; the innkeeper tests must still reach the rest event).
  - **Verify by hand:** talk to the giver: the line, then the Quests tab lists "Placeholder errand"; talk again: the reminder; save, quit, load: still listed; talk to the innkeeper: the quest line, then talking again gives the usual rest; back to the giver: the completion line, the Quests page empty (completed ones show from G3); again: the thanks line.
