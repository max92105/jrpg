# L1. The old tilesheet images leave

Builds on C3 (the developer removed the old sheets in the editor, E3a) and AS1's manifest. Had an image left before its sheet, the editor would have marked its tiles (X1) and E3c would have taken it out; this slice is the ordinary path.

## Goal
The old tilesheet images that no sheet names are deleted from `content/art/tilesheets/`, with their manifest entries; the repository's art is Mana Seed plus whatever the manifest flags as placeholder.

## Changes
- Before anything: `ArtReferenceCheck` on the repository finds nothing, and `tilesheets.json` names none of the files to delete (grep each name). A file still named stays, and the slice says which and why.
- `git rm` the old images (`City.png`, `Grass1.png`, `Grass2.png`, `Ground.png`, `RA_Ground_Tiles.png`, `RA_Jungle.png`, `RA_Jungle_Animations.png`, `tree01_s_01_animation.png`, `Water1.png`, `Water2.png`, and `FG_Forest_Fall.png` if the developer dropped it).
- `content/art/art-sources.json`: their entries leave; a source left with no file leaves too, and its CREDITS section with it.
- `docs/plans/backlog.md`: the plan's follow-ups are already there; add any found while rebuilding.
