# M1. Mana Seed cuts

Builds on design.md, "Key decisions" 5, 6 and 7, and "Tunables" (the Mana Seed cut).

## Goal
Setting up a Mana Seed sheet takes no correction: the guess is 16 px, the id from a pack file name is tidy, and a non-square cut is refused in the Cut panel and by Data before it can be saved.

## Changes
- `Editor/Tiles/SheetCutGuess`: the sizes become 16 first (every Mana Seed sheet's sides are multiples of 16), then 24, else 48; the comment says why (Mana Seed is the art family, decision 438) and drops the 48-first reason.
- `Editor/Tiles/TilesheetIds.SnakeCaseOf` (or `FromFile`): runs of underscores collapse to one, and underscores at either end go (`autumn trees (bare) 80x112.png` gives `autumn_trees_bare_80_x_112`). Its summary gains the example.
- `Editor/Tiles/SheetCutViewModel.Problem`: "Tiles must be square: columns and rows give 16 x 32 px tiles." when `TileWidth != TileHeight`; the Apply button stays disabled while it shows (as for other problems).
- `Data/Maps/TilesheetCatalogValidator.FindProblem`: "tiles must be square, since the map draws each into a square cell (was 16 x 32)."
- `.claude/rules/content.md` (or `editor.md`): "Mana Seed sheets are cut at 16 x 16 px; a bigger prop is an object built from cells."
