# X1. The editor opens with missing art

Builds on decision 442 and design.md, "Key decisions" 5, "Structure" (`MissingArt`, `ArtStatus`, `MissingArtMark`).

## Goal
With a tilesheet image or an NPC's field sprite deleted, the editor opens on its maps as usual: every tile of that sheet and every such NPC draws as a marked cell on the map, inside objects and in canopies; the status band shows the art problems as a warning. Maps, tiles and objects stay editable. (The cursor status naming the sheet and the sheet box's "image missing" are X2's.) Content that fails to load (a broken JSON file) still shows `LoadError` instead of the maps, as today.

## New types
- `Editor/Catalogs/MissingArt`: which sheets' images and which NPC sprites the catalog names but the art folder lacks; built from the catalog and a file-exists lookup (`Func<string, bool>` per folder), so it reads no file itself. `IsSheetMissing(sheetId)`, `IsSpriteMissing(file)`.
- `Editor/Shell/ArtStatus`: the status band's warning, from `ArtReferenceCheck.FindProblems` (the same lines the game would print, one per file); `MissingArt` for the drawing and the cursor; refreshed when `CatalogDraft.Current.Tilesheets` or `.Objects` is replaced (`Refresh()`; X2 also calls it after an import or a save).
- `Editor/Tiles/MissingArtMark`: the marked cell's picture (magenta with a dark diagonal hatch), a frozen `DrawingImage` built once.
- `Editor/Tiles/SheetImageSizes`: each tilesheet image's size in pixels, read from its header once (moved out of `MainViewModel`, the backlog's line).

## Changes
- `Editor/Shell/MainViewModel` (502 lines; the plan adds about 11 over X2, E3a, E3c and O1, so this slice makes room first, from the backlog's line): the sheet image-size cache (`_sheetImageSizes`, `SheetImageSizeOf`) moves into a new `Tiles/SheetImageSizes`, and `ImportStatusOf` becomes `SheetImportResult.Summary`, about 25 lines out. Then the two lines that turn art problems into `LoadError` go; it builds `ArtStatus` (exposed as `Art`) and the panels whenever the content loaded. Count the lines before and after in the Done note: the file ends this slice at about 480, and the plan's end below 502.
- `Editor/Tiles/TileImages`: takes `MissingArt` (through `ArtStatus`); `TileImageOf` returns `MissingArtMark`'s picture for a tile of a missing sheet, or a cell past its image's edge (a smaller image re-imported); `FieldSpriteFrameOf` does the same for a missing sprite. A mark is never cached under the tile's key, so `Forget` after an import draws the real tile.
- `Editor/Shell/MainWindow.xaml`: a warning line in the status band bound to `Art.Warning` (amber text, `BasedOn` the theme's style), shown only when there is one; the `LoadError` panel unchanged.
- `Editor/Shell/MainWindow.xaml.cs`: passes the `ArtStatus` to `TileImages` where it builds it (line 51).
