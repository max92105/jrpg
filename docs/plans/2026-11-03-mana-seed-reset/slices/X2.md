# X2. Sheets with a missing image; saving with art missing

Builds on X1 and decision 442, design.md "Key decisions" 5.

## Goal
The sheet box lists a sheet whose image is missing as "city (image missing)"; choosing it shows the notice instead of the image, and Set up and Cut stay disabled for it. Importing an image under the missing file's name puts it back (no replace question, since there is nothing to replace; the size check against the tiles cut from it still applies) and the marks turn back into tiles. Ctrl+S saves the map and the catalogs with art missing: the writer checks the content itself and refuses only what the loader would; the status band keeps the art warning. The cursor status names the sheet of a marked tile.

## New types
- `Editor/Tiles/SheetChoices`: the sheet box's list: each image in the folder with its sheets (or alone, not set up), then each sheet whose image is missing; moved out of `TileBrowserViewModel.ChoicesOf`.

## Changes
- `Editor/Tiles/SheetChoice`: `IsImageMissing`, and its label says "(image missing)".
- `Editor/Tiles/TileBrowserViewModel`: `ChoicesOf` moves to `SheetChoices` (the file shrinks first); `CanSetUpSheet`, `CanCutSheet` and the hit-testing (`CellAt`, `SelectCellAt`) return early for a choice whose image is missing, so `SheetImages.SizeOf` is never asked for a missing file.
- `Editor/Tiles/TileBrowserView.xaml(.cs)`: the "Image missing: re-import it under this name or remove the sheet" notice in place of the sheet image for such a choice.
- `Data/Content/ContentWriter.WriteMapCatalogs`: drops the `ArtReferenceCheck` call and its summary's "as the art check would"; every content check stays. `ImportTilesheetImage`: unchanged (verify by test that a missing file is copied with no question).
- `Editor/Shell/MainViewModel.Save` and `ImportSheetImages`: one `Art.Refresh()` each; `ShowCursorAt` appends `Art.NoteFor(tile.TileId)` (the lines X1 freed pay for them).
- `Editor/Shell/ArtStatus.NoteFor(int tileId)`: "  (sheet city: image missing)" for a tile of a missing sheet, else empty.
- `.claude/rules/editor.md`, "Validate on save": "...except missing art: the editor saves with an image missing and warns (decision 442); the game's startup is where the art check refuses."

## Verify by hand
- Rename `City.png` aside, start the editor: the sheet box lists "city (image missing)" with the notice; paint a tile elsewhere and Ctrl+S: it saves, the warning stays. Import `City.png` back from where it was moved: the houses draw again and the warning goes. Before that, hover a marked cell: the status names sheet `city`. Start the game with the image missing: it refuses and names the file.
