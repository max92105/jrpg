# B3. A zoom mid-drag keeps the selection's marks

Editor window, about 5 lines, hand check. Builds on design.md, "Backlog survey" (the MO2 and F2 lines). Comes before S1, which moves `ApplyViewport` into `MainWindow.Viewport`.

## Goal
During a Shift + drag of the selection, any zoom (the wheel, Ctrl+0, Ctrl+1, Fit, Actual size) leaves the selection's outlines under the dragged objects. Today `ApplyViewport` redraws the grid when the zoom changes and calls `DrawSelectionMarks`, which resets `SelectionMarks.RenderTransform` to identity, so the outlines snap back to where the drag started until the mouse moves again.

## Files
- `src/Jrpg.Editor/Shell/MainWindow.xaml.cs` (425 → about 426): in `ApplyViewport`'s zoom-changed branch, `ShowObjectDragAt(_mapPoint)` right after `DrawSelectionMarks()`. Every zoom goes through that branch, so one call covers them all; `ShowObjectDragAt` sets the marks' offset again (and a rectangle drag's stroke to the new zoom), and does nothing outside Objects mode or without a drag. `_mapPoint` is the mouse's map point from its last move: a wheel zoom keeps the point under the mouse, and a keyboard or button zoom moves the map under a still mouse until its next move, as the ghost does today.
- `docs/plans/backlog.md`: delete the MO2 line; for the F2 line, see below.

## The Space line (demo retirement, F2)
"With a button focused (Fit, Add layer), Space + drag pans, but releasing Space still clicks the button." Since the map editing flows, `OnViewportMouseDown` focuses `MapViewport` (`Focusable="True"`) before the pan starts, and a WPF button drops its Space press when it loses keyboard focus, so the click should be gone. Reproduce it first (hand check 3):
- gone: delete the backlog line, and say so in the Done note;
- still there: in `OnPreviewKeyUp`, mark the Space up handled when a pan ran while Space was held (a `_hasPannedWithSpace` flag set in `StartPanning`, cleared on Space up), and run the hand check again.

## Verify by hand
1. Objects mode, Ctrl + drag to select two objects, then Shift + drag one of them; while dragging, turn the wheel both ways: the cyan outlines stay on the dragged objects at every zoom; releasing moves both as before.
2. Ctrl + drag a selection rectangle and turn the wheel mid-drag: its outline keeps a one-pixel stroke at the new zoom.
3. Click the Fit button (or the Add layer box's button) so it has focus, hold Space, drag on the map, release Space: the map panned and the button did not click (Fit didn't refit, no layer was added).
4. Start a Shift + drag of the selection, let go of Shift while keeping the mouse button down, press Ctrl+0 (fit), then move the mouse a little: the outlines are on the dragged objects right after the fit, not back at the start.
