# D1. One `MapLayout.AllEvents`, one enum JSON name, one `SheetCell.Of`

Data and Editor, about 45 lines, no behavior change. Builds on design.md, "Dead code survey", "Folder dependencies" and "Replacement mapping", and decision 549. After X1; before R3, which works on the same Data files.

## Goal
Each of three rules is written once: a layout's events through Core's `MapLayout.AllEvents` (the quests plan's QE1 made it for this), an enum value's JSON name through `ContentJsonOptions.EnumName`, beside the serializer's own enum converter, and a tile's sheet cell through `SheetCell.Of`.

## Changes
- `src/Jrpg.Data/Content/ContentJsonOptions.cs` (36 → about 45): a private `EnumNaming` (`JsonNamingPolicy.CamelCase`) that the `JsonStringEnumConverter` is built with, and `public static string EnumName<T>(T value) where T : struct, Enum => EnumNaming.ConvertName(value.ToString())`, summary: "An enum value's name as content files spell it, the converter's spelling, for messages that name a value."
- `layout.AllEvents` replaces the inline objects-then-cells concat in:
  - `src/Jrpg.Data/Maps/MapEventValidator.cs` (241): its private `AllEvents(layout)` is deleted, its three callers read `layout.AllEvents`;
  - `src/Jrpg.Data/Maps/MapEventSteps.cs` (19): the query's second `from`;
  - `src/Jrpg.Data/Saving/WorldStateRepair.cs` (87): line 85's collection.

  Same order as today (objects' events, then cells'), so every message naming the first bad event is unchanged.
- `ContentJsonOptions.EnumName` replaces `JsonNamingPolicy.CamelCase.ConvertName(x.ToString())` in:
  - `src/Jrpg.Data/Items/StatBonusesConverter.cs` and `src/Jrpg.Data/Battle/ResistancesConverter.cs` (their name tables);
  - `src/Jrpg.Data/Crafting/CraftingRulesValidator.cs` and `src/Jrpg.Data/Loot/LootRulesValidator.cs` (their private `NameOf(Rarity)` deleted);
  - `src/Jrpg.Data/Maps/MapEventValidator.cs` (its private `JsonNameOf<T>` deleted).
- `SheetCell.Of(tile)` replaces `new SheetCell(tile.SheetId, tile.Column, tile.Row)` in `src/Jrpg.Editor/Tiles/TileBrowserViewModel.cs` (`Select`) and `src/Jrpg.Editor/Tiles/TileImages.cs` (`TileImageOf`, and `AnimatedTileIds`' `GroupBy` key). `TileImageAt`'s `new SheetCell(tile.SheetId, tile.ColumnShownAt(elapsed), tile.Row)` stays: it is a frame's cell, not the tile's.
- `docs/map.md`, Data Content row: `ContentJsonOptions` (`Strict`; `EnumName`, a value's spelling in files and messages).
- `docs/plans/backlog.md`: delete the "layout's events three times", "enum to camelCase five times" and OM2 (`SheetCell.Of`) lines.
