# X1. Dead code with evidence; `ContentWriter.WriteMap` deleted

Data, Editor and Data tests, about 90 lines (about 25 deleted in `ContentWriter`, 20 test calls rewritten, one shared test helper). Builds on design.md, "Dead code survey", decision 548 and "Risks" (X1's test moves). Before D1 and D2, which change the same Data files and writer tests.

## Goal
Every `public` or `internal` member of `src/Jrpg.Data` and `src/Jrpg.Editor` with no caller in `src/` outside its own file is listed with its fate, and the known one, `ContentWriter.WriteMap`, is gone: the editor saves through `WriteMaps` since decision 518, and only tests call it.

## The listing (the method, recorded in the Done note)
1. List the declarations: `Grep "^\s*(public|internal)\s[^=;]*\b(\w+)\s*(\(|\{|=>|;|=)"` over `src/Jrpg.Data/**/*.cs` and `src/Jrpg.Editor/**/*.cs`, keeping methods, properties, fields, constants and events; types are covered by the build (an unused `internal` type's members show up here too).
2. For each member name, `Grep "\bName\b"` over `src/` with `*.cs` and `*.xaml`, and drop the hits in its own file. A member counts as called when a hit remains, or when it is reached without its name:
   - a XAML binding or handler (`{Binding Name}`, `Click="Name"`): the `*.xaml` search finds it;
   - a toolkit hook or command (`partial void OnXChanged`, a `[RelayCommand]` method reached as `NameCommand`): grep the generated name too;
   - an interface or override member, a record's positional property read by the serializer, an `IDisposable.Dispose`.
3. The Done note's table: member, file, callers found (none, tests only), fate.

Fates:
- **Deleted in this slice** when no `src/` caller remains and its tests (if any) can move onto the member that replaced it with a mechanical edit, at most about five test sites; its tests move or go with it (a test of nothing else).
- **A `backlog.md` line** otherwise, naming the member, its test sites and why it waits.
- **Kept, with the reason in the table** when a reader is real but nameless (step 2's list).
