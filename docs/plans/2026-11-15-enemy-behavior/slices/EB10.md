# EB10. Once per battle

Core + Data + Editor, about 180 lines (Core about 25 and 5 tests; Data about 10 and 3 tests; Editor about 20 and 2
tests). Needs EB9 (the memory). Design: design.md, section 2.5 (the pick); decision 842 (trimmable: striking it removes
this slice).

## Goal
A rule may be marked once per battle: after the enemy used its skill in this battle, through any rule, it is no longer
eligible. A boss's big move happens once.

## Changes
- Core `Battle/TacticMemory`: `public bool HasUsed(string skillId)`, `public void NoteUsed(string skillId)`.
- Core `Battle/TacticMemoryNotes.Note`: an enemy actor with a `SkillCommand` notes the skill (beside forgetting its
  reactions).
- Core `Battle/EnemyAction`: `public bool IsOncePerBattle { get; init; }` ("not eligible once the enemy used its skill
  this battle, decision 842; never on the attack").
- Core `Battle/EnemyTactics`: a fourth predicate, `NotUsedUp(action, actor)`.
- Data `Battle/EnemyTacticsValidator`: `FindActionProblem` refuses `isOncePerBattle` on the attack: "tactics[0]
  (attack).isOncePerBattle: the attack can't be once per battle."
- Data `Content/AbsentWhenFalseFilter`: `(typeof(EnemyAction), "isOncePerBattle")`.
- Editor `Battle/TacticRuleRow`: observable `bool IsOncePerBattle` as `IsPriority` (EB8); the sentence ends ", once per
  battle"; `EnemyTacticsView.xaml`: a "Once per battle" check box.
- `docs/map.md`, Core `Battle` row.
