# IU13. The unique form: the fixed affix rows and the piece's price

Editor, about 210 lines (view model about 75, XAML about 30, tests about 105). Needs IU3, IU11. Design: design.md,
sections 2.3, 2.4 and 5.1; decisions 865, 866, 871, 878, 882.

## Goal
A unique (an item added with Add unique, decision 878) shows its fixed affix rows under its bonuses: Add affix adds a
row after the chosen one with the first pool affix not yet listed, its value the affix's range min; each row an affix
box (the draft's pool by id, each labelled "power: Power") and a value box, with "rolls 2..5" beside it for reference
only (decision 866: the value is free within ±100 on the affix's side of zero, Data's check); Remove and Move up and
down. The piece's whole price shows: "Price as a piece: 440, sells for 220" (`PriceFormula.PieceValue`, `SalePrice`).
No Unique box: the category is read-only (decision 878).

## New types
- `Editor/Items/UniqueAffixesViewModel` (internal sealed partial, `ObservableObject`): a unique's fixed affix rows as
  typed and the price they make.
  - `From(IReadOnlyList<RolledAffix> fixedAffixes, IReadOnlyDictionary<string, AffixDefinition> pool)`; `Rows`
    (`ObservableCollection<FixedAffixRow>`), `SelectedRow`, `AddRowCommand` (greyed with the whole pool listed),
    `RemoveRowCommand`, `MoveRowUpCommand`, `MoveRowDownCommand` (`Events/ListOrder`); `AffixChoices` from the pool by
    id.
  - `Problem`: "fixedAffixes[0] (power): Value must be a whole number (was 'x')."; Data's checks through the list.
  - `Changed` (an event): a row typed, added, removed or moved, never a `Problem` notice.
  - `ToFixedAffixes()`: each stat from the pool; throws on a problem.
  - `PieceValueLine(string priceText, int sellPercent)`: "Price as a piece: 440, sells for 220", "" while the price box
    isn't a number, "Never bought nor sold" without a price.
- `Editor/Items/FixedAffixRow` (internal sealed partial, `ObservableObject`): one fixed affix of a unique as typed:
  `Affix` (`AffixChoice`), `ValueText`, `RollLine` ("rolls 2..5"), `Problem`, `Index`.
- `Editor/Items/AffixChoice` (internal sealed record): one pool affix the row box offers: `Id`, `Stat`, `Min`, `Max`,
  `Label`.

## Changes
- `Editor/Items/ItemViewModel`: `Unique` (`UniqueAffixesViewModel?`, a unique's), its `Problem` after the equipment's,
  `ToItem` taking `Unique.ToFixedAffixes()`; `PieceValueLine` raised when the price or a row changes.
- `Editor/Items/ItemCatalogViewModel` and `ItemEditingViewModel`: pass the draft's affixes.
- `Editor/Items/ItemCatalogPage.xaml`: the Fixed affixes section, visible when `Unique` is set: the rows (affix box,
  value box on `PropertyChanged`, roll line; rows chosen by `PreviewGotKeyboardFocus`), the four buttons, the price line.
