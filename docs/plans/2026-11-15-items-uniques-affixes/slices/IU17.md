# IU17. A "+% damage" affix stat raises its wearer's damage through the modifiers' sum

Core + Data + Game, about 230 lines (about 140 of them tests), plus one `ui.json` line and an ADR 0030 amendment line.
Needs row 6's WK (`CombatStats.DamageModifierPermille`). Design: design.md, sections 2.1 and 2.2; decisions 886-888.

## Goal
The damage sheet's "gear 33 %" (decision 704): `StatKind.DamageBonus`, a percent only affixes give, summed over a
member's worn gear into their sheet and copied into `CombatStats.DamageModifierPermille`, where row 6's Weakened already
adds; so a member wearing +20 % deals Power x `perPower` x 1.2 with a tiered skill and weapon damage x Power's percent x
1.2 with the basic attack; heals and items don't change (decisions 786, 873). The Status page lists it with the other
affix stats, in a third row. No pool affix gives it yet (decision 887): the hand check makes one in the Affixes page.

## Changes
- `Core/Stats/StatKind`: `DamageBonus` last ("a percent added to the modifiers' sum of the damage its wearer deals,
  decision 704's gear modifier"); `StatKinds.AffixOnly` ends with it (screen order); `IsHeldInPermille` already counts
  it a percent.
- `Core/Stats/StatSheet`: `DamageBonusPermille { get; init; }` and its `AffixStatOf` arm.
- `Core/Party/MemberSheet`: `DamageBonusPermille = PermilleOf(worn, StatKind.DamageBonus)`.
- `Core/Battle/MemberBattleStats`: `DamageModifierPermille = sheet.DamageBonusPermille`; `StatusModifiers.Apply` (WK)
  already adds the statuses' share to it. The `CombatStats.DamageModifierPermille` summary now names gear as a source.
- `Data`: nothing new (`StatBonusesConverter` names every kind; `AffixCatalogValidator` keeps an affix-only stat above
  0; `ItemCatalogValidator` refuses it on a base item). A test pins the name `damageBonus`.
- `Game/Ui/MessageIds.Stats`: `StatDamageBonus = "stat_damage_bonus"`; `Game/Ui/StatNames`: its entry;
  `content/text/ui.json`: "Damage bonus".
- `Game/Menus/StatusParametersView`: `AffixRowsPerColumn` 3 (five stats in two columns, one cell empty). The
  arithmetic, written in the slice's Done note from the code: `SectionTitle.Height` 36, `BelowBand` 46, `RowHeight` 34;
  `CombatHeight` 46 + 7 x 34 = 284; `AffixesBottom` (46 + 4 x 34) + 16 + 46 + 3 x 34 = 346 (was 312), so the band grows
  34 px. Check the page's lower sections (Resources, skills) still end above the footer at 1080, reading
  `StatusPage`'s layout; if they don't, the Done note says what moved.
- `docs/decisions/0030-loot-rolls.md`: an amendment line (decision 887: the damage bonus joins the stats only affixes
  give).
