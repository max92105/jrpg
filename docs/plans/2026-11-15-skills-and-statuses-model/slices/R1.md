# R1. Core tests build statuses through `TestStatuses`

Tests only, about 250 lines, mechanical (about 60 of them the fixture). Runs after SR1 in the plan's order; it needs
nothing from it and must land before MS. Design: README, decision 811; design.md, section 7 ("Test churn").

## Goal
No file of `Jrpg.Core.Tests` but `Builders/TestStatuses.cs` names `StatusKind` or calls `new StatusGrant(`, reads
`ActiveStatus.Kind` or `.Power`, or passes a grant to `new Effect(` positionally. Every test passes unchanged in what
it asserts; the runner's test count is the same before and after (recorded in the Done note). MS, CH and the swap (SW)
then change only the fixture's bodies.

## New types
- `tests/Jrpg.Core.Tests/Builders/TestStatuses` (internal static): the statuses Core tests grant and compare, in one
  place, so the status model can change under them.
  - Grants: `Poison(int amount, int turns)`, `Regen(int amount, int turns)`, `Guard(int points, int turns)`,
    `Exposed(int percent, int turns)`, `Stun(int chance, int turns)`, `Taunt(int turns)`; today each is
    `new StatusGrant(StatusKind.X, number, turns)` (Taunt's number 0).
  - Identities: `PoisonId`, `RegenId`, `GuardId`, `ExposedId`, `StunId`, `TauntId`: today `StatusKind` properties;
    from SW `const string` ids.
  - Readers: `IdOf(StatusKind status)` (identity today; from SW `IdOf(StatusDefinition status)`),
    `IdOf(ActiveStatus status)`, `AmountOf(ActiveStatus status)`, `AmountOf(StatusGrant grant)`,
    `ChanceOf(StatusGrant grant)` (today all `Power`; from CH `ChanceOf` reads `Chance`).
  - `Granting(Effect effect, StatusGrant grant)`: today `effect with { Status = grant }`; from MS
    `effect with { Statuses = [grant] }`.

`new Effect(..., grant)` passing a grant positionally):

- `Battle/`: `BattleStatusTests` (20), `BattleTickingStatusTests` (18), `BattleStatusScalingTests` (9),
  `EnemyPhaseTests` (5), `BattleHitTests` (4), `BattleDominanceTests` (3), `EnemySkillTacticsTests` (3),
  `EffectScalingTests` (3), `BattleFormationTests` (2), `BattleReadyTests` (2), `BattleQuickActionTests`,
  `BattleMultiHitTests`, `EnemyTacticsTests`, `BattleGuardedTests` (1 each).
- An assertion on an event's status becomes `Assert.Equal(TestStatuses.StunId, TestStatuses.IdOf(skipped.Status))`; a

  and fresh mark compared one by one.
- `GrantScalingTests.StunChancePermille_*` (the Stun-only rule CH replaces) stay as they are: CH rewrites them (named
  there).
