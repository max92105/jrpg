# U2. Measured text

Part of [the menu cleanup plan](../README.md). Design: [design.md](../design.md), "What exists" (copies).

- **U2. Measured text** (Game, about 70 lines)
  - **Goal:** the three "text and its measured width" copies become one shared `Ui` part, used by U3 and U4. Nothing changes on screen.
  - **New types (Game):** `Ui/MeasuredText`: `internal readonly record struct MeasuredText(string Text, float Width)`. A piece of text and its width, measured once, for right-aligning or centering it.
    - `public static MeasuredText Of(SpriteFontBase font, string text)`.
  - **Changes:**
    - `PartyMemberCardView`: its nested `MeasuredText` goes; `Measured(...)` becomes `MeasuredText.Of`.
    - `PartyPage._count` uses `Ui/MeasuredText`.
    - `OptionsPage`: `ValueText` goes, and `_onOff` and `_speeds` are `MeasuredText[]`.
    - `ItemTargetPickerView.MemberCard`: `Name` + `NameWidth` become one `MeasuredText Name`. U4 replaces this card.
  - **Tests:** none new. `Of` only forwards to FontStashSharp's measuring (devil's advocate 6). The existing page and picker tests pass unchanged.
- **Done, with deviations:** as planned. The Party card's own `Name` + `NameWidth` pair stays until U4 replaces the card. Other text-with-width pairs (`InventoryPage.ItemRow`, `SaveSlotListView`, `ConfirmPromptView`, `MenuHeader`, `EquipmentChoiceView`) are follow-ups, like `InventoryLabels`.
