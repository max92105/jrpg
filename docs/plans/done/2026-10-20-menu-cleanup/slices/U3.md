# U3. The vital meter, one HP and MP format

Part of [the menu cleanup plan](../README.md). Design: [design.md](../design.md), key decision 6, tunables.

- **U3. The vital meter, one HP and MP format** (content + Game, about 200 lines; decision 110)
  - **Goal:** every HP and MP value in the menu shows as "45 / 60" (decision 110), formatted in one place, and the three copies of "HP and MP bars from vitals" become one part. The Party cards change from "45/60" to "45 / 60"; nothing else changes on screen.
  - **New types (Game):**
    - `Ui/VitalMeter`, `internal sealed`. It is one vital's bar and its value text in the shared format.
      - `public VitalMeter(ScreenText text, UiTextures ui, ImmutableArray<GradientStop> fill, int valuePixels)`.
      - `public StatBar Bar { get; }` and `public MeasuredText Value { get; }`.
      - `public void Show(int value, int max)`: fills the bar, and reformats `stat_value_of_max` only when `value` or `max` changed.
    - `Ui/MemberVitalBars`, `internal sealed`. It is a member's HP and MP meters, shown from their vitals.
      - `public MemberVitalBars(ScreenText text, UiTextures ui, int valuePixels)` makes `Hp` (`UiTheme.HpBar`) and `Mp` (`UiTheme.MpBar`).
      - `public VitalMeter Hp { get; }`, `public VitalMeter Mp { get; }`.
      - `public void Show(Vitals vitals)`.
  - **Changes (content + Game):**
    - `content/text/ui.json` gains `"stat_value_of_max": "{value} / {max}"`.
    - `Ui/MessageIds.StatValueOfMax`.
    - `PartyMemberCardView`: `VitalBar` goes. `Card` holds one `MemberVitalBars`, and `DrawBarRow` reads `meter.Bar` and `meter.Value`.
    - `ItemTargetPickerView.MemberCard` holds `MemberVitalBars` (bars only, until U4).
    - `StatusPage`:
      - `_vitalBars` becomes a `MemberVitalBars`;
      - the HP and MP stat texts come from its meters' `Value.Text`, not `$"{Hp} / {MaxHp}"`;
      - the "stat index is its bar's index" array goes.
  - **Tests (Game):**
    - `VitalMeterTests`:
      - `Show_HalfFull_FillsTheBarHalfway`;
      - `Show_Values_FormatsValueOverMax` (`"30 / 60"`);
      - `Show_SameValuesAgain_KeepsTheSameString` (same instance);
      - `Show_ValueChanged_Reformats`.
    - `MemberVitalBarsTests.Show_HurtMember_HpShowsItsHpAndMpItsMp`.
    - These use `RepositoryScreenText` for the message table, in its collection.
    - `MessageIdsTests` covers the new id.
    - Requested change: M1's `PartyPageTests.Open_AfterHpChanged_CardShowsTheNewHp` reads `CardOf(leader).Vitals.Hp.Bar.Fraction` instead of `.Hp.Bar.Fraction`. The `Card` shape changed; the assertion is the same.
    - M1's `StatusPageTests.Open_AfterHpChanged_ShowsTheNewHp` passes unchanged (same format).
  - **Verify by hand:**
    - [ ] Party cards show "45 / 60", and the values still fit right-aligned in the 100 px value column.
    - [ ] Status and the picker look as before.
- **Done, with deviations:** as planned. Status draws its HP and MP bars after the stat loop, under the first line's two columns. The picker's meters use its 14 px name size for value texts it doesn't draw yet; U4 sets the real size.
