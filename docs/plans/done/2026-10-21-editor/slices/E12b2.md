# E12b2. The New object window

Part of [the editor plan](../README.md). Builds on [E12b1](E12b1.md)'s rules and the shapes window (E9-E11b); decision 124. Split from E12b (developer, 2026-10-21).

- **E12b2. The New object window** (Editor, about 140 lines)
  - **Goal:**
    - Objects > **New object from selection...** (enabled with a rectangle chosen) asks for an **Id** and a **Category** (an editable list), with the size ("3 x 4 cells"). OK is disabled with the reason while E12b1 finds a problem.
    - On OK the object is created (E12b1); the editor switches to the Objects tab with it chosen, and opens its shapes window so the outline and zones are drawn right away (decision 124). Cancelling the shapes window keeps the object, without shapes.
  - **New types:**
    - `Objects/NewObjectWindow` (XAML + code-behind, no rules): the two fields, their problems, OK and Cancel, as `NewMapWindow`.
  - **Changes:**
    - `Shell/MainViewModel`: `CanStartNewObject` for the menu entry.
    - `Shell/MainWindow`: the menu entry, the dialog, the Objects tab, then E9's shapes window through `Placing.StartEditingShapes()`. Controls help (F1).
  - **Tests:**
    - `MainViewModelTests`: `CanStartNewObject_RectangleChosen_IsTrue`.
  - **Verify by hand:**
    - [ ] Choose a tree's cells on `tree_01_s_01_animation` (E12a); Objects > New object from selection: type `Tree 4`: refused; `tree`: refused as taken; `tree_4`, category General: OK.
    - [ ] The Objects tab shows `tree_4` under General, chosen; the shapes window is open; draw the trunk's outline and a canopy zone; OK.
    - [ ] Place `tree_4` on the map; Ctrl+S; `git diff` shows the new tiles in `tiles.json` and `tree_4` in `objects.json`; F5: the tree blocks at its trunk and covers the player with its leaves.
- **Done, with deviations:** the shapes window opens with `StartEditingChosenShapes()` (the new object is the chosen one), not `StartEditingShapes()`, which would prefer a placed object selected on the map. The dialog's Create button stays enabled; Create keeps the dialog open while a problem is shown, as New map does. `CanStartNewObject` is notified when the browser's rectangle changes.
