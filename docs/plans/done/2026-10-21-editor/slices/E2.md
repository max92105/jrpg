# E2. Menu bar and controls help

Part of [the editor plan](../README.md). Design: [design.md](../design.md), "Extension points" (a command); decision 121. Placed after the painting slices (review): painting is the reported breakage, and the menu has more to hold by then.

- **E2. Menu bar and controls help** (Editor, about 170 lines)
  - **Goal:**
    - A menu bar above the toolbar, as legacy had:
      - **File:** New map... (Ctrl+N), Save (Ctrl+S), Exit.
      - **Edit:** Undo (Ctrl+Z), Redo (Ctrl+Y), Delete selected objects (Del).
      - **View:** Grid (checkable), Dim other layers (checkable), Fit map (Ctrl+0), Actual size (Ctrl+1).
      - **Map:** Settings..., Add layer... (focuses E1's Add layer box).
      - **Help:** Controls (F1).
    - The toolbar keeps Save, Undo, Redo, the layer box and the tile tools (decision 121); "New map..." and "Map settings..." move to the menu.
    - F1 opens a controls window listing, per mode (Tiles, Objects, Events) and for the view, every mouse gesture and key the editor has at this point (the comments in `MainWindow.xaml` and the tooltips).
    - Later slices add their entries and help lines: Tiles > Mark blocked (E4a), View > Show collision (E8), Tiles > Set up sheet... and Cut... (E5b, E6), Tiles > Import sheet image... (E7), Objects > Edit shapes... (E9), Objects > New object from selection... (E12b), Objects > New NPC... (N3).
  - **New types:**
    - `Shell/ControlsHelpWindow` (XAML, no logic): shows the controls text.
  - **Changes:**
    - `MainWindow.xaml`: the `Menu`; Ctrl+N and F1 key bindings; `Exit` closes through `OnClosing` (so unsaved changes still ask).
    - `Objects/ObjectPlacingViewModel.DeleteSelectedObjects` gains `[RelayCommand]`, so the menu binds to it; the Delete key keeps calling it.
    - `MainWindow.xaml.cs`: `OnFitClicked`, `OnActualSizeClicked`, `OnNewMapClicked`, `OnMapSettingsClicked` serve the menu entries too.
  - **Tests:**
    - `ObjectPlacingViewModelTests`: `DeleteSelectedObjectsCommand_NothingSelected_ChangesNothing`.
  - **Verify by hand:**
    - [ ] Every menu entry does what its toolbar button or key did; checkable entries follow the toolbar check boxes.
    - [ ] File > Exit with unsaved changes asks.
    - [ ] F1 opens the controls; each listed gesture works as written.
    - [ ] Ctrl+N opens the new map dialog.
- **Done, with deviations:** Ctrl+N and F1 are WPF's own `New` and `Help` commands, bound in `MainWindow.xaml` (no hand-written key handling); the menu is not the main menu (`IsMainMenu="False"`), so releasing Alt after Alt + click doesn't move the focus to it, and it has no Alt access keys. Fit and 100 % stay on the toolbar beside the menu entries.
- **Review follow-up:** F1 brings the one open controls window to the front instead of opening another; the Events help line says a right click removes the event of a cell without an object. Edit > Delete selected objects works in every mode while Del works only in Objects mode: kept, since only Objects mode selects. The Space + drag focus bug (older) is in the backlog.
