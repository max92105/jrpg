# Q2. The equipment list offers one row per wearer, and Confirm takes it

Part of [the demo retirement plan](../README.md). Design: [design.md](../design.md), key decision 7, "Backlog items near this plan"; tunables "worn row" and "take hint"; decision 137.

- **Q2. One row per wearer; Confirm takes it** (Game + content, about 200 lines)
  - **Goal:**
    - In Equipment, a slot's list shows "Remove", the owned items, then one row per item another member wears there: "Bronze Sword (Sarxian)", in the secondary text color.
    - Highlighting a worn row previews the stats as for an owned item. The footer (H1) says "Taking it leaves Sarxian without it."
    - Confirm moves the item to the shown member at once (`TryTakeFrom`). The wearer's slot empties, and the shown member's old item goes to the bag.
    - If Core refuses because the bag has no room for the old item, the page shows the existing "no room" notice for it.
    - The list already has its look, and worn rows only change color and text, so there is no separate look slice.
  - **Changes:**
    - `Menus/EquipmentChoice`:
      - takes `(IReadOnlyList<ItemDefinition> wearable, IReadOnlyList<WornItem> takeable)`;
      - rows are Remove, then wearable, then takeable;
      - `Highlighted` stays the item;
      - new `HighlightedWearer` (`PartyMember?`).
    - `Menus/EquipmentPick` gains `Giver` (`PartyMember?`): null for Remove and owned rows.
    - `Menus/EquipmentChoiceView`: worn rows formatted with `equipment_worn_row` when the list opens, in the secondary color.
    - `Menus/EquipmentPage`:
      - opens the choice with `TakeableFor(Shown, slot, party)`;
      - in `Apply`, a pick with a `Giver` calls `TryTakeFrom(giver, Shown, slot)`;
      - `Hint` (H1) becomes the take hint while a worn row is highlighted, formatted when the highlighted row changes (where `ShowPreview` already rebuilds).
    - `Ui/MessageIds.EquipmentWornRow`, `EquipmentTakeHint`, with `content/text/ui.json` `"equipment_worn_row": "{item} ({member})"` and `"equipment_take_hint": "Taking it leaves {member} without it."` (placeholders).
  - **Tests:**
    - `EquipmentChoiceTests`:
      - `Rows_WornByOthers_ListedAfterTheOwnedOnes`;
      - `Update_ConfirmWornRow_PicksItWithItsWearer`;
      - `Update_ConfirmOwnedRow_HasNoGiver`.
    - `EquipmentPageTests`:
      - `Update_ConfirmWornRow_MovesTheItemToTheShownMember`;
      - `Update_TakeWithNoRoomForOwnItem_ShowsTheNoRoomNotice`;
      - `Hint_WornRowHighlighted_NamesTheWearer`.
