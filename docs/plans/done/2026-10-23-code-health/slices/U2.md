# U2. `Ui/ColumnTitles`: column captions over a hairline, once

Part of [the code health plan](../README.md). Design: [design.md](../design.md), tunable "Column titles", backlog survey ("Column titles over a hairline copied 3 times").

- **U2. `ColumnTitles`** (Game, about 120 lines)
  - **Goal:**
    - The captions over a list's columns ("Name … Qty", "File  Location … Party") and the hairline under them are drawn by one Ui part.
    - The Inventory page, the equipment choice and the save list use it, and their copies and title-width fields go.
    - What the player sees is unchanged, pixel for pixel.
  - **New types:**
    - `Ui/ColumnTitles`: a list's column captions over a hairline, measured once.
      - `const int Height = 28` (where rows start), `const int LineGap = 20`.
      - `ColumnTitles(SpriteFontBase font, UiTextures ui, IReadOnlyList<ColumnTitle> titles)`.
      - `void Draw(SpriteBatch batch, TextureLibrary textures, Rectangle section, float opacity)`: section is the titles' row; the hairline spans its width.
    - `Ui/ColumnTitle` (record struct): one caption and where it sits.
      - `static ColumnTitle FromLeft(MeasuredText text, int offset)`, `static ColumnTitle FromRight(MeasuredText text, int offset)`.
      - These are two factories rather than a flag: a right-aligned title needs its width, a left one doesn't.
  - **Changes:**
    - `Menus/InventoryPage`: `DrawColumnTitles` and `InventoryLabels.Name`/`Quantity`/`QuantityWidth` go. `ColumnTitlesTop`, `ColumnTitleLineGap` and `RowsTop` use `ColumnTitles`.
    - `Menus/EquipmentChoiceView`: `_quantityTitle`, `_quantityTitleWidth` and its title lines go.
    - `Saving/SaveSlotListView`: `DrawColumnTitles`, `_columnTitles`, `_partyTitleWidth`, `ColumnTitlesHeight` and `ColumnTitleLineGap` go.
    - Opacity: the equipment choice draws its titles at full opacity today. Keep that (pass 1), so nothing changes.
    - `docs/map.md`: Ui row lists `ColumnTitles`.
    - `docs/plans/backlog.md`: remove the "Column titles over a hairline" line.
  - **Tests:** none (draw-only). Existing page tests pass unchanged.
  - **Verify by hand:** before/after screenshots, the same pixels:
    - [ ] Inventory page (Esc, Inventory);
    - [ ] Equipment page with a slot's choice open;
    - [ ] the Save page's list.
- **Done, with deviations:** `ColumnTitle` is a record struct with a private constructor, so the two factories are its only way in (no public bool argument). The Inventory page's label font is now a constructor local, and `InventoryLabels` keeps only the empty-list text. Before/after screenshots compared pixel by pixel over each title row (Inventory, Equipment with a slot's choice open, the Save list): 0 different pixels in all three. Review: `ColumnTitles.LineGap` is private (nothing outside reads it). Inventory and the equipment choice build the same Name/Qty titles: two copies, left until a third.
