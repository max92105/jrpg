# A1a1. The voice step, checked at startup

Part of [the new-game flow plan](../README.md). Design: [design.md](../design.md), "Content format", "Tunables and placeholders" (voice). ADRs 0016, 0018. Split from A1a at the size check. A1a2 adds the editor support and puts the voice into the intros.

- **A1a1. The voice step: an event starts a voice file, checked at startup; one generated placeholder voice** (Core + Data + Game startup + content, about 280 lines; decision 160)
  - **Goal:**
    - An event step `{ "type": "voice", "file": "Placeholder.wav" }` starts a voice-over and doesn't wait: the stills that follow play over it.
    - It is a presentation step, so a skip runs past it (K2a).
    - At startup, a missing file, or a name differing only in case, stops the start with the file named, as missing art does.
    - No repository map uses the step yet, so the editor (which can't edit it until A1a2) still opens every map. Nothing plays yet (A1b).
  - **New types:**
    - Core `Events/VoiceStep(string File) : EventStep`, which starts a voice-over in `audio/voices/` and runs on at once (`IsPresentation`).
    - Data `Audio/AudioFolders` (static): where sound lives. `RootIn(string contentRoot)` gives `content/audio`, and `Voices = "voices"`.
    - Data `Audio/AudioReferenceCheck` (static): every voice step's file exists by exact name, "Named by event 'intro_omer' on map 'intro'".
    - Data `Content/ExactFileName` and `Maps/MapEventSteps` (internal, static): `ArtReferenceCheck`'s case-mismatch check and its walk over the maps' event steps, moved out so the two checks share them.
  - **Changes:**
    - Core `EventRun`: a voice step runs on at once, like a swap, and records it so the Game can play it. `ExplorationState.StartedVoice` is "the voice the running event started, or null", cleared when the event ends or skips.
    - Data:
      - `ContentTypeDiscriminators` gains `voice`;
      - `MapEventValidator` checks `file` not blank.
    - Game: `Program` reports art and audio problems together.
    - Content: `content/audio/voices/Placeholder.wav`, about 3 s, made once with Windows' built-in speech synthesizer from Windows PowerShell 5.1. It is a tool already on the machine, and nothing is added to the solution. Record the command in the Done note:
      ```powershell
      Add-Type -AssemblyName System.Speech
      $synth = New-Object System.Speech.Synthesis.SpeechSynthesizer
      $format = New-Object System.Speech.AudioFormat.SpeechAudioFormatInfo(22050, [System.Speech.AudioFormat.AudioBitsPerSample]::Sixteen, [System.Speech.AudioFormat.AudioChannel]::Mono)
      $synth.SetOutputToWaveFile("content\audio\voices\Placeholder.wav", $format)
      $synth.Speak("Placeholder voice-over.")
      $synth.Dispose()
      ```
    - `Jrpg.Game.csproj` already publishes `content/**`, so no change there.
  - **Tests:**
    - `EventRunTests`:
      - `Start_VoiceThenStill_RunsOnToTheStillWithTheVoiceStarted`
      - `SkipPresentation_VoiceAndStills_StopsOnTheWarp`
    - `AudioReferenceCheckTests`:
      - `FindProblems_RepositoryContent_IsEmpty`
      - `FindProblems_MissingVoice_NamesTheEventAndMap`
      - `FindProblems_CaseMismatch_NamesTheActualFile`
    - `MapEventValidatorTests`: theory row for a blank `file`.
  - **Verify by hand:**
    - The game starts.
    - The file plays in Windows' media player.
- **Done, with deviations:**
  - Split from A1a at the size check (developer). The intro content moved to A1a2 with the editor support, so the editor never meets a step it can't open. No repository map uses the voice step yet.
  - `ArtReferenceCheck`'s case check and its event-step walk moved to `Content/ExactFileName` and `Maps/MapEventSteps`, shared with `AudioReferenceCheck`. `EventRun.StartedVoice` stays set over the steps after the voice and clears on a skip.
  - `Placeholder.wav` (16-bit PCM, mono, 22050 Hz, about 2.3 s) was made with the planned command from Windows PowerShell 5.1, writing to `content\audio\voices\Placeholder.wav`.
  - A test checks the placeholder file is found under its exact name. `ContentWriter` (the editor's save) still runs only the art check: noted as a follow-up. Tests: 1751 before, 1758 after.
