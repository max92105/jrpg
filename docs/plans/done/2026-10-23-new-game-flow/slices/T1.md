# T1. The title shows only usable entries

Part of [the new-game flow plan](../README.md). Design: [design.md](../design.md), "What exists, checked" and "Replacement mapping".

- **T1. The title shows only usable entries; Continue first and selected with a save** (Game, about 170 lines; decisions 156, 177)
  - **Goal:**
    - With a readable save, the title lists Continue, New Game, Load, Quit, with the cursor on Continue.
    - Without one, it lists New Game and Quit, with the cursor on New Game.
    - Nothing is greyed.
  - **Changes (Game):**
    - `Title/TitleMenu`:
      - `Entries` becomes an instance `IReadOnlyList<TitleEntry>`, built in the constructor from `hasReadableSave`;
      - the cursor starts on the first entry, which is Continue whenever it is listed;
      - `IsEnabled` is deleted, and the `ListCursor` gets no skip predicate;
      - the summary says what is listed and why, and drops decision 80's greying.
    - `Title/TitleScene`:
      - labels, centers and origins are built from `_menu.Entries`;
      - the greyed branch in `DrawEntry` goes;
      - a small read accessor `SelectedEntry` lets tests pick entries by what they are.
    - `UiTheme.TextDisabled` stays while other screens use it (the defeat menu does until T2).
  - **Tests:**
    - Rewrite `TitleMenuTests`:
      - `Entries_ReadableSave_ListsContinueNewGameLoadQuit`
      - `Entries_NoReadableSave_ListsNewGameAndQuit`
      - `Selected_ReadableSave_IsContinue`
      - `Selected_NoReadableSave_IsNewGame`
      - `Update_DownFromContinue_SelectsNewGame`
      - `Update_DownWithoutReadableSave_SelectsQuit`
      - `Update_NothingPressed_ReturnsNothing`
      - `Update_ConfirmWithReadableSave_ReturnsContinue`
    - `TitleSceneTests`:
      - Continue is confirmed with no Down.
      - New Game and Load are reached with a helper that presses Down until `SelectedEntry` is the one wanted (`tests.md`: pick an entry by what it is).
    - `GameFlowTests`: their save slots are unwritten, so New Game is still first and selected. Check that any test writing a save first uses the helper.
  - **Verify by hand:**
    - With no save files (rename the save folder): New Game and Quit, with New Game lit.
    - With a save: Continue, New Game, Load, Quit, with Continue lit. Confirm loads the latest save.
  - **Done, with deviations:**
    - The tests pick entries with a `Select` helper that presses Down until `SelectedEntry` matches.
    - Two tests were added beyond the plan: Up from Continue wraps to Quit, and Confirm with no save returns New Game.
    - `GameFlowTests` needed no change: their title presses all happen with no save, where New Game stays first.
    - `ListCursor`'s summary now gives a member an item can't be used on as its example of a skipped entry, replacing greyed Continue.
    - Review: the test helper `Select` is capped at one press per entry and then asserts the entry, so a missing entry fails the test instead of hanging the run.
