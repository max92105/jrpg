# Z1. Run-through: the full new-game flow

Part of [the new-game flow plan](../README.md).

- **Z1. Run-through** (manual, after A1b, before the look phase)
  - **Goal:** the developer plays the whole flow, plain-looking, and says what to change before the look work starts.
  - **Checklist:**
    1. **No saves** (rename the save folder): the title shows New Game and Quit, and New Game is selected.
    2. New Game lists the nine, Ragnir to Thaali. The information beside the list (class, description, summary, level 1 stats) changes with the cursor.
    3. Cancel returns to the title.
    4. Confirm asks "Begin as X?". No returns to the list; Yes plays the intro, with stills fading, subtitles and the placeholder voice. Then the map.
    5. The leader is alone, at level 1, with their class's numbers.
    6. On the start map, the recruit points add members. The fifth joins the active party, the rest the reserve, and the leader's own point says already joined.
    7. Win the goblin fight: a level-up raises the stats.
    8. Lose a fight with no save: only Main Menu shows.
    9. Save and return to the title: Continue, New Game, Load, Quit, with Continue selected. Continue loads with the same leader and recruits.
  - **Done when:** the developer has gone through it, and anything they want changed is a new question, a backlog line or a slice before S3a.
- **Done, with deviations:** the developer went through the run-through on 2026-10-24: "ok test are good". Nothing to change before the look phase.
