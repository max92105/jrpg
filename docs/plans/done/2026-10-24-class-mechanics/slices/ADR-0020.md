# ADR 0020: Skills come from the class

Part of [the class mechanics plan](../README.md). Design: [design.md](../design.md), "Replacement mapping". Answers question 181.

- **ADR 0020: Skills come from the class** (checkbox step before CS1; write with `/adr`)
  - **Question:** where does a member's skill list come from, now that skills use their class's resource? Question 181 left skills on the member "until a class-skills plan".
  - **Options:**
    - A. the class lists its skills in `classes.json` `skillIds`; every member of the class has them (recommended);
    - B. the member keeps `skillIds`, as today. A skill could then name a resource its member's class lacks;
    - C. both: class skills plus a member's own. Nothing needs per-character skills yet, and C can be added to A later.
  - **Record with the decision:**
    - Every resource a skill changes or requires must be one of the class's resources; Data checks it, naming the class and the skill.
    - Saves are unchanged: they never held skills.
    - Learning skills by level is a later extension of the class's list.
  - **Done when:** `docs/decisions/0020-skills-come-from-the-class.md` is accepted and indexed; question 181 is marked answered in the new-game flow plan's README.
- **Done, with deviations:** as planned. The developer accepted A on 2026-10-24.
