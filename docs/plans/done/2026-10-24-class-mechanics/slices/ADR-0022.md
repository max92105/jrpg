# ADR 0022: MP leaves the game; how saves migrate

Part of [the class mechanics plan](../README.md). Design: [design.md](../design.md), "Key design decisions" 9, "Risks" (save migrations). Decision 197; ADR 0007.

- **ADR 0022: MP leaves the game; how saves migrate** (checkbox step before MP1; write with `/adr`)
  - **Question:** decision 197 removes MP, the first change to the save format since ADR 0007. How does an old save load once a field it holds is gone? LR2 adds a field later with the same mechanism.
  - **Options:**
    - A. an ordered chain of migrations in Data (`Saving/SaveMigrations`), one per version step, each rewriting the JSON tree (`JsonObject`) from version n to n + 1. They run in `FileSaveStore` before deserializing; the strict reader stays strict (recommended).
    - B. tolerant deserialization (ignore unknown fields, default missing ones), with no version bump. It contradicts ADR 0007 and hides damaged files.
    - C. one versioned DTO per format, mapped to the model. Heavy for a field drop, and every later change copies a DTO.
  - **Record with the decision:**
    - MP leaves in four steps, each building alone:
      - skills and effects (MP1);
      - screens (MP2);
      - saves, format 1 → 2, dropping `mp` from each member (MP3a);
      - members and enemies (MP3b).
    - Each migration has a test loading a file in the old format. A save newer than the build is still rejected.
    - `RestoreMp` goes, since no content uses it; no item retires.
  - **Done when:** `docs/decisions/0022-mp-leaves-and-save-migrations.md` is accepted and indexed; ADR 0007 gets a "migrations: see 0022" line.
- **Done, with deviations:** the developer chose a fourth option, D, over the three planned (2026-10-24): saves are test saves, so until the first release a format change bumps the version and refuses older saves, with no migration (decision 229). Updated to match:
  - `docs/decisions/0022-mp-leaves-and-save-migrations.md` is accepted with D, and ADR 0007 gets its "migrations: see 0022" line.
  - CLAUDE.md's save rule, plus MP3a, LR2, the ADR 0024 slice and design.md.
  - The developer's one test save (`%LOCALAPPDATA%\Jrpg\Saves\slot_01.json`) was deleted at their request.
