# D1. `enemies.json` actions, checked against the skills

Part of [the enemy skills and bosses plan](../README.md). After T1. Decisions 411, 412. Design: [design.md](../design.md), "Core changes" (Data).

- **D1. `enemies.json` actions, checked against the skills** (Data, about 190 lines)
  - **Goal:** `enemies.json` may give an enemy `tactics`; a broken action stops the load with a message naming the enemy, the field and the index. Conditions (`when`) come in T2. Content shape:
    ```json
    "tactics": [
      { "weight": 4 },
      { "skillId": "cleave", "weight": 2 }
    ]
    ```
  - **New types** (`Data/Battle/`):
    - `EnemyReferences`: what an enemy may name. `internal sealed record EnemyReferences(IReadOnlySet<string> DropTableIds, IReadOnlyDictionary<string, SkillDefinition> Skills)`.
    - `EnemyTacticsValidator`: an enemy's actions against the skills. `internal static`; `string? FindProblem(IReadOnlyList<EnemyAction> tactics, string field, IReadOnlyDictionary<string, SkillDefinition> skills)` (`field` is `tactics` here, `phases[i].tactics` in B3).
  - **Rules** (decision 411):
    - no null entry; weight at least 1;
    - a `skillId` is a known skill; the skill changes no resource and requires none (enemies have none, ADR 0019); its targeting is neither `alliesInRange` nor `otherCombatant`.
  - **Changes:**
    - `Battle/EnemyCatalogValidator.Validate(string fileName, IReadOnlyList<EnemyDefinition> enemies, EnemyReferences references)`; calls `EnemyTacticsValidator` after its own checks.
    - `Content/ContentCatalogLoader`: builds `EnemyReferences(dropTableIds, skillsById)`.
  - **Call sites:** `EnemyCatalogValidatorTests` (4).
  - **Tests** (new file `EnemyTacticsValidatorTests`; message text pinned as the other validator tests do):
    - `Validate_TacticsWithANullEntry_NamesTheIndex`
    - `Validate_ActionWeightZero_IsRefused`
    - `Validate_UnknownSkillId_NamesIt`
    - `Validate_SkillThatSpendsAResource_IsRefused` (Fire Blast's shape)
    - `Validate_SkillThatRequiresAResource_IsRefused` (Heal's shape)
    - `Validate_SkillAimedAlongTheFormation_IsRefused` (`alliesInRange`)
    - `Validate_SkillAimedAtAnyOtherCombatant_IsRefused` (`otherCombatant`)
    - `Validate_ActionWithoutSkillId_IsAccepted` (the basic attack, decision 412)
    - `Load_EnemyWithTactics_ReadsTheActions` (a temp content root through `ContentCatalogLoader`: `skillId` and `weight` reach the record)
  - **Verify by hand:** a game start with an unknown id in a local copy of `enemies.json` names the enemy and the id on screen.
  - **Watch:** `ContentCatalogLoader` 113 (+2).
  - **Done, with deviations:** as planned; the two resource tests are one theory (`Validate_SkillThatChangesOrRequiresAResource_IsRefused`), with `Validate_SkillWithoutAResourceAtWeightOne_IsAccepted` added as the accepted bound. The load test adds its own skill to a copied `skills.json`. Tests 3362 → 3372.
