# T0. Move the attack's target rule into `EnemyTargeting`

Part of [the enemy skills and bosses plan](../README.md). After the ADR 0034 step. Design: [design.md](../design.md), "Core changes", "Replacement mapping".

- **T0. Move the attack's target rule into `EnemyTargeting`** (Core refactor, about 70 lines)
  - **Goal:** the rule "a taunting member unless the enemy's crowd control resistance shrugs the taunt off, else a random living member" leaves `EnemyTactics` for its own type, so T1 can aim skills by it. Behavior and draws are unchanged.
  - **New types:**
    - `Core/Battle/EnemyTargeting`: whom an enemy aims a chosen action at. `internal sealed class EnemyTargeting(IRandom random)`; `Combatant ForAttack(BattleState battle)` (today's rule and draws: one for the target, one more only when a taunt might be resisted). Its summary carries the draw note now on `EnemyTactics`.
  - **Changes:**
    - `Battle/EnemyTactics`: keeps the phase guard and returns `new AttackCommand(_targeting.ForAttack(battle))`; its summary says it chooses the command and `EnemyTargeting` aims it. `ResistsTaunt` and the `ChanceRolls` field move.
  - **Tests:** none new. The guard is `EnemyTacticsTests` (9 tests, including the taunt and resist draws), `BattleTurnSequenceTests` and `ForestFightsSimulation`, passing unchanged (refactor slice).
  - **Verify by hand:** none (no behavior change).
  - **Done:** as planned; tests unchanged at 3345.
