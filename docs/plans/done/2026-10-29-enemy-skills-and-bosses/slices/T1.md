# T1. Enemies choose a skill from a weighted list; nothing usable means the attack

Part of [the enemy skills and bosses plan](../README.md). After T0. Decisions 400, 403, 412, 413. Design: [design.md](../design.md), "Core changes", "Key decisions" 2 and 3, "Replacement mapping".

- **T1. Enemies choose a skill from a weighted list; nothing usable means the attack** (Core, about 245 lines)
  - **Goal:** an enemy whose definition lists tactics picks one action by weight among the eligible ones (a skill it can use, or the basic attack) and aims it; with nothing eligible it attacks (decision 403). `Execute` lands the skill through the party's path. An enemy without tactics attacks exactly as today, with the same draws (decision 412).
  - **New types:**
    - `Core/Battle/EnemyAction`: one weighted choice in an enemy's tactics. `public sealed record`; `string? SkillId { get; init; }` (null: the basic attack), `required int Weight { get; init; }`. (`When` comes in T2.)
  - **Changes:**
    - `Battle/EnemyDefinition`: `IReadOnlyList<EnemyAction> Tactics { get; init; } = []`; `bool NamesSkill(string skillId)`.
    - `Battle/Combatant.Knows(SkillDefinition skill)`; the `Skills` summary says an enemy's skills are named by its tactics.
    - `Battle/BattleState.CanUse(SkillDefinition)`: `CurrentActor.Knows(skill)` in place of `Skills.Contains(skill)`.
    - `Battle/EnemyTargeting.ForSkill(BattleState battle, SkillDefinition skill)`: every candidate of `battle.TargetChoiceFor(skill)` when it takes all; a `singleEnemy` skill by the attack's taunt rule over its candidates (decision 400); any other single target at random among its candidates.
    - `Battle/EnemyTactics(IRandom random, IReadOnlyDictionary<string, SkillDefinition> skills)`: no tactics → the attack as today; else the actions whose skill `battle.CanUse` allows (an attack is always allowed); none → the attack; else `WeightedPick.Pick` over their weights, then an `AttackCommand` or a `SkillCommand(skill, targeting.ForSkill(battle, skill))`. Its summary says what it draws, in order.
    - `Session/GameSession`: `new EnemyTactics(context.Random, context.Catalog.Skills)`.
    - Test builder: `EnemyDefinitionBuilder.WithTactics(params EnemyAction[] actions)`.
  - **Call sites:** `new EnemyTactics(random)` in 18 places (`EnemyTacticsTests` 9, `BattleTurnSequenceTests` 5, `BattleStateOutcomeTests`, `BattleStatusTests`, `ForestFightsSimulation`, `GameSession`): tests pass an empty skill dictionary; the simulation passes `catalog.Skills`. About 20 lines.
  - **Tests** (new file `EnemySkillTacticsTests`, with a test skill catalog; an enemy without tactics is already pinned by `EnemyTacticsTests`, whose builder enemies have none):
    - `ChooseCommand_WeightedDrawInSkillsShare_UsesTheSkill` (attack weight 1, skill weight 3, draw 1: the draw sits where the weights move the edge)
    - `ChooseCommand_WeightedDrawInAttacksShare_Attacks` (same weights, draw 0)
    - `ChooseCommand_OnlyActionIsASkill_DrawsNothingForThePick` (one value in the sequence, the target's)
    - `ChooseCommand_SkillWithNoTarget_IsNotPicked` (a revive with nobody fallen beside an attack: the attack holds the whole weight, no pick draw)
    - `ChooseCommand_OnlySkillUnusable_Attacks` (a kit of one revive with nobody fallen: the attack, without reaching `WeightedPick`'s throw)
    - `ChooseCommand_AllEnemiesSkill_TargetsEveryLivingMember`
    - `ChooseCommand_SingleEnemySkillWithATaunter_AimsAtTheTaunter`
    - `ChooseCommand_SingleAllySkill_AimsAtARandomEnemy` (a status skill, Guarded on one ally, not a heal: T3 gives heals their own rule; the enemy's allies are the enemies, itself included)
    - `Execute_EnemySkillCommand_LandsTheSkillsContentPower` (decision 413: `EffectApplied` with the content power, no resource event)
    - `CanUse_EnemyWhoseTacticsDontNameTheSkill_IsFalse` (new file `CombatantKnowsTests`)
    - `Knows_MemberWithTheSkill_IsTrue` (`CombatantKnowsTests`: the member side of `Knows`)
  - **Verify by hand:** nothing changes in play (no repository enemy has tactics before C1); the forest's goblins still only attack.
  - **Watch:** `BattleState` 269 (±0). `EnemyTactics` stays one per playthrough; `EnemyTargeting` is its field.
  - **Done, with deviations:** as planned, with `Knows_MemberWithoutTheSkill_IsFalse`, `CanUse_EnemyWhoseTacticsNameTheSkill_IsTrue` and two taunt tests (a resisted one, and a skill taking all that ignores it) added. An enemy without tactics needs no branch: nothing is eligible, so it attacks without a pick.
