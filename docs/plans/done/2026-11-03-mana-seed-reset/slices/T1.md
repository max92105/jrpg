# T1. The test world

Builds on ADR 0037 (written before this slice) and design.md, "Key decisions" 1. Needs S0 done: the pack out of `content/`, and the 23 deleted sheets restored, so every test passes at the end of this slice.

## Goal
A whole content root, `test-world/`, in each test project's output: the live `content/` without its map side, plus a frozen copy of today's map side. Nothing reads it yet but its own tests; T2a-T2c move the tests onto it.

## Files
- `tests/TestWorld/maps/*.json`, `tests/TestWorld/map-layouts/*.json`: today's five maps (`intro`, `start`, `interior_1`, `forest`, `to_aslas_1`), copied byte for byte.
- `tests/TestWorld/tiles.json`, `tilesheets.json`, `objects.json`, `new-game.json`: copied.
- `tests/TestWorld/art/tilesheets/`: the ten images `tilesheets.json` names, plus `Grass3.png` (an image no sheet is set up on, which the Editor tests open). Same blobs as in history: the repository doesn't grow.
- `tests/TestWorld/README.md` (new): what the folder is, that it is frozen at this commit, that the editor never writes it, that a change is a hand edit for a test's need, what renaming live content does to it, and that the frozen `new-game.json` holds the starting items, gold and leader choices the Game tests count on (ADR 0037's consequences).
- `tests/TestWorld/TestWorld.props` (new): two `None` items with `LinkBase="test-world"` and `CopyToOutputDirectory="PreserveNewest"`: `content\**` excluding `maps\**`, `map-layouts\**`, `tiles.json`, `tilesheets.json`, `objects.json`, `new-game.json` and `art\tilesheets\**`; then `TestWorld\**` excluding `README.md` and `TestWorld.props`. Paths from `$(MSBuildThisFileDirectory)`.
- `tests/Jrpg.Data.Tests/Jrpg.Data.Tests.csproj`, `Jrpg.Editor.Tests`, `Jrpg.Game.Tests`, `Jrpg.Simulations`: `<Import Project="..\TestWorld\TestWorld.props" />` beside the existing `content` item.
- `docs/map.md`, "Where to look": "A map a test walks → `tests/TestWorld` (frozen, ADR 0037)."
