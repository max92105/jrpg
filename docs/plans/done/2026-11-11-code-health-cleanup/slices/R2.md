# R2. Editor Maps: the lines that do two things

Editor, about 50 lines, no behavior change. Builds on decision 539. After V1, so its changed lines are checked at 130 columns.

## Goal
In the editor's `Maps/` folder, which every map plan opens, the lines that compute two things at once become named steps. Lines that are only long are left for V1's check to wrap when a slice next changes them.

## Changes
- `Maps/MapDrawing.cs`: the above-player zones' clip, `zones.Children.Add(new PathGeometry([new PathFigure(outline[0], [new PolyLineSegment(outline.Skip(1), isStroked: false)], closed: true)]))`, builds the segment, the figure and the geometry as named locals (or a private `static PathGeometry ClosedOutline(IReadOnlyList<Point> outline)`); `DrawObjectAt`'s area `Rect` from a named top-left and size.
- `Maps/CollisionShapes.cs`: `Of` builds the placed objects with their definitions, then the outlines, then the zones, each a named local on its own line; `InMapCells`' point arithmetic through a private `static Point2D InMapCell(Point2D point, PlacedObject placed, ObjectDefinition definition)`.
- `Maps/MapTree.cs`: `Of` (four parameters on one 180-column line) takes them one per line; its `folders` set (the shown maps' folders, plus the session's unless filtering) as two named steps; the folder rows' `isExpanded` as a named local in `RowsUnder`.

Comments the changes touch are rewrapped with `perl .claude/scripts/reflow-comments.pl`. A summary that turns out stale on rereading (the reviewer's smell) is fixed in the same slice and named in the Done note.

## Tests
None new: `MapDrawingTests`, `CollisionShapesTests` and `MapTreeTests` reach every changed line. The runner's totals per project are equal before and after (Done note).

## Verify by hand
1. View > Collision on a map with an object that has an outline and an above-player zone: both drawn where they were.
2. The map list's tree: folders, their open state and a filter as before.

- **Done, with deviations:** as planned: `MapDrawing`'s `ClosedOutline(Point[] outline)` (the analyzer wants the array the caller has, CA1859) and the sprite area's `areaTopLeft` and `areaSize`; `CollisionShapes.Of`'s `placed`, `withOutline` and `zones` as their own steps, `InMapCell` for one point; `MapTree.Of`'s parameters one per line, `mapFolders` then `folders`, an `IsOpen` local function in `RowsUnder`. Two wraps were for length alone, against decision 539: `InMapCells`' signature (its body changed under it) and the `Shown` record's parameters (plain length; recorded here as the review asked).
