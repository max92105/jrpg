# V1. `verify.ps1` refuses a changed code line over 130 columns (the developer's edit)

Script, about 10 lines. **The developer makes this edit**: `.claude/scripts/verify.ps1` is protected. Builds on decision 539. After R1, before R2, so R2 and R3 run under it.

## Goal
`verify.ps1` refuses a changed or new C# code line over 130 columns, as step 7 already refuses a changed comment over 120, so a long line wraps when a slice next changes it and the repository never needs a bulk rewrap.

## The check to add
In step 7 of `.claude/scripts/verify.ps1` (the "Comment lines changed since the last commit fit in 120 columns" block), beside the comment check, reading the same added lines:

1. Next to `$maxCommentColumns = 120`:
   ```powershell
   $maxCodeColumns = 130
   $longCode = @()
   ```
2. In the `git diff -U0 HEAD -- '*.cs'` loop, right after the `$longComments +=` line:
   ```powershell
   elseif ($text -notmatch $commentPattern -and $text.Length -gt $maxCodeColumns) { $longCode += "${file}:$lineNumber ($($text.Length) columns)" }
   ```
   (an `elseif` of the comment check's `if` on the line above, so a comment line is never counted twice).
3. In the untracked-files loop, right after its `$longComments +=` line, the same `elseif` with `${newFile}:$number`.
4. After the comments' `Report` line:
   ```powershell
   Report "changed code lines fit in $maxCodeColumns columns (split the line where it does two things)" (-not $longCode) ($longCode | Select-Object -First 20)
   ```
5. The step's heading comment: "7. Comment lines changed since the last commit fit in 120 columns and code lines in 130 (code-quality.md) ...".

`CLAUDE.md`'s `verify.ps1` line gains "changed code lines within 130 columns" beside "changed comments within 120 columns", and `.claude/rules/code-quality.md`'s Comments section beside its 120-column rule: "Code lines fit in 130 columns; `verify.ps1` refuses a changed one over it."

## Verify by hand
1. With a clean tree, `powershell -NoProfile -ExecutionPolicy Bypass -File .claude/scripts/verify.ps1`: the new line reports success.
2. Add a 140-column statement to any `src/` file: the new line fails, naming the file, the line and "140 columns"; revert.
3. A 125-column comment still fails the comment check, not the code check.
