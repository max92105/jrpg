# UI reference

Screenshots of the developer's favorite UI/UX, Octopath Traveler II, the target style for every screen. Four shots come from the first game (marked *Octopath I*). Look at them before planning or drawing a screen: take the vibe, not a one-for-one copy (decision 253).

**Reference only.** Like every other game's asset (these screenshots, the extracted UI export), they are never loaded or shipped by the game, which draws its own versions (decision 264).

## Names

`<area>-<what>.<ext>`: the area is `title`, `menu`, `dialog`, `shop` or `battle`; the rest says what the shot shows, with a number when several show the same thing. `.webp` files open with the Read tool.
